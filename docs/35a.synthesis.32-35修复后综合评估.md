## P0 修复详情（阻塞编译/运行）

### 1. PRAGMA key 语法修正（32）
- **问题**：`QuotedStr('x' + hex)` 被 SQLCipher 当 passphrase 二次派生
- **修复**：`PRAGMA key` 移到 `BeforeConnect` 事件，同时推荐 `sqlite3_key()` C API 为首选注入方式

### 2. SQLCipher cipher 参数协商（32）
- **问题**：未设置 page_size/kdf_iter/hmac_algorithm 等必要参数
- **修复**：新增 `TSQLCipherCompatibilityConfig` 结构 + `WeChat39xCipherConfig`/`WeChat4xCipherConfig` 预设 + `TryProbeCipherParams` 自动探测

### 3. PRAGMA key 执行时机（32）
- **问题**：在 `Result.Open` 之后执行——SQLCipher 此时已读取数据页面
- **修复**：移到 `BeforeConnect` 事件中，确保密钥在页面读取前设置

### 4. 删除不存在的 PRAGMA query_only（32）
- **问题**：SQLite 无此 pragma，语句会运行时失败
- **修复**：删除。三层防护替代：`OpenMode=ReadOnly` + `SafeQuery` 内嵌 `IsWriteStatement` + `sqlite3_set_authorizer`

### 5. FConnection.BeforeExecute 不存在（32）
- **问题**：`TFDConnection` 没有此事件，无法编译
- **修复**：写入拦截改为在 `SafeQuery` 工厂方法内部检查 + `sqlite3_set_authorizer` C 层防线

### 6. FConnection.CreateQuery 不存在（32）
- **问题**：此方法不存在，无法编译 + 内存泄漏
- **修复**：`var Q := TFDQuery.Create(FConnection)` + `try/finally Q.Free`

## P1 修复详情（影响正确性/安全性，但不阻塞编译）

### 7. 执行线程 COM 初始化（34）
- **问题**：`TUIAExecutionThread.Execute` 无 `CoInitializeEx`，UIA COM 调用静默失败
- **修复**：`Execute` 开头 `CoInitializeEx(nil, COINIT_APARTMENTTHREADED)` + 结尾 `CoUninitialize`

### 8. SetValue 策略反转（34）
- **问题**：优先用 `ValuePattern.SetValue`，但微信输入框不支持
- **修复**：主策略改为 ClipboardGuard + Ctrl+V 粘贴，ValuePattern 仅作优化路径。增加粘贴后验证（轮询读取控件文本）

### 9. TClipboardGuard 混合 ARC/手动释放（35）
- **问题**：`TInterfacedObject` + `Free` 混合使用 = double-free
- **修复**：TClipboardGuard 改为纯对象，通过 `IClipboardGuard` 接口持有

### 10. BodyZero 自动触发（32）
- **问题**：审计依赖手动调用 `RecordColumnAccess`，可绕过
- **修复**：新增 `SafeQuery` 方法作为唯一数据读取入口，内部自动调用审计

### 11. 结构化 Schema 指纹（32）
- **问题**：Hash `sqlite_master.sql` 原文——格式差异导致同 schema 不同指纹
- **修复**：基于 `PRAGMA table_info` 的结构化 hash（表名+列名+列类型）

### 12. WAL 锁定探测（32）
- **问题**：假设微信不启用 exclusive locking
- **修复**：新增 `CheckWALCompatibility` 探测锁模式 + `busy_timeout=5000` + SQLITE_BUSY 重试

### 13. 密钥内存清零（32）
- **问题**：密钥在 string 中多副本无清零
- **修复**：改用 `TBytes` + `FillChar` 在使用后立即清零

### 14-21. Clipboard/Win32 修复（35）
- AnsiString → TBytes 存储二进制数据（正确处理 `\0` 字节和 GDI handle）
- `keybd_event` → `SendInput` + `wScan`（兼容非英文键盘布局 + UIPI）
- `Sleep(50)` → 粘贴后验证循环（消除竞态）
- Restore 添加重试 + `%TEMP%` 兜底备份
- SetWinEventHook 替代轮��（内核级事件驱动，零延迟）
- `AddWatchTarget` 隐私约束——仅采集注册目标的窗口标题
- 回调列表 `TCriticalSection` 线程安全

### 22-24. SchemaAdapter 加强（33）
- `Resolve` 强制调用 `Validate`
- `MapRow` 增加运行时 `FForbiddenFields` 检查
- 新增批量 `MapRows` 方法

### 25-27. UIA 架构解耦（34）
- `IClipboardGuard` 工厂注入替代具体类依赖
- 拆分 `IUIAutomationEngine` 为单一职责子接口
- UIA mapping JSON 外置配置文件
