# UniBase 文档导航

> UniBase 是 Delphi 应用程序基础设施框架，提供配置管理、国际化、日志、主题等核心能力。

## 📚 文档结构

| 文档 | 说明 | 受众 |
|------|------|------|
| **01_Architecture** | 架构设计文档，模块说明、数据库设计 | 架构师/核心开发 |
| **02_API_Reference** | API 参考手册，全部接口详细说明 | 所有开发者 |
| **03_FAQ_Troubleshooting** | 常见问题、故障排查、性能优化 | 所有开发者 |
| **unibase-spec-v0.3** | 框架权威规范：Schema、协议 | 架构师/核心开发 |
| **tasks** | 开发任务进度跟踪 | 项目管理 |
