# UniFlow 1.0 开发规范

> **版本**: 1.0 | **更新日期**: 2025-12-03
> 1.0 核心命题：成为可对外发布的产品，验证场景为「洞见 + 元老院」

---

## 1. 1.0 目标

### 1.1 核心命题

在 MVP 基础上，将 UniFlow 打造为**可对外发布的产品**：
- 完善的 Skill 生态基础
- 多 LLM 后端支持
- AI Persona 系统
- 可选的云端同步
- 开发者友好的 SDK

### 1.2 验证场景

在 MVP 的「洞见」基础上，增加「元老院」场景：

**元老院·军师决策系统**：
1. 四元老并行推演（分析师、风险官、创意官、价值观守护者）
2. 完整的推演白皮书生成
3. 冲突点自动高亮
4. 长期可复盘

### 1.3 验收标准

1. ✅ 能同时支撑「洞见」和「元老院」
2. ✅ Official Skills ≥ 20 个
3. ✅ 支持多 LLM 后端切换
4. ✅ AI 输出有置信度
5. ✅ 完整的开发者文档
6. ✅ Skill SDK 可用

**Python SDK**：
```python
# uniflow_sdk/skill.py
from abc import ABC, abstractmethod
from pydantic import BaseModel
from typing import AsyncIterator

class UniFlowSkill(ABC):
    """UniFlow Skill 开发基类"""
    
    @property
    @abstractmethod
    def name(self) -> str:
        pass
    
    @property
    @abstractmethod
    def version(self) -> str:
        pass
    
    @property
    def description(self) -> str:
        return ""
    
    @abstractmethod
    async def execute(self, input: dict, context: dict) -> dict:
        pass
    
    async def stream(self, input: dict, context: dict) -> AsyncIterator[str]:
        """可选：流式输出"""
        result = await self.execute(input, context)
        yield str(result)
    
    def validate(self, input: dict) -> bool:
        """可选：输入校验"""
        return True

# 装饰器注册
def skill(name: str, version: str = "1.0.0"):
    def decorator(cls):
        cls._skill_name = name
        cls._skill_version = version
        return cls
    return decorator
```

## 4. 数据模型增量

### 4.1 Skill 市场表

```sql
-- Skill 市场表
CREATE TABLE skill_market (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL UNIQUE,
    version TEXT NOT NULL,
    description TEXT,
    category TEXT NOT NULL,
    author TEXT,
    input_schema TEXT,
    output_schema TEXT,
    trust_level TEXT NOT NULL,
    language TEXT NOT NULL,
    package_url TEXT,
    readme TEXT,
    rating REAL DEFAULT 0,
    download_count INTEGER DEFAULT 0,
    is_official INTEGER DEFAULT 0,
    is_active INTEGER DEFAULT 1,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Skill 评价表
CREATE TABLE skill_reviews (
    id TEXT PRIMARY KEY,
    skill_id TEXT NOT NULL,
    user_id TEXT NOT NULL,
    rating INTEGER NOT NULL,
    comment TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (skill_id) REFERENCES skill_market(id)
);
```

### 4.2 Persona 表

```sql
-- AI 人格表
CREATE TABLE ai_personas (
    name TEXT PRIMARY KEY,
    display_name TEXT NOT NULL,
    description TEXT,
    tone TEXT DEFAULT 'professional',
    verbosity INTEGER DEFAULT 3,
    use_emoji INTEGER DEFAULT 0,
    language TEXT DEFAULT 'zh-CN',
    domain_expertise TEXT,  -- JSON array
    system_prompt TEXT,
    is_builtin INTEGER DEFAULT 0,
    is_active INTEGER DEFAULT 1,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 4.3 同步相关表

```sql
-- 同步队列表
CREATE TABLE sync_queue (
    id TEXT PRIMARY KEY,
    table_name TEXT NOT NULL,
    record_id TEXT NOT NULL,
    operation TEXT NOT NULL,  -- INSERT, UPDATE, DELETE
    data_json TEXT,
    status TEXT DEFAULT 'pending',
    retry_count INTEGER DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    synced_at TIMESTAMP
);

-- 同步冲突表
CREATE TABLE sync_conflicts (
    id TEXT PRIMARY KEY,
    table_name TEXT NOT NULL,
    record_id TEXT NOT NULL,
    local_data TEXT,
    remote_data TEXT,
    resolution TEXT,  -- local, remote, merge, pending
    resolved_at TIMESTAMP,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```
