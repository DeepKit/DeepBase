# UniFlow 角色图谱

> 深入描述 UniFlow 11 个角色的依赖关系、协作模式和消息流转。
>
> 名词和角色编号以 `02.01.Product-UniFlow-名词与角色表-v1.0.md` 为准，本篇主要关注**依赖关系**和**信息流图谱**。

## 1. 角色依赖关系

### 1.1 层级依赖规则

```
依赖方向：只能从高层依赖低层，不能反向依赖

Level 0（元层）    ← 被所有层依赖
Level 1（基础层）  ← 被 Level 2/3/4 依赖
Level 2（能力层）  ← 被 Level 3/4 依赖
Level 3（智能层）  ← 被 Level 4 依赖
Level 4（决策层）  ← 最顶层
```

### 1.2 完整依赖矩阵

```
                      被依赖方
                ┌───────────────────────────────────────────────────────────────┐
                │ 引擎  督察  后勤  记录员  通信官  执行者  守卫  军械官  智囊  调度员  总指挥 │
        ────────┼───────────────────────────────────────────────────────────────┤
        引擎    │  -                                                            │
依      督察    │  ✓     -                                                       │
赖      后勤    │  ✓          -                                                  │
方      记录员  │  ✓          ✓      -                                           │
        通信官  │  ✓          ✓             -                                    │
        执行者  │             ✓      ✓      ✓             -                      │
        守卫    │             ✓      ✓                         -                 │
        军械官  │             ✓      ✓                              -            │
        智囊    │             ✓      ✓             ✓          ✓     ✓      -     │
        调度员  │             ✓      ✓             ✓     ✓    ✓     ✓      ✓    - │
        总指挥  │                                        ✓                       -│
        ────────┴───────────────────────────────────────────────────────────────┘
```

### 1.3 各角色直接依赖清单

| 角色 | 直接依赖 | 被谁直接依赖 |
|------|----------|--------------|
| **引擎** | - | 督察、后勤、记录员、通信官 |
| **督察** | 引擎 | - (观测者，不被依赖) |
| **后勤** | 引擎 | 记录员、通信官、执行者、守卫、军械官、智囊、调度员 |
| **记录员** | 引擎、后勤 | 执行者、守卫、军械官、智囊、调度员 |
| **通信官** | 引擎、后勤 | 执行者、智囊 |
| **执行者** | 后勤、记录员、通信官 | 智囊、调度员 |
| **守卫** | 后勤、记录员 | 调度员、总指挥 |
| **军械官** | 后勤、记录员 | 智囊、调度员 |
| **智囊** | 后勤、记录员、通信官、执行者、军械官 | 调度员 |
| **调度员** | 后勤、记录员、执行者、守卫、军械官、智囊 | 总指挥 |
| **总指挥** | 守卫、调度员 | - (最顶层) |

## 4. 角色消息流

### 4.1 命令消息流（同步）

```
发起方                     接收方                     说明
────────────────────────────────────────────────────────────────
总指挥   ──────────────▶   调度员                    下达任务
调度员   ──────────────▶   智囊                      请求理解/生成
调度员   ──────────────▶   执行者                    请求执行 Skill
智囊     ──────────────▶   军械官                    获取 Prompt 模板
智囊     ──────────────▶   记录员                    读/写上下文记忆
执行者   ──────────────▶   军械官                    获取 Skill 定义
执行者   ──────────────▶   通信官                    调用外部服务
守卫     ──────────────▶   任意角色                  校验请求/响应
```

### 4.2 事件消息流（异步）

```
发布方                     订阅方                     事件类型
────────────────────────────────────────────────────────────────
任意角色 ──────────────▶   记录员                    行为事件（自动）
守卫     ──────────────▶   总指挥                    安全告警
引擎     ──────────────▶   所有角色                  生命周期事件
调度员   ──────────────▶   总指挥                    任务状态变更
执行者   ──────────────▶   调度员                    执行进度上报
通信官   ──────────────▶   守卫/总指挥               外部服务状态
```

### 4.3 消息协议结构

```
UniFlowMessage {
    // 消息头
    header: {
        id:          string        // 唯一消息 ID
        type:        "command" | "event"
        from:        RoleType      // 发送方角色
        to:          RoleType[]    // 接收方角色（event 可多个）
        timestamp:   DateTime
        correlationId: string      // 关联 ID（用于追踪）
        traceId:     string        // 分布式追踪 ID
    }
    
    // 消息体
    body: {
        action:      string        // 动作名称
        payload:     any           // 业务数据
        context:     Context       // 上下文信息
    }
    
    // 元数据
    metadata: {
        priority:    number        // 优先级
        timeout:     number        // 超时时间（ms）
        retryPolicy: RetryPolicy   // 重试策略
    }
}
```
