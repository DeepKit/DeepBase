## 1. ThirdParty 扩展概述

### 1.1 什么是 ThirdParty 扩展

UniBase 的 `ThirdParty/` 目录存放**可选的第三方服务集成**，这些模块：

- 不是 UniBase 的核心功能
- 用户可以选择不使用，不影响 UniBase 主体
- 对接外部服务（云存储、支付网关、社交媒体等）

### 1.2 已有的扩展

| 目录 | 模块 | 说明 |
|------|------|------|
| `ThirdParty/DB/` | `UniBase.DB.PostgreSQL.pas` | PostgreSQL 驱动适配 |
| `ThirdParty/DB/` | `UniBase.DB.MySQL.pas` | MySQL 驱动适配 |
| `ThirdParty/UI/` | `UniBase.UI.Themes.pas` | UI 主题系统 |
| `ThirdParty/Cloud/` | `UniBase.Cloud.Storage.pas` | 云存储集成 (AWS/Azure/阿里云) |

### 1.3 计划中的扩展

| 目录 | 用途 | 状态 |
|------|------|------|
| `ThirdParty/Payment/` | 支付网关 (Stripe/PayPal/Alipay) | 🔲 待开发 |
| `ThirdParty/Social/` | 社交媒体 (WeChat/Weibo/Twitter) | 🔲 待开发 |

## 2. 开发新扩展前的检查

在开始开发新的 ThirdParty 扩展之前，请确认：

### 2.1 边界检查

- [ ] **这是对接外部服务**，而非应该成为 Core 的基础设施
- [ ] **用户可以选择不使用**，不影响 UniBase 核心功能
- [ ] **不与现有 Core 模块重复**（参考 [01.03 项目定位与边界](01.03.uniBase-4H-项目定位与边界-v1.0.md)）

### 2.2 可行性检查

- [ ] **有清晰的接口抽象**，便于支持多个提供商
- [ ] **维护成本可接受**（外部 API 变化不会频繁破坏兼容性）
- [ ] **有实际使用场景**（至少 2-3 个潜在用户/项目）

### 2.3 不适合放入 ThirdParty 的情况

- 应该成为 Core 功能的基础设施 → 考虑提 PR 到 Core
- 与特定业务强耦合 → 放在业务项目中
- 外部 API 极不稳定 → 等待 API 稳定后再集成
- 只有单一提供商 → 考虑是否需要抽象层

## 3. 标准架构模式

所有 ThirdParty 扩展应遵循**统一接口 + 多实现 + 工厂函数**的模式。

### 3.1 参考实现：云存储

以 `ThirdParty/Cloud/UniBase.Cloud.Storage.pas` 为例：

```
┌─────────────────────────────────────────────────────────────┐
│                    架构模式                                  │
│                                                             │
│   ICloudStorageClient (接口)                                │
│        ↑                                                    │
│   ┌────┴────┬────────────┬────────────┐                    │
│   │         │            │            │                    │
│ TAWSS3   TAzureBlob   TAliOSS    TMinIO                    │
│ Client    Client       Client    Client                    │
│                                                             │
│   CreateCloudStorageClient() ← 工厂函数                     │
│                                                             │
│   TCloudStorageHelper ← 高级封装 (可选)                     │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 核心组件

1. **统一接口** (`IXxxClient`)
   - 定义所有提供商必须实现的方法
   - 使用 GUID 标识接口

2. **基础实现类** (`TXxxClient`)
   - 提供通用逻辑和默认实现
   - 子类只需覆盖特定方法

3. **具体提供商类** (`TProviderXxxClient`)
   - 实现特定提供商的 API 调用
   - 处理认证、签名等细节

4. **工厂函数** (`CreateXxxClient`)
   - 根据配置创建对应的实现
   - 隐藏具体实现类

5. **Helper 类** (可选)
   - 提供高级封装和便捷方法
   - 如批量操作、目录同步等

## 4. 开发步骤

### 4.1 第一步：定义类型和接口

```pascal
unit UniBase.Payment.Types;

interface

type
  // 提供商枚举
  TPaymentProviderKind = (ppStripe, ppPayPal, ppAlipay);
  
  // 配置记录
  TPaymentConfig = record
    Provider: TPaymentProviderKind;
    ApiKey: string;
    SecretKey: string;
    Environment: (peSandbox, peProduction);
    // ... 其他配置
  end;
  
  // 请求/响应记录
  TPaymentRequest = record
    OrderId: string;
    Amount: Currency;
    Currency: string;
    // ...
  end;
  
  TPaymentResult = record
    Success: Boolean;
    TransactionId: string;
    ErrorCode: string;
    ErrorMessage: string;
    // ...
  end;

implementation
end.
```

### 4.2 第二步：定义统一接口

```pascal
unit UniBase.Payment.Core;

interface

uses
  UniBase.Payment.Types;

type
  IPaymentClient = interface
    ['{XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX}']
    
    // 核心操作
    function CreatePayment(const ARequest: TPaymentRequest): TPaymentResult;
    function GetPaymentStatus(const ATransactionId: string): TPaymentResult;
    function RefundPayment(const ATransactionId: string; AAmount: Currency): TPaymentResult;
    
    // Webhook 处理
    function HandleWebhook(const AHeaders, ABody: string): TPaymentResult;
  end;

// 工厂函数
function CreatePaymentClient(const AConfig: TPaymentConfig): IPaymentClient;

implementation
// ...
end.
```

### 4.3 第三步：实现基础类

```pascal
unit UniBase.Payment.Base;

interface

uses
  UniBase.Payment.Types,
  UniBase.Payment.Core,
  UniBase.Net;  // 使用 UniBase 的 HTTP 客户端

type
  TPaymentClientBase = class(TInterfacedObject, IPaymentClient)
  protected
    FConfig: TPaymentConfig;
    FHttpClient: THttpClient_;
    
    // 子类覆盖
    function BuildAuthHeaders: TArray<TPair<string, string>>; virtual; abstract;
    function GetApiBaseUrl: string; virtual; abstract;
  public
    constructor Create(const AConfig: TPaymentConfig);
    destructor Destroy; override;
    
    // IPaymentClient
    function CreatePayment(const ARequest: TPaymentRequest): TPaymentResult; virtual; abstract;
    function GetPaymentStatus(const ATransactionId: string): TPaymentResult; virtual; abstract;
    function RefundPayment(const ATransactionId: string; AAmount: Currency): TPaymentResult; virtual; abstract;
    function HandleWebhook(const AHeaders, ABody: string): TPaymentResult; virtual;
  end;

implementation
// ...
end.
```

### 4.4 第四步：实现具体提供商

```pascal
unit UniBase.Payment.Stripe;

interface

uses
  UniBase.Payment.Types,
  UniBase.Payment.Core,
  UniBase.Payment.Base;

type
  TStripePaymentClient = class(TPaymentClientBase)
  private
    function ParseStripeResponse(const AJson: string): TPaymentResult;
  protected
    function BuildAuthHeaders: TArray<TPair<string, string>>; override;
    function GetApiBaseUrl: string; override;
  public
    function CreatePayment(const ARequest: TPaymentRequest): TPaymentResult; override;
    function GetPaymentStatus(const ATransactionId: string): TPaymentResult; override;
    function RefundPayment(const ATransactionId: string; AAmount: Currency): TPaymentResult; override;
    function HandleWebhook(const AHeaders, ABody: string): TPaymentResult; override;
  end;

implementation

uses
  System.SysUtils, System.JSON, UniBase.Net;

function TStripePaymentClient.GetApiBaseUrl: string;
begin
  Result := 'https://api.stripe.com/v1';
end;

function TStripePaymentClient.BuildAuthHeaders: TArray<TPair<string, string>>;
begin
  SetLength(Result, 1);
  Result[0] := TPair<string, string>.Create('Authorization', 
    'Bearer ' + FConfig.SecretKey);
end;

function TStripePaymentClient.CreatePayment(const ARequest: TPaymentRequest): TPaymentResult;
var
  LResponse: THttpResponse;
begin
  // 实现 Stripe PaymentIntent 创建逻辑
  LResponse := Http.Request(GetApiBaseUrl + '/payment_intents')
    .Header('Authorization', 'Bearer ' + FConfig.SecretKey)
    .FormParam('amount', IntToStr(Round(ARequest.Amount * 100)))
    .FormParam('currency', ARequest.Currency)
    .Post;
    
  Result := ParseStripeResponse(LResponse.Body);
end;

// ... 其他方法实现

end.
```

### 4.5 第五步：实现工厂函数

```pascal
// 在 UniBase.Payment.Core.pas 中

function CreatePaymentClient(const AConfig: TPaymentConfig): IPaymentClient;
begin
  case AConfig.Provider of
    ppStripe:
      Result := TStripePaymentClient.Create(AConfig);
    ppPayPal:
      Result := TPayPalPaymentClient.Create(AConfig);
    ppAlipay:
      Result := TAlipayPaymentClient.Create(AConfig);
  else
    raise Exception.Create('Unsupported payment provider');
  end;
end;
```

## 6. 测试要求

### 6.1 必须提供的测试

1. **单元测试** (`Tests/Test.UniBase.{Category}.pas`)
   - 测试接口定义的所有方法
   - 使用 Mock 或 Sandbox 环境

2. **集成测试** (可选，使用真实 API)
   - 标记为需要网络/凭证
   - 不在 CI 中自动运行

### 6.2 测试模板

