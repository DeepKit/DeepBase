# DeepBase.BrowserAutomation 下游接入指南

## 概述

DeepBase 浏览器自动化模块为 Deep 系列产品（DeepCompare、Assayer 等）提供完整的浏览器驱动能力，覆盖：

- **基础动作执行**：Navigate / Click / Input / WaitForSelector / GetText / Screenshot 等 11 种动作
- **自然语言驱动**：通过 PageDriver（集成 Alibaba page-agent）实现 NL→DOM→Action
- **会话生命周期**：基于状态机的 ready/busy/recovering/crashed 等状态管理
- **响应等待**：基于 MutationObserver 的 DOM 稳定性检测（适合 LLM 流式输出）
- **浏览器恢复**：心跳监控、崩溃自愈、快照恢复
- **选择器自愈**：缓存 + 验证 + 自动发现降级
- **多窗口池化**：网格 / 横向 / 纵向 布局
- **视觉识别备选**：DOM 失败时截图 + LLM 视觉模型识别
- **CDP 异步策略**：完整的 Chrome DevTools Protocol 封装
- **WebView2 默认实现**：即插即用，下游无需自带浏览器代码

## 模块拓扑

```
DeepBase.BrowserAutomation         ← Phase 1 抽象（Action / Runner / Scripts）
  ├─ DeepBase.Browser.Types        ← 类型 / 接口 / 异常 / 辅助函数
```

## 最小接入（3 步）

### 步骤 1：选择后端

```pascal
uses
  DeepBase.Browser.Types,
  DeepBase.Browser.Registry,
  DeepBase.Browser.Engine.WebView2;  // 自动注册 WebView2 后端

procedure InitBrowser;
var
  LSession: IBrowserSession;
begin
  // 自动选择优先级最高的可用后端（默认 WebView2）
  LSession := TBrowserRegistry.CreateSession;
  TBrowserService.SetDefaultSession(LSession);
end;
```

后端注册是自描述的：每个引擎单元在 `initialization` 段调用 `TBrowserRegistry.Register`。下游可通过 `Disable` / `SetPriority` 调整选择策略。

### 步骤 2：执行动作（同步）

```pascal
uses
  DeepBase.BrowserAutomation;

var
  LRunner: TBrowserAutomationRunner;
  LResults: TArray<TBrowserAutomationResult>;
  LActions: TArray<TBrowserAutomationAction>;
begin
  // 复用 Phase 1 同步 Runner，无需改动现有调用代码
  // BUG-BA-024 fix: AsAutomationSession 现在直接返回强类型，不需要 as
  LRunner := TBrowserAutomationRunner.Create(
    TBrowserService.Session.AsAutomationSession,
    TBrowserAutomationPolicy.Default);
  try
    LActions := [
      TBrowserAutomationAction.Navigate('https://chat.openai.com'),
      TBrowserAutomationAction.WaitForSelector('textarea#prompt-textarea'),
      TBrowserAutomationAction.InputText('textarea#prompt-textarea', 'Hello'),
      TBrowserAutomationAction.Click('[data-testid="send-button"]'),
      TBrowserAutomationAction.Delay(500),  // BUG-BA-009 fix: 用 DelayMs 字段
      TBrowserAutomationAction.GetText('[data-message-author-role="assistant"]')
    ];
    LResults := LRunner.Run(LActions);
  finally
    LRunner.Free;
  end;
end;
```

### 步骤 3：处理响应（推荐使用 ResponseWaiter）

LLM 类应用建议用 `ResponseWaiter` 而不是固定 Sleep——它通过 MutationObserver 等 DOM 稳定 N 毫秒才认为响应完成：

```pascal
uses
  DeepBase.Browser.ResponseWaiter;

var
  LWaiter: TBrowserResponseWaiter;
begin
  LWaiter := TBrowserResponseWaiter.Create(TBrowserService.Session);
  try
    LWaiter.TimeoutMs := 120000;  // 总超时 2 分钟
    LWaiter.StableMs := 3000;     // 稳定 3 秒视为完成
    LWaiter.OnResult := procedure(R: TBrowserWaitResult; const Resp: string; D: Int64)
      begin
        case R of
          bwrSuccess: Logger.Info('LLM 回复完成: ' + Resp);
          bwrTimeout: Logger.Warn('LLM 响应超时');
        end;
      end;
    LWaiter.StartWaiting('[data-message-author-role="assistant"]', '.thinking');
  finally
    LWaiter.Free;
  end;
end;
```

## 进阶能力

### 浏览器恢复（自动崩溃自愈）

```pascal
uses
  DeepBase.Browser.Recovery;

var
  LRecovery: IBrowserRecovery;
begin
  LRecovery := BrowserRecovery;  // 单例
  TBrowserRecoveryManager(LRecovery).OnRecovery :=
    procedure(const ASessionId: TBrowserSessionId;
      AStrategy: TBrowserRecoveryStrategy; AAttempt: Integer;
      ASuccess: Boolean)
    begin
      // 由下游决定如何重建：reload / restart / recreate
      MyApp.RebuildBrowser(ASessionId);
    end;
  LRecovery.StartHealthMonitor;
end;
```

恢复策略自动按重试次数升级：`reload → restart → recreate`，超过 `MaxRetries`（默认 3）后停止。

### 自然语言驱动（PageDriver）

PageDriver 集成 [Alibaba page-agent](https://github.com/alibaba/page-agent) 实现自然语言→DOM 操作。不需要截图或多模态 LLM，page-agent 在页面内解析 DOM 树，调用文本 LLM，映射 NL 指令到具体操作。

**适用场景**：选择器不固定、UI 经常变动、或用户以自然语言描述操作目标时。

```pascal
uses
  DeepBase.Browser.PageDriver,
  DeepBase.Browser.Service;

var
  LDriver: IPageDriver;
  LResult: TPageDriverResult;
begin
  // 创建并配置 PageDriver
  LDriver := TPageDriver.Create;
  try
    // 注入 page-agent JS 到 WebView2 页面
    if not LDriver.Load(TBrowserService.Session.AsAutomationSession) then
    begin
      Logger.Error('PageDriver load failed: ' + TPageDriver(LDriver).LastError);
      Exit;
    end;

    // 用自然语言驱动浏览器
    if LDriver.Execute('点击页面上的登录按钮', LResult) then
      Logger.Info('操作成功')
    else
      Logger.Warn('操作失败: ' + LResult.ErrorMessage);
  finally
    LDriver.Unload;
  end;
end;
```

也可以通过 IoC 一行注册并自动注入：

```pascal
uses DeepBase.Browser.IoC;

var
  LConfig: TPageDriverConfig;
begin
  LConfig := TPageDriverConfig.Default;
  LConfig.Model := 'qwen3.5-plus';
  LConfig.Language := 'zh-CN';

  TBrowserIoCRegistration.RegisterAll(MyContainer, LConfig);
  // IPageDriver 已注册到容器，可直接 Resolve
end;
```

在 `TBrowserAutomationRunner` 中混编确定性动作与 NL 指令：

```pascal
var
  LRunner: TBrowserAutomationRunner;
begin
  LRunner := TBrowserAutomationRunner.Create(Session);
  LRunner.DriveCallback :=
    function(const AInstruction: string;
      out AValue: string; out AError: string): Boolean
    var
      LResult: TPageDriverResult;
    begin
      Result := LDriver.Execute(AInstruction, LResult);
      AValue := LResult.RawResponse;
      AError := LResult.ErrorMessage;
    end;

  LResults := LRunner.Run([
    TBrowserAutomationAction.Navigate('https://example.com/login'),
    TBrowserAutomationAction.WaitForSelector('form'),
    // 以下用自然语言代替硬编码选择器
    TBrowserAutomationAction.DriveInstruction('在用户名输入框中输入 admin'),
    TBrowserAutomationAction.DriveInstruction('在密码框中输入 mypassword'),
    TBrowserAutomationAction.DriveInstruction('点击登录按钮')
  ]);
end;
```

PageDriver 配置项：

| 配置 | 默认 | 说明 |
|---|---|---|
| `Model` | `qwen3.5-plus` | LLM 模型名 |
| `BaseURL` | 空（用 page-agent 默认） | OpenAI 兼容 API 地址 |
| `ApiKey` | 空 | LLM API Key（生产环境应从 Credential Manager 读取） |
| `Language` | `en-US` | 操作语言 |
| `MaxSteps` | 10 | 单次指令最大执行步数 |
| `TimeoutMs` | 120000 | 单次执行超时（毫秒） |
| `BundleUrl` | `cdn.jsdelivr.net/npm/page-agent@1.8.2/...` | page-agent JS 地址 |

> **注意**：PageDriver 需要目标页面能访问 BundleUrl（CDN）和 LLM API。内网环境需自托管 JS 文件并配置 `BaseURL` 指向内部 LLM 服务。

| 配置 | 默认 | 说明 |
|---|---|---|
| `Wait.TimeoutMs` | 60000 | Runner 总超时 |
| `Wait.PerCallTimeoutMs` | 5000 | EvaluateScript 单次超时（BUG-BA-001 fix） |
| `Wait.CheckIntervalMs` | 200 | 轮询间隔 |
| `Wait.StableMs` | 3000 | ResponseWaiter 稳定窗口 |
| `Recovery.MaxRetries` | 3 | 恢复最大重试 |
| `Recovery.HealthCheckIntervalMs` | 5000 | 心跳检查间隔 |
| `Recovery.UnresponsiveThresholdMs` | 30000 | 无响应阈值 |
| `Action.TimeoutMs = -1` | — | **无限超时**（BUG-BA-008 fix）。使用常量 `BROWSER_INFINITE_TIMEOUT` |

| 模块 | 用法 |

| `DeepBase.Resilience` | Recovery 内部已应用重试策略；下游可在 OnRecovery 中加入熔断逻辑 |

## 已知限制与最佳实践

1. **WebView2 单线程要求**：UI 事件必须在主线程，异步回调内部已用 `TThread.Queue` 切回主线程。
2. **截图 PNG 编码**：`CapturePreview` 使用 PNG，单帧约 100-500KB，高频截图需控制频率。
3. **CDP 命令的同步包装**：`CallDevToolsProtocol` 会阻塞主线程，请避免在 UI 回调里大量调用，需批量时考虑 `IBrowserSessionAsync`。
4. **选择器自愈的局限**：依赖目标页面有 `data-testid` / `aria-label` / `name` / `placeholder`，纯 className 类选择器自愈率较低。
5. **WindowPool 不会自动回收崩溃会话**：下游需在 OnRecovery 里主动 `Release` 失败的会话或 `ShutdownAll` 重启。

## 跟历史接口的兼容

Phase 1 的 `IBrowserAutomationSession` / `TBrowserAutomationAction` / `TBrowserAutomationRunner` 一律保留，新加的 `IBrowserSession` 接口提供 `AsAutomationSession` 方法返回 Phase 1 兼容包装。**老代码无需改动**。

新建议：

- 新代码请使用 `IBrowserSession` 接口（更完整的状态/错误回报）
- `Delay` 动作请用 `TBrowserAutomationAction.Delay(500)` 工厂，毫秒数走专属 `DelayMs` 字段（BUG-BA-009 修正）
- 需要无限等待时显式传 `BROWSER_INFINITE_TIMEOUT`（-1），不要靠 0 触发默认值

## 上线后调优 JS（ScriptStore，ISSUE-BA-101）

JS 模板不再硬编码在 Pascal 代码里。运行时通过 SQLite 表 `js_scripts` 加载，下游可以**在不重新编译 Delphi 的情况下**修改、回滚、A/B 测试 JS 注入逻辑。

### 内置脚本清单

| 名称（常量） | 占位符 | 作用 |
|---|---|---|
| `JSCRIPT_EXISTS` | `selector` | 检测 CSS 选择器是否匹配 |
| `JSCRIPT_CLICK` | `selector` | 点击元素 |
| `JSCRIPT_INPUT_TEXT` | `selector`, `text` | 设置 input/textarea 值 |
| `JSCRIPT_GET_TEXT` | `selector` | 取最后匹配元素的 innerText |
| `JSCRIPT_RESPONSE_WAITER` | `response_selector`, `loading_selector`, `timeout_ms`, `stable_ms` | MutationObserver 稳定性等待 |
| `JSCRIPT_WAITER_CANCEL` | — | 取消进行中的 waiter |
| `JSCRIPT_SELECTOR_HEAL` | — | 自动发现 data-testid / aria-label 等稳定 selector |

首次运行会自动建表 + Seed。后续部署只需 SQL 更新 `js_scripts.body` 字段（或通过 `Replace()` API）。

### 占位符语法

JS 模板用 `{{name}}` 标记占位符。`TJSTemplate.Render` 在 Pascal 侧把每个值用 `TJSONString.ToJSON` 包成合法 JS 字面量再替换：

| Pascal 类型 | 渲染产物 | 例子 |
|---|---|---|
| `string` | `"escaped string"` | `'hello'` → `"hello"` |
| `Integer` / `Int64` | 数字 | `5000` → `5000` |
| `Boolean` | JS 字面量 | `True` → `true` |
| `Extended` | `FloatToStr` | `3.14` → `3.14` |

字符串自动处理 `'` / `"` / `\` 转义，所以选择器可以放心写：

```pascal
ScriptStore.Render(JSCRIPT_EXISTS,
  ['selector', '[data-name="x''y"]']);
// → '(function(){try{return document.querySelector("[data-name=\"x''y\"]")...'
```

### 修改一个内置脚本

```pascal
uses DeepBase.Browser.ScriptStore;

procedure UpdateClickScript;
var
  LScript: TJSScript;
begin
  LScript := Default(TJSScript);
  LScript.Name := JSCRIPT_CLICK;
  LScript.Version := 2;
  LScript.Body :=
    '(function(){' +
    '  var el = document.querySelector({{selector}});' +
    '  if (!el) return {success:false};' +
    '  el.dispatchEvent(new MouseEvent("click", ' +
    '    {bubbles:true, cancelable:true}));' +  // 新版用合成事件
    '  return {success:true};' +
    '})();';
  LScript.Description := 'Click via synthetic MouseEvent (v2)';
  LScript.Placeholders := ['selector'];
  LScript.IsActive := True;

  ScriptStore.Replace(LScript);
  // 立即生效；下一次 BrowserAutomationRunner 取脚本时拿到新版本
end;
```

### 推荐工作流

```
开发期：把 JS 写在 Pascal 单元里（用作 Seed 默认）
   ↓
集成期：DeepBase 第一次启动自动 Seed 到 js_scripts 表
   ↓
生产期：DBA / 运维通过 SQL 或 admin 工具修改 body 字段
   ↓
应用调用 ScriptStore.Reload 即时刷新（或重启进程）
```

> 安全提示：`js_scripts` 表内容会被注入到浏览器执行。不要让不可信的人写入。

### 注册到 Recovery 实现自动重建闭环（BUG-BA-025 修复）

```pascal
uses
  DeepBase.Browser.Recovery,
  DeepBase.Browser.Service;

procedure WireRecovery;
var
  LRecovery: TBrowserRecoveryManager;
begin
  LRecovery := TBrowserRecoveryManager(BrowserRecovery);

  LRecovery.SessionFactory := TMyEngineFactory.Create;

  LRecovery.OnSessionRebuilt :=
    procedure(const AOldSessionId: TBrowserSessionId;
      const ANewSession: IBrowserSession)
    begin
      // 重建成功 → 替换 Service 默认会话
      TBrowserService.SetDefaultSession(ANewSession);
      // 把快照应用回新会话
      var LSnap := LRecovery.GetSnapshot(AOldSessionId);
      if LSnap.Url <> '' then
      begin
        var LErr: string;
        ANewSession.Navigate(LSnap.Url, 30000, LErr);
      end;
    end;

  LRecovery.StartHealthMonitor;
end;
```

```pascal
uses DeepBase.Browser.IoC;
```

## WebView2 异步并发

`TWebView2BrowserSession` 实现了 `IBrowserSessionAsync` 接口（BUG-BA-014 修复后线程安全）：

```pascal
uses System.Threading, DeepBase.Browser.Engine.WebView2;

procedure ParallelEvaluate;
var
  LAsync: IBrowserSessionAsync;
  LTaskA, LTaskB: ITask;
begin
  LAsync := TBrowserService.Session as IBrowserSessionAsync;

  // 并发触发，互不污染（per-call CDP routing 已修）
  LTaskA := LAsync.EvaluateScriptAsync(
    'document.title', 5000,
    procedure(S: Boolean; const Result, Err: string)
    begin
      Logger.InfoFmt('Title: %s', [Result], 'App');
    end);

  LTaskB := LAsync.EvaluateScriptAsync(
    'document.location.href', 5000,
    procedure(S: Boolean; const Result, Err: string)
    begin
      Logger.InfoFmt('URL: %s', [Result], 'App');
    end);

  TTask.WaitForAll([LTaskA, LTaskB]);
end;
```

注意事项：

- 回调通过 `TThread.Queue` 切回主线程，可以直接操作 UI
- `Navigate` 会真正等待 `NavigationCompleted`（BUG-BA-021 修复），不再 fire-and-forget
- 多个并发 CDP 调用通过 `AExecutionId` 路由到独立的 pending entry；不共享 event/result（BUG-BA-014 修复）

## 健康检查清单（生产部署前）

- [ ] 数据库迁移：第一次启动会自动建 `js_scripts` 表，确认 DB.Factory 配置好
- [ ] 内置脚本 Seed：`SELECT count(*) FROM js_scripts` 应 ≥ 7
- [ ] 后端注册：`TBrowserRegistry.Discover(True)` 至少返回一个可用后端
- [ ] Recovery 阈值：根据生产环境调整 `UnresponsiveThresholdMs`、`HealthCheckIntervalMs`
- [ ] WebView2 用户数据目录：`InitializeWebView2('C:\YourApp\Browser')` 显式指定，避免和其它进程争 lock
