# 权限裁决契约 v1

- 代码实现：`Core\DeepBase.Gate.Verdict.pas`（类型定义唯一真相源）
- 法源：WO-20260919-AUDIT-甲 A6；总报告 T1 fail-closed 家族

## 裁决类型

| 成员 | 枚举序 | 语义 | IsApproved |
|---|---|---|---|
| `gdRejected` | 0 | 拒绝（缺省值） | False |
| `gdApproved` | 1 | 放行 | True |
| `gdIndeterminate` | 2 | 不可判定（不放行，仅审计归因） | False |

## Fail-Closed 设计原理

`gdRejected` 保持枚举序 0，使得：
- `default(TGateVerdict)` → gdRejected
- `FillChar(V, SizeOf(V), 0)` → gdRejected
- 任何未显式赋 Approved 的路径 → 天然拒绝

**语言级保证**，不依赖运行时检查。

## 调用侧契约

1. 门禁函数返回 `TGateVerdict`，调用侧**以 `IsApproved` 为唯一放行判据**。
2. `gdIndeterminate` 不等于豁免——`IsApproved` 恒 False，不得据此放行。
3. 缺字段 / 未知算法 / 校验异常 → 必须 `Rejected`。
4. 校验能力不可用（如签名基线缺失）→ `Indeterminate`。

## 兼容层

`class operator Implicit(TGateVerdict): Boolean` 允许旧代码 `if GateFunc(...) then` 继续编译，但语义等价 `IsApproved`。新代码推荐显式 `.IsApproved`。

## 编码纪律

- `.pas` 文件必须 UTF-8 with BOM（`EF BB BF`）或纯 ASCII。
- 非 ASCII 字符串不得出现在未类型化 `Exit()` 实参位（W1057）。
- 经 `const AReason: string` 形参传递不受影响。
