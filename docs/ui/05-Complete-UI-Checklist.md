# UniBase 完整 UI 界面清单与设计规范

本文档列出 UniBase 框架中所有需要设计和实现的 UI 界面。

---

## 📋 完整界面清单

### 第一类：应用程序集成界面

#### 1.1 主应用界面集成
- **主窗体** - 集成 UniBase 的应用主窗口
  - 菜单栏（使用 TI18nMenuItem）
  - 工具栏（按钮、快捷键提示）
  - MRU 菜单（文件 → 最近打开）
  - 状态栏（显示 App 语言、主题）
  - 主体工作区

#### 1.2 设置 / 偏好设置界面
- **常规设置**
  - 语言选择（TLanguageComboBox）
  - 主题选择（TThemeComboBox）
  - 调试模式开关
  - 自动更新设置

- **高级设置**
  - 日志级别选择
  - 日志保留天数
  - 缓存大小配置
  - 性能参数调整

---

### 第二类：i18n 国际化界面

#### 2.1 语言管理界面
- **语言列表对话框**
  - 支持的语言列表（TreeView 或 Grid）
  - 语言名称、本地名称、启用状态
  - 添加/删除/编辑按钮
  - 设置默认语言

#### 2.2 翻译编辑界面
- **翻译文本编辑器**
  - 原文本（只读）
  - 各语言翻译输入框（标签页或并排）
  - 上下文说明（帮助翻译）
  - 复数形式编辑
  - 是否人工校验复选框
  - 保存/下一条/上一条按钮

- **批量翻译对话框**
  - 选择待翻译语言
  - 选择翻译提供商（LiteLLM、Google 等）
  - 进度条
  - 预览翻译结果
  - 确认/取消按钮

---

### 第三类：LLM 管理界面（新增）

#### 3.1 LLM 参数配置界面（上半部分）
- **LLM 配置面板**
  - LLM 启用开关（Enable/Disable）
  - Provider 下拉框（LiteLLM、OpenAI Direct、Local 等）
  - API 地址输入框（URL）
  - API Key 输入框（密码输入，显示/隐藏按钮）
  - Model Name 下拉框（根据 Provider 动态填充）
  - Timeout 时间设置（毫秒）
  - Temperature 滑块（0.0 - 2.0）
  - Max Tokens 输入框
  - 成本参数
    - Input Price per 1K tokens
    - Output Price per 1K tokens
  - 并发限制数值框
  - 重试策略（次数、延迟）
  
- **测试连接按钮**
  - 点击后显示加载动画 + 响应时间
  - 成功/失败提示
  - 显示返回的模型信息

#### 3.2 LLM 调用记录 Grid（下半部分）
- **LLMCalls 数据网格**
  - 时间戳
  - Provider / Model 名称
  - 调用方标识（Caller）
  - 持续时间（ms）
  - Input Tokens / Output Tokens
  - 状态（Success/Failed）
  - 估算费用
  - 操作列（查看详情、删除）
  
- **Grid 功能**
  - 排序、筛选、搜索
  - 按日期范围筛选
  - 按 Provider 筛选
  - 成本统计（总费用、平均费用）
  - 导出为 CSV/Excel

---

### 第四类：等待和加载界面（新增）

#### 4.1 LLM 等待界面（关键新增）
- **等待窗体**
  - 位置：居中或右下角浮窗
  - 大小：400×200 像素（推荐）
  - 内容结构：
    - **上部**：动画区域
      - SVG 动画（从 AnimationAssets 中随机选择）
      - 自动播放、循环
      - 常见动画：旋转加载器、脉冲、跳动等
    - **中部**：提示文本
      - 主消息（"正在使用 LLM..."）
      - 副消息（动态更新，显示当前操作）
      - 进度百分比（可选，如果 LLM 支持流式输出）
    - **下部**：操作按钮
      - 取消按钮（允许中断 LLM 调用）
      - 后台运行按钮（最小化等待窗）
  
- **样式**
  - 半透明遮罩背景（可选）
  - 圆角窗体
  - 无标题栏或简洁标题栏
  - 模态对话框（阻塞用户交互）

#### 4.2 通用等待对话框（TWaitForm）
- **通用等待窗体**（已在控件中定义）
  - 支持自定义消息
  - 支持进度条（0-100% 或不确定模式）
  - 支持取消按钮
  - 自动关闭或手动关闭

#### 4.3 后台任务通知栏
- **系统托盘/通知栏**
  - 长时间运行的 LLM 任务显示进度
  - 完成时弹出通知
  - 错误时显示错误提示

---

### 第五类：日志和异常界面

#### 5.1 日志查看器
- **日志表格**
  - 时间戳、级别、来源、消息
  - 颜色编码：DEBUG=灰、INFO=蓝、WARN=黄、ERROR=红、FATAL=紫
  - 排序、筛选、搜索功能
  - 详情预览（展开行查看完整信息）

- **日志控制**
  - 日志级别过滤
  - 时间范围选择
  - 导出为 TXT/CSV/JSON
  - 清空日志按钮
  - 自动刷新 On/Off

#### 5.2 异常报告界面
- **异常列表**
  - 异常类型、消息、发生时间
  - 涉及的窗体、用户操作
  - 处理状态（未处理/已处理/已忽略）
  
- **异常详情**
  - 完整堆栈跟踪（可复制）
  - 系统信息（OS 版本、内存等）
  - 应用版本
  - 处理备注编辑框
  
- **操作**
  - 标记为已处理
  - 生成报告并上传
  - 导出诊断信息包
