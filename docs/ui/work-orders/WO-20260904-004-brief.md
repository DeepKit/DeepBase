- **任务范围**：
  - **Task A**: 遥测持久化驱动

    - Core 包定义 `IHbSnapshotProvider` 快照契约（Capture/Restore JSON 协议）。
    - Persistence 层提供 `hb_snapshots` 表存储管理，支持 7 天过期清理与任务完成后主动清除。

  - **Task C**: 测试覆盖与性能守护
    - 新建 `Tests\Test.DeepBase.HB.Persistence.pas`，覆盖持久化三路径、WAL 断言、快照恢复全流程。
