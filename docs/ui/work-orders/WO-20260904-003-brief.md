## 1. 目标与范围 (Objective & Scope)
- **核心目标**：彻底消除 HB 界面及分享卡中文渲染时由于 Segoe UI 无中文字形导致的 GDI+ 静默回退宋体（SimSun）问题，全库统一切换为 `Microsoft YaHei UI` 并建立三级运行时可用性回退链。
- **任务范围**：
  - **A1**: `Core/DeepBase.HB.Core.pas` Token 默认字体切换为 `'Microsoft YaHei UI'`，并实现 `'Microsoft YaHei UI'` → `'Microsoft YaHei'` → `'Segoe UI'` 三级探测回退与缓存机制。
  - **A2**: 全库扫描并消除硬编码字体名残留（`DeepBase.VCL.HB.Gate.pas`、`DeepBase.VCL.HB.VirtualList.pas`），保证 Token 单一真相源。
  - **A3**: 提供真实环境视觉验证窗体/用例，覆盖中英文混排、六档字号 (SizeXS..SizeXXL) 与 125%/150% DPI 渲染验证，产出截图与证据。
