## 一、派发依据（主控实测，非转述）

**甲 R7-P3 报「卡死在 HB Gate #5」**，主控在**静默窗口独立复跑两次**，结论**更正**如下：

| Gate | 隔离跑耗时 | 指标（阈值） | 判定 |
| :--- | ---: | :--- | :---: |
| Gate1 | 8.6 s | P95 **476.29 ms**（≤800） | **PASS** |
| Gate2 | 4.2 s | 4.160 ms（≤16.6） | PASS |
| Gate3 | 0.37 s | ≤6.98 ms（≤100） | PASS |
| Gate4 | 0.46 s | Step2 13.189 ms（≤30） | PASS |
| Gate5 | **82 s** | step181 **19.808 ms**（≤16.6） | **FAIL** |
| **Gate6** | **> 5 min 未完**（被 400 s 超时 kill，`EXIT=124`） | —（`C_GATE6_INSTANCES = 10000` × 2 轮） | 未跑完 |

- **Gate5 单跑**另一次实测 **PASS（Worst 14.248 ms）** ⇒ 同一环境两次结果跨 16.6 ms 阈值 ⇒ **阈值处噪声翻转（真 flaky 门禁）**。
- **更正后的根因**：「全量套件裸跑卡死」= **Σ(各 Gate 固有时长) × 并发争用系数（≈3–10×）**，超出人工观察窗后被误判挂死。
  - **真正的长尾是 Gate6**（2 万次窗口创建/销毁），**非**甲所报的 Gate5；
  - 甲现场日志的 **Gate1 FAIL（1315 ms）系并发争用**（隔离跑 PASS 476 ms），非「虚显环境固有」；
  - 日志停在 Gate5 BEGIN = **杀进程时恰处于 Gate5**，非 Gate5 不可完成。
- **复跑原始输出**（主控亲跑，永久留证）：`CodeReview/20260921-AUDIT-主控-甲-R7-P3-证据/`。

## 二、任务清单（按质量影响排序）

### P1｜**分离**：HB 性能基准从快速门禁移出，作为独立、串行、独占的长超时作业

- **目标**：**全量裸跑 / 快速门禁**不再包含 `Test.DeepBase.HB.Benchmark` 整组；另设**独立的性能作业**运行它。
- **要求**：
  - 独立作业**串行、独占**运行（不与重负载会话/其他测试并发；由主控在调度层给独占窗口）；
  - **长超时**（须覆盖 Gate1–Gate6 完整时长；基线：隔离下 Gate6 单跑 >5 min，整组 >6.5 min）；
  - 机制建议：DUnitX 类别标记 + 运行脚本（`--exclude` 默认裸跑 / `--include` 性能作业）。
- **禁**：把「分离」做成「不跑」。

### P2｜**Gate5 抖动修复**（真缺陷，须修）

- 现象：同一环境两次 **14.248 ms（过）/ 19.808 ms（不过）**，跨 16.6 ms 阈值。
- 要求：复核**统计口径**（现为「每步 min-of-3 × 500 步取 Worst」），给出**可复现的稳定判定**。
- **禁调阈值** —— 承 `WO-20260905-003-HB-GATE5-RESIZE-FIX` 明文纪律：「严禁调大阈值迁就，必须从渲染路径定位根因」。
- 若根因确在渲染路径（脏矩形裁剪/双缓冲/擦除抑制）⇒ 属 **VCL 测试源码**，见 §三 域边界。

### P3｜**Gate6 保持全规模**

- `C_GATE6_INSTANCES` 仍须 = **10000**（×2 轮）；**仅**把它归入长跑作业。
- **禁降规模**（降规模会削弱其 GDI/堆泄漏检出能力 = 质量覆盖削减）。

### P4｜**禁止项（违反即 REJECT）**

- 禁 env 豁免 / 静默跳过 / 降采样掩盖 / 以长超时掩盖 flaky。
- 若确需「环境不适用时跳过」，**须**登记：跳过项 + 原因 + 替代验证 + 风险，且须主控批准（本单**不预设**跳过）。
