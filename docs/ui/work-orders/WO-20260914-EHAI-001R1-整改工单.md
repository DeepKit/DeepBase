### R-03 · 公共层 `Covers()` 改 fail-closed【MAJOR · 阻塞 AXIS】

**问题（终审 M-01）**：`Core\DeepBase.EHAI.Types.pas:335-348`：

```pascal
if (ScopeBoundary <> '') and (ScopeBoundary <> '*') and
   (SameText(ScopeBoundary, AScope) = False) then Exit(False);
```

`ScopeBoundary` 为空字符串时**跳过范围校验直接放行**；`CeilingAmount = 0` 时**跳过额度校验**。即 `CreateStanding(holder, '', '', 0, 0)` 得到一份"覆盖一切、永不过期"的授权。AXIS 的 `DeepAxis.Binding.EHAI.pas:464` 正是此函数的调用方——**公共层的宽松语义已构成跨产品安全缺口**（契约 §3.2 要求"产生不可逆承诺必须满足适用的授权与边界要求"，空 Scope 放行与之相反）。

**精确修改点**：`Core\DeepBase.EHAI.Types.pas` 第 335–348 行（`TEhaiAuthorityBasis.Covers`）

**改法**：空 Scope 一律 **fail-closed**：

```pascal
if ScopeBoundary = '' then Exit(False);   // 空 Scope = 无授权，而非通配
```

放在 `IsValidAt(Now)` 检查之后、`'*'` 判断之前。`'*'` 通配语义可保留，但**必须要求显式书写**；`CeilingAmount = 0` 保持"无额度约束"语义，并在 R-00 符号基准中写明该约定。

> 说明：这是**实现层符合性修正**，不是契约语义变更，不需要 Reopen Common Contract。

**验收标准**：

- ✅ 新增 CSV-008 负向断言：空 Scope 的 Standing 授权 `Covers(<任意>)` 返回 `False`；
- ✅ 新增断言：`Covers` 对已过期授权返回 `False`；
- ✅ 原 CSV-008 正向断言仍全绿（不回归）。

**证据要求**：`Tests\Test.DeepBase.EHAI.Conformance.pas` 的断言 diff + 运行日志。
