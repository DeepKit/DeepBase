## 1. 目标与范围 (Goal & Scope)
- **目标**：从零实施 HB 行为层核心契约、运行时生命周期管线、触点登记与分级采样引擎。
- **包含范围**：
  1. Core/DeepBase.HB.Touchpoint.Types.pas（IHbTouchpoint, TTouchEvidence, TMetricDefinition, THbTouchpointLevel）；
  2. Core/DeepBase.HB.StateSlot.Types.pas（IHbStateSlotProvider 零业务枚举）；
  3. Core/DeepBase.HB.Runtime.pas（THbRuntime.RegisterStateSlot 注册审计与 EHbLifecycleViolation）；
  4. Core/DeepBase.HB.Touchpoint.Engine.pas（THbTouchpointRegistry, TRingBuffer<TTouchEvidence> 10000 缓冲，三级分级采集与 Grid 聚合）；
  5. VCL/DeepBase.VCL.HB.Controls.pas（THbCustomControl 7 步生命周期、Paint 前置断言、Dispose 幂等、THbButton 试点）；
  6. VCL/DeepBase.VCL.HB.Dialogs.pas（THbDialog 确认按钮 tlCritical 试点）；
  7. Tests/ 落地 C1 契约与反污染测试、C2 生命周期与异常断言测试、C3 10万行写入延迟 P95 ≤ 2ms 基准测试。
- **明确排除**：SQLite/WAL 磁盘持久化、FMX 端生命周期改造、第 1–6 项视觉性能基准。
