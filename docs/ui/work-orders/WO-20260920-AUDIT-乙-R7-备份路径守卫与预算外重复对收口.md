## 二、任务清单

### P1【CloudBackup 归档落盘无目标守卫 —— 同名重复备份失败】

**现状（主控实测，`Features/DeepBase.CloudBackup.pas:1935-1939`）**：
```pascal
else
begin
  LArchivePath := TPath.Combine(FConfig.LocalBackupPath, LBackupId + '.zip');
  TFile.Move(LTempPath, LArchivePath);   // :1938 无目标守卫
end;
```
目标路径固定为 `<LocalBackupPath>/<LBackupId>.zip`。`TFile.Move` 在**目标已存在**时抛 `ERROR_ALREADY_EXISTS`（与 M2 keystore 事故同机理）⇒ **非加密备份路径**下，同一 `LBackupId` 二次备份**直接失败**。（注：`if Assigned(FEncryptor)` 分支的 `TFile.Delete` 删的是**源** `LTempPath`，**不构成**对目标 `LArchivePath` 的守卫。）

**同型正确实现（已修，可对齐）**：
- `Core/DeepBase.AutoFix.HealthSignal.pas:160-161`：`if TFile.Exists(LPath) then TFile.Delete(LPath); TFile.Move(LTmpPath, LPath);`
- `Persistence/DeepBase.DB.Guardian.pas:305-306`
- `Core/DeepBase.KeyManager.pas:735-740`（含注释说明 `ERROR_ALREADY_EXISTS` 语义）

**改法**：
1. 目标存在时先 `TFile.Delete` 再 `Move`（或改覆盖语义），与上述同型实现一致；
2. **同法核**加密分支 `FEncryptor.EncryptFile(LTempPath, LArchivePath)`：若该分支在目标已存在时亦失败/行为不一致，一并校正；
3. **质量优先（H8）**：不得以「正常流程不会重复备份」为由保留缺陷。

**验收**：新增或复用测试覆盖「同 `LBackupId` 二次备份」并**真跑通过**（附 NUnit XML）；源码中无未守卫的 `TFile.Move`。
