## 根因（已主控定位，无需重复诊断）

`D:\_Progs\02Business\DeepBase\Core\DeepBase.HB.Core.pas` 第 345 行：
`Result.FontFamily := 'Segoe UI';`

Segoe UI 无中文字形，GDI+ 绘制中文时静默回退宋体（SimSun）→ 点阵感、笔画细、小字号发虚。
VCL GDI+ 全部绘制与 FMX `Canvas.Font.Family` 均引用 `Tokens.FontFamily`，改 Token 默认值即全库生效。

## 任务

- `Core\DeepBase.HB.Core.pas`：`FontFamily` 默认值 `'Segoe UI'` → `'Microsoft YaHei UI'`

- 新增运行时可用性回退链（Theme 初始化时一次解析，结果缓存）：
  `'Microsoft YaHei UI'` → 不可用则 `'Microsoft YaHei'` → 再不可用回 `'Segoe UI'`
  （解析用 GDI+ `TGPFontFamily.Create` 探测或 `Screen.Fonts` 查询，实现取最简）

- 回退结果经现有 Theme 变更广播通知控件刷新，不新增广播机制

- 按规范 §4 Token 治理：默认值变更登记为 Token Minor 变更（无属性删除，无废弃期义务）

### A2 渲染路径核查（确认无第二真相源）

- ShareCard PNG 导出（`VCL\DeepBase.VCL.HB.ShareCard.pas`）必须走 Token（导出图片同样不能出现宋体回退）
