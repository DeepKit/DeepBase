## 一、修单与判据

### B13-01：`PaymentBridge.pas` 的 `PaidAtISO` 写出口

**代码事实**：`Features/DeepBase.Commerce.PaymentBridge.pas`（按符号 `TSDKNotificationVerifier`/通知转换过程定位，修前行号线索 `:261`）

```pascal
if SDKNotif.PaidAt > 0 then
  Result.PaidAtISO := DateToISO8601(SDKNotif.PaidAt, False)
```

**缺陷**：`AUTCDate=False` 的 RTL 语义是「数值原样 + 本地偏移后缀、不换算」（B10-1 探针实测、B10 验收结论 §二.3 认定）。当入参 `SDKNotif.PaidAt` 是**本地裸值**时它正确；当入参是 **UTC 裸值**时它指向比本意早一个偏移量的瞬时。B10 实测三个第三方桥里 `PayPal.pas:574/810` 填的是本地裸值 `Now`（`DeepBase.Payment.pas:374/429` 填 0），Stripe/WeChatPay 侧**未经证明**——跨域输入框架不齐时，这里等于把一种混用换成另一种。

**修法**：**先枚举后修**（B10 同范，不得只改工单点名处）——把 `ThirdParty/Payment/**` 所有 `PaidAt` 赋值点的框架逐点分类（本地裸值 / UTC 裸值 / 线格式往返），形成表格；然后依分类定 `PaidAtISO` 写出口的框架：**输入统一为本地裸值 ⇒ 写出口用 `TTimeZone.Local.ToUniversalTime(SDKNotif.PaidAt)` 再 `DateToISO8601(..., True)`**（与 wire convention 对齐，对任何偏移都自洽）；若枚举发现某桥只能是 UTC 裸值 ⇒ 停机上报主控裁定（不许自行选一边）。
**判据**：① 枚举表逐点分类闭环、无「未定」格；② 单测（新增于已注册 fixture 或既有单元，全限定）以 `SetNowFunc` 注入假时钟驱动 PayPal 通知转换，断言 `PaidAtISO` 往返回同一 UTC 瞬时（毫秒级）；③ 反事实：换回 `DateToISO8601(SDKNotif.PaidAt, False)` 必须变红；④ `PaidAtISO` 在 Commerce 域仍不参与判定（B10 验收结论 §二.7 认定）——只改写出口框架，**不得**顺手让它进入判定链。

### B13-02：`ThirdParty/Payment/DeepBase.Payment.Stripe.pas` 的 `expires_at`

**代码事实**：修前行号线索 `:300`（`CreateCheckoutSession`），形态 `DateTimeToUnix(Now + minutes/1440)`；佐证 `docs/evaluation/08-commerce-payment-integration.md:106`（P3）与 `:240`（S8 Medium）。
**缺陷**：Stripe API 的 `expires_at` 是 **UTC Unix 时间戳**，而 `Now` 是本地裸值 ⇒ 非 UTC 部署下过期时间偏差本机偏移量（UTC+8 上差 8 小时）。
**修法**：改 `DateTimeToUnix(TTimeZone.Local.ToUniversalTime(Now) + minutes/1440)`；若该文件已有 UTC 取值惯例则照仓内同形写。
**判据**：① 修后 `expires_at` 与 `TDeepBaseTimeSource.Shared.Now` 注入值经 UTC 换算后相等（现有 fixture 或新用例，全限定）；② 反事实：换回裸 `Now` 必须变红；③ 不改其余字段语义。

### B13-03：`ThirdParty/Payment/DeepBase.Payment.WeChatPay.pas` 的 `time_expire`

**代码事实**：修前行号线索 `:731`，形态「本地时间 + 固定 `+08:00` 偏移」；佐证 `docs/evaluation/08-commerce-payment-integration.md:67`（P3）。
**缺陷**：把「本机时区」硬编码为 `+08:00`——负偏移机器上 `time_expire` 指向错误瞬时；且本地时间与固定偏移拼接本身就不是 UTC 框架。
**修法**：按微信支付官方要求显式转 **UTC+8（`Asia/Shanghai`）**：`TTimeZone.Local.ToUniversalTime` 取 UTC 后再 `IncHour(...,8)`，或用 RTL 的 `TTimeZone.Create('Asia/Shanghai')` 换算（**先 rg 仓内有无既有惯例**，有则照同形写；两案均须在回执说明选型理由）。**不得**保留「本机本地 + 固定 +08:00」的拼接。
**判据**：① 单测以假时钟注入，断言 `time_expire` 字符串 = 注入瞬时的 Asia/Shanghai 表示（不随本机时区变）；② 反事实：换回本机本地 + 固定偏移必须变红；③ 错误/请求体其余字段不变。
