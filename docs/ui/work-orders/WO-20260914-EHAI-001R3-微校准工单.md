## 四、关于重复文档，不按“物理重复即违规”处理

不得因为存在两个字节相同文件就机械删除历史 evidence。

首先确认其角色。

若：

```text
docs/... 
= authoritative document
```

而：

```text
TestResults/...
= evidence snapshot
```

则允许物理并存。

但必须在 evidence index / manifest 中明确：

```text
NON-AUTHORITATIVE EVIDENCE SNAPSHOT
Source:
Source Commit:
SHA256:
```

确保：

```text
Authority Uniqueness
≠
Physical File Uniqueness
```

只有确认 TestResults 中的文件完全没有证据价值、且删除不会破坏历史审计可恢复性时，才允许删除。

不得为了“目录漂亮”破坏 evidence lineage。
