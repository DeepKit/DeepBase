# 03. 数据库与查询指南

> 本文档整合了 PostgreSQL 业务数据库指南和 doQry 查询框架使用说明。

---

## 1. PostgreSQL 业务数据库

> 本节适用于**业务数据库**设计。本地配置使用 UniBase 的 `config.db` (SQLite)。

### 1.1 数据库优先架构

UniBase 推崇"胖数据库"模式，充分利用 PostgreSQL 原生能力：

- **应用层 (Delphi)**：UI 交互、简单输入验证、调用数据库接口
- **数据库层 (PG)**：复杂查询、数据一致性、全文搜索、消息队列

### 1.2 推荐 PG 特性

#### JSONB - 灵活数据存储

```sql
CREATE TABLE user_profiles (
    user_id SERIAL PRIMARY KEY,
    preferences JSONB DEFAULT '{}'::jsonb
);

SELECT * FROM user_profiles WHERE preferences->>'theme' = 'dark';
```

#### 全文搜索

```sql
ALTER TABLE products ADD COLUMN search_vector tsvector;

CREATE TRIGGER tsvectorupdate BEFORE INSERT OR UPDATE
ON products FOR EACH ROW EXECUTE FUNCTION
tsvector_update_trigger(search_vector, 'pg_catalog.english', title, description);

SELECT title FROM products WHERE search_vector @@ to_tsquery('apple & phone');
```

#### 消息队列 (SKIP LOCKED)

```sql
DELETE FROM task_queue
WHERE id = (
    SELECT id FROM task_queue
    WHERE status = 'pending'
    FOR UPDATE SKIP LOCKED
    LIMIT 1
)
RETURNING *;
```

#### 实时通知 (LISTEN/NOTIFY)

```sql
NOTIFY channel_order_update, 'order_id=123';
```

Delphi 端使用 `TFDEventAlerter` 接收通知。

### 1.3 连接与事务管理

```pascal
// 显式事务管理
FDConnection1.StartTransaction;
try
  // 业务逻辑...
  FDConnection1.Commit;
except
  FDConnection1.Rollback;
  raise;
end;
```

### 1.4 推荐扩展

| 扩展名 | 用途 |
|--------|------|
| `uuid-ossp` | 生成 UUID |
| `pg_trgm` | 模糊搜索优化 |
| `pgcrypto` | 加密函数 |
| `zhparser` | 中文分词 |

## 2. doQry 查询框架

### 2.1 概述

`UniBase.DB.DoQry` 是统一的数据访问门面，提供：

- **统一**：标准化上下文、事务、执行、日志
- **安全**：参数化优先 + 治理策略（禁无 WHERE、默认 LIMIT）
- **高效**：查询模板热更新、Returning 减少往返
- **可观测**：JSON 日志 + CorrelationId 全链路追踪

### 2.2 快速开始

```pascal
uses UniBase.Manager, UniBase.DB.DoQry, FireDAC.Comp.Client;

var
  Conn: TFDConnection;
  Ctx: TDoQryContext;
  Data: TClientDataSet;
begin
  // 1. 初始化
  UniBase.Initialize;
  DoQryInit(UniBase.RootPath);

  // 2. 建立连接
  Conn := TFDConnection.Create(nil);
  Conn.DriverName := 'PG';
  Conn.Params.Values['Server'] := '127.0.0.1';
  Conn.Params.Values['Database'] := 'mydb';
  Conn.Connected := True;

  // 3. 创建上下文
  Ctx := DoQryMakeContext(Conn, dbPostgreSQL, 30, DoQryNewCorrelationId);

  // 4. 执行查询
  var NewId := DoQryExecInsertReturningId('texts.insert',
    '{"user_id":2,"title":"示例","status":"pending"}', Ctx);

  var Rows := DoQryExecSelect('texts.list', '{"page":1,"size":50}', Data, Ctx);
end;
```

### 2.3 公开 API

```pascal
// 初始化
procedure DoQryInit(const ProjectRoot: string);
function DoQryMakeContext(Conn: TFDConnection; DBType: TDBType; 
  TimeoutSec: Integer; const CorrelationId: string): TDoQryContext;
function DoQryNewCorrelationId: string;

// 事务
function DoQryBeginTx(const Ctx: TDoQryContext): IDoQryTx;
procedure DoQryRunInTx(const Ctx: TDoQryContext; const Proc: TProc);

// 执行
function DoQryExecSelect(const Proc, ParamsJson: string; 
  var Data: TClientDataSet; const Ctx: TDoQryContext): Integer;
function DoQryExecNonQuery(const Proc, ParamsJson: string; 
  const Ctx: TDoQryContext): Integer;
function DoQryExecInsertReturningId(const Proc, ParamsJson: string; 
  const Ctx: TDoQryContext): Integer;
function DoQryExecScalar(const Proc, ParamsJson: string; 
  const Ctx: TDoQryContext): Variant;
```

### 2.4 参数协议 (JSON)

```json
{
  "user_id": 2,
  "title": "示例标题",
  "status": "pending",
  "created_at": "2025-11-27T12:30:00Z",
  "tags": ["a", "b", "c"]
}
```

- 日期：ISO-8601 格式
- 数组：用于 IN 子句，模板使用 `{in:ids}`

### 2.5 查询定义

在 `config.db` 的 `queries` 表配置：

```sql
-- sql_template
INSERT INTO texts (user_id, title, status)
VALUES (:user_id, :title, :status)

-- param_schema_json
{
  "user_id": {"type":"integer", "required":true},
  "title": {"type":"string", "required":true},
  "status": {"type":"string", "enum":["pending","done"]}
}
```

### 2.6 事务与安全

- **事务**：支持嵌套 SAVEPOINT，默认超时 30s
- **安全**：
  - 禁止无 WHERE 的 UPDATE/DELETE
  - SELECT 默认 LIMIT=1000
  - 仅允许参数化绑定

### 2.7 日志

路径：`[ProjectRoot]/logs/query.log`

```json
{"ts":"2025-11-27T12:34:56Z", "level":"INFO", "corrId":"abc123", 
 "proc":"texts.list", "dbType":"PostgreSQL", "durationMs":12, "rows":50}
```

## 3. 方言差异

| 特性 | PostgreSQL | SQLite |
|------|------------|--------|
| 分页 | `LIMIT/OFFSET` | `LIMIT/OFFSET` |
| 返回ID | `RETURNING id` | `last_insert_rowid()` |
| 标识符 | `"col"` | `"col"` |
