# DB3 / DB4 下游产品数据库矩阵

> 日期：2026-05-13  
> 服务器：`124.221.136.137`  
> 口径：DB3 是下游业务 PostgreSQL；DB4 是 DeepKit 统一认证、支付、订单、权益后端。  
> 凭据：连接密码只记录在仓库根目录 `.env`，本文不写明文密码。

---

## 1. 总原则

1. 桌面端不直连公网 PostgreSQL。
2. DB3 只给各产品自己的业务后端、运维脚本或受控服务使用。
3. DB4 统一由 DeepKit/DeepBase Commerce/Auth 提供能力，下游软件不自建支付、订单、权益表。
4. `goodmem.cn` 已弃用，新认证支付中心统一为 `deepkit.top` / `deepkit`。
5. 备案、DNS、HTTPS 未完成前，客户端不要硬编码公网 IP；正式 URL 以 `https://deepkit.top` 为准。

## 2. 现有数据库

| 层 | 数据库 | 用户环境变量 | 用途 |
|---|---|---|---|
| DB4 | `deepkit` | `PG_AIPEX_USER` / `PG_AIPEX_PASSWORD` | DeepKit 统一用户、订单、支付、权益 |
| DB3-dev | `devdb` | `PG_DEV_USER` / `PG_DEV_PASSWORD` | 开发工具、评测、网关、代码分析类业务数据 |

| DB3-config | `configdb` | `PG_CONFIG_USER` / `PG_CONFIG_PASSWORD` | 共享配置目录预留，当前未建业务表 |

## 4. DB3 接入方式

下游产品后端连接格式：

```text
Host: 124.221.136.137
Port: 5432
Database: devdb / bizdb / noveldb
Schema: 见上表
User/Password: 见 DeepBase 根目录 .env 的 PG_*_USER / PG_*_PASSWORD
```

Delphi 桌面端不使用这些连接串。桌面端只调用产品自己的 HTTPS 业务 API：

```text
Desktop -> Product Backend API -> DB3 PostgreSQL
```

服务端连接某个 schema 时推荐设置 search_path，例如：

```sql
SET search_path TO guideduse, public;
```

## 5. DB4 接入方式

下游统一走 DeepBase 封装，不直接拼支付认证 API：

```text
TDeepKitSafeClient
TDeepKitUpgradeFlowClient
TDeepKitPermissionClient
DeepBase.Desktop.Lifecycle
```

正式 base URL：

```text
https://deepkit.top
```

逻辑路由由封装处理，后端实际前缀为 `/dk`：

```text
/dk/auth/login
/dk/auth/refresh
/dk/commerce/products
/dk/commerce/orders
/dk/commerce/payments/intents
/dk/commerce/entitlements
/dk/commerce/entitlements/consume
/dk/license/snapshots
/dk/updates/manifest
```

下游只需要提供：

```text
app_id
product_id
entitlement_code
feature_code
device_id
current_version / channel
```

支付结果以 DeepKit 服务端回调验签为准。客户端不得保存支付密钥，不得把订单直接改成 paid。
