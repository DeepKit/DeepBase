## 目标架构

### 新建数据库
创建 `OmniSyncConfig.db` 用于存放应用配置，与业务数据库分离：

```sql
-- aboutMeImages 表（以 UniBase.AntiTamper / SeedTool 实现为准）
CREATE TABLE IF NOT EXISTS aboutMeImages (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  image_key TEXT NOT NULL UNIQUE,
  image_data BLOB NOT NULL,      -- AES-256 加密的图像数据（SeedTool 写入）
  address_text TEXT,
  description TEXT,
  enabled INTEGER NOT NULL DEFAULT 1,
  sha256_hash TEXT NOT NULL,
  hmac_sha256 TEXT NOT NULL,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

## 集成方案

### 挑战：VCL vs FMX
`UniBase.VCL.AboutFrame` 是 VCL 组件，而 OmniSync 使用 FMX。

当前仓库已有 `FMX/UniBase.FMX.AboutFrame.pas`（`TFMXAboutFrame`），但**尚需与 SeedTool/UniBase.AntiTamper 的数据协议对齐**后再用于 OmniSync/Stocks：
- 字段名应为 `sha256_hash` + `hmac_sha256`（不是 `hmac_signature`）
- `image_data` 为 **AES-256 加密**的 BLOB（需要解密后再加载图像）
- 校验应以 `UniBase.AntiTamper` 的逻辑为准（SHA-256 + HMAC）

**方案 A: 使用并对齐现有 UniBase.FMX.AboutFrame** (推荐)
- 对齐 `FMX/UniBase.FMX.AboutFrame.pas` 的字段名/解密/校验逻辑
- OmniSync 直接复用该 FMX Frame

**方案 B: 混合模式**
- 使用 VCL 窗体承载 AboutFrame
- 从 FMX 主程序调用
- 不推荐 - 增加复杂度

### 推荐实施步骤

#### Phase 1: 对齐现有 FMX AboutFrame
1. 对齐 `FMX/UniBase.FMX.AboutFrame.pas` 与 `Features/UniBase.AntiTamper.pas` / SeedTool 的字段与解密/校验逻辑
2. 验证可正确读取 SeedTool 播种的数据（解密 + sha256 + hmac）
3. 在 OmniSync 内集成显示

#### Phase 2: 数据库配置
1. 创建 `OmniSyncConfig.db`
2. 添加 `aboutMeImages` 表
3. 使用 SeedTool 填充 6 个标准图片

#### Phase 3: 集成到 OmniSync
1. 在 `uSidePanelFrame` 添加 "关于" 导航项
2. 在 `uMainForm` 添加 AboutFrame 容器区域
3. 导航点击时显示 AboutFrame

## SeedTool 工作流

SeedTool 当前以 GUI 方式使用（未实现 CLI 参数）。建议：
1. 打开 `UniBase/Tools/SeedTool/SeedTool.exe`
2. 选择/创建 `OmniSyncConfig.db`
3. 初始化 `aboutMeImages` 表（如不存在）
4. 导入 6 张图片并填写 ImageKey / 地址文本（BTC/USDT）/ enabled
