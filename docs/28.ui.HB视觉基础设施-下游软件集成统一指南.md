# HB 视觉基础设施 · 下游软件集成统一指南

> **文件编号**：28.ui  
> **版本**：v1.2（2026-08-26）· 变更：新增 DeepRW V2 集成项——`THbCommandPalette` / `THbGatePanel` / `THbShareCardRenderer` 4:5 竖版扩展；锁定 DeepRW 主题 `canghai-blue`＋`hdComfortable`；DeepRW 语音链路排期至其 P2。  
> **适用产品**：`DeepDsh`、`Assayer`、`DeepRW`、`DeepCommerce（唤金）`、`DeepSync` 及所有基于 DeepBase 开发的 Delphi 软件  
> **编译器要求**：Delphi 13.1 on Win64（`dcc64.exe`），纯 0 Error / 0 Warning / 0 Leaked DCU  
> **设计哲学**：设计令牌驱动（Design Tokens）· VCL/FMX 孪生对等 · AI初筛人来拍板（Fail-Closed）· 动效克制高级 · 国防级工程治理（Counterfactual Gate）

## 1. 架构定位与二层边界原则

```
+-----------------------------------------------------------------------------------------------+
|  【应用业务层】(DeepDsh / Assayer / DeepRW / DeepCommerce / DeepSync)                          |
|  • 负责业务表单编排、DB1/DB2/API 事务绑定、业务规则校验与多步骤向导逻辑                           |
+-----------------------------------------------------------------------------------------------+
                                          │ 消费 / 组装 (只读依赖)
                                          ▼
+-----------------------------------------------------------------------------------------------+
|  【DeepBase HB 视觉基座层】(DeepBaseCore.dpk / DeepBaseVCL.dpk / DeepBaseFMX.dpk)             |
|  • 纯设计令牌系统 (10 主题 x 2 密度 x DPI 矢量缩放)                                             |
|  • 通用控件库 (THbDialog / THbSummaryBar / THbToastHost / THbVoiceDialog / THbMotionKit 等)     |
|  • 离屏脱敏渲染器 (THbShareCardRenderer) / 全局动效调度器 (THbAnimationTicker)                 |
|  • 反事实门禁断言 (CF-VOICE-01..06) 与多线程死锁防御基础设施                                   |
+-----------------------------------------------------------------------------------------------+
```

### 核心纪律红线
1. **零硬编码色值**：所有界面绘制必须且只能从 `THbTheme.Tokens`（或控件内建令牌）获取颜色、圆角、字号与间距；
2. **严禁越界反向依赖**：DeepBase 任何单元不得引用下游产品私有 Units、SQL 语句或专属业务 DTO；
3. **动效克制高级**：金色像素占比 `< 8%`（`MotionGoldMaxRatio`），严禁全屏高频刷新，低配机稳定 60fps；
4. **决策安全闭环（Fail-Closed）**：关键变更、高风险行为与 AI 提取字段必须经人类用户在 `THbDialog` 或 `THbVoiceDialog` 中显式确认，未确认内容绝不得直接入库；
5. **线程与死锁防御**：UI 线程禁止 `Sleep`，跨线程刷新严禁使用 `TThread.Queue`，必须使用 `TThread.ForceQueue`。

## 3. 主题系统与设计令牌接入

### 3.1 应用启动时初始化与换肤

在下游程序启动（`Application.Initialize`）或主窗口创建时调用：

```pascal
uses
  DeepBase.HB.Core,
  DeepBase.HB.Palettes;

// 1. 初始化主题系统 (自动注册 10 套内置调色板)
THbTheme.Initialize;

// 2. 根据产品设定默认主题与密度
// DeepDsh / 终端类: 推荐 'admin-graphite' (玄石) 或 'canghai-blue' (沧海)
// Assayer / 安全座舱: 推荐 'violet-dusk' (紫暮)
// DeepCommerce / 唤金: 推荐 'gold-luxury' (暖金) 或 'ink-gold' (墨金)
THbTheme.ApplyTheme('gold-luxury', hdComfortable);
```

### 3.2 动态响应主题切换广播

控件内部无需手动轮询。控件若继承自 `THbCustomControl`（VCL）或 `THbFmxControl`（FMX），将自动捕获 `THbThemeChangedMessage` 消息并触发平滑重绘。

## 4. 核心组件调用规范与代码范例

### 4.1 现代分块多按钮对话框 (`THbDialog`)

替代传统丑陋的 `ShowMessage` / `MessageDlg` / `InputBox`，全系统统一弹窗体验。

```pascal
uses
  DeepBase.HB.Dialogs.Types,
  DeepBase.VCL.HB.Dialogs;

// 场景 1: 普通操作成功/通知
THbDialog.ShowInfo('配置同步成功', '所有 5 个子组件已热加载最新有效配置。');

// 场景 2: 高风险操作拦截确认 (P0 Fail-Closed)
if THbDialog.Confirm('确认覆盖主路由表？', 
  '检测到未授权的配置文件重写尝试', 
  '⚠️ 影响范围：不可逆配置文件重写，放行将覆盖当前路由。') then
begin
  ApplyRouteOverride;
end;

// 场景 3: 单行 Prompt 输入 (如重命名)
var LNewName: string := '新建任务_01';
if THbDialog.Prompt('重命名任务', '请输入新任务名称：', LNewName) then
  RenameTask(LNewName);

// 场景 4: 带上下文展示 + 多行必填理由输入 (如治理审批驳回)
var LReason: string := '';
if THbDialog.PromptReason('驳回外部调用审批', '请填写驳回原因（必填，将存入审计日志）：', LReason) then
  RejectExecutionWithAudit(LReason);
```

### 4.2 通用语音录入与确认全生命周期 (`THbVoiceDialog` / `THbVoiceWaveform`)

用于口述录入、LLM 抽取与逐项人工核对确认。

```pascal
uses
  DeepBase.HB.Voice.Types,
  DeepBase.VCL.HB.Voice,
  DeepBase.VCL.HB.Terminal;

var
  Items: TArray<THbVoiceFieldItem>;
  ConfirmedCount: Integer;
begin
  // 1. 装载提取字段 (支持 Diff 原值比对与低置信度标记)
  SetLength(Items, 2);
  Items[0].FieldKey := 'phone';
  Items[0].FieldLabel := '备用联系手机';
  Items[0].OldValue := '138-0000-1122'; // 数据库已有旧值
  Items[0].ExtractedValue := '139-8877-6655';
  Items[0].OriginalQuote := '留了备用手机 139-8877-6655';
  Items[0].Status := vfsPending;

  Items[1].FieldKey := 'budget';
  Items[1].FieldLabel := '意向采购量';
  Items[1].ExtractedValue := '4 套';
  Items[1].IsLowConfidence := True; // 琥珀黄警告 badge
  Items[1].Status := vfsPending;

  // 2. 调出全生命周期确认对话框 (支持 Enter 全选、就地修改、丢弃)
  if THbVoiceDialog.Execute('唤金 · 客户档案语音提取确认', Items, ConfirmedCount) then
  begin
    // 3. 仅对用户确认项执行原子事务写库 (CF-VOICE-01 纪律)
    WriteConfirmedItemsToDatabase(Items);
    THbToastHost.Show(MainForm, Format('✓ 成功写入 %d 项客户属性到 DB1', [ConfirmedCount]), btSuccess);
  end;
end;
```

## 6. 国防级工程治理与多线程军规 (DeepAxis 补充条款)

所有下游系统在集成 HB 视觉体系与异步/语音能力时，必须严格遵守以下 4 大工程治理军规：

### 6.1 反事实门禁 (Counterfactual Gate · CF-VOICE 系列)
1. **CF-VOICE-01 (防越狱直接写库)**：写库层必须设置守门断言，无 `vfsAccepted` / `vfsModified` 确认态的字段一律拒绝写入并记审计日志；
2. **CF-VOICE-02 (畸形 JSON 容错)**：LLM 响应异常或截断时必须安全捕获并降级为 `[📝 原始原话全文]` 备忘卡，严禁崩溃；
3. **CF-VOICE-03 (零残留原子性)**：多字段写入必须包裹在同一数据库 Transaction 中，单项失败整单回滚；
4. **CF-VOICE-04 (草稿不复活丢弃项)**：恢复草稿时显式丢弃项保持丢弃态；
5. **CF-VOICE-05 (断电零污染)**：未完成会话被杀后，正式业务数据库零脏数据残留；
6. **CF-VOICE-06 (120s 截断保全)**：录音超时自动截断并保全已录音轨转写。

### 6.2 Delphi / VCL 多线程死锁防御铁律
1. **禁止 UI 线程 `Sleep`**：等待一律采用轻量计时器或可取消后台调度器；
2. **跨线程必须用 `TThread.ForceQueue`**：**严禁使用 `TThread.Queue`**（其在主线程内联执行时极易与 Synchronize 发生死锁，`ForceQueue` 强制入队彻底免疫死锁）；
3. **资源释放确定性**：音频采集句柄（waveIn / WASAPI）必须走 `try..finally` 确保确定性释放，异常时不得锁死声卡；
4. **编码规范**：所有含中文注释或字符串的 Pascal 源文件**必须保存为 UTF-8 BOM 编码**；
5. **统一 Command ID**：所有入口（按钮、快捷键、菜单、任务调度）绑定统一 Command ID，防止绕过审计拦截。

## 7. 质量门禁与验收标准 (CI Checklist)

下游产品在集成 HB 控件并发起 PR 验收时，必须全部满足以下 7 项门禁：

- [ ] **编译门禁**：Delphi 13.1 Win64 编译通过（0 Error, 0 Warning, 0 Leaked DCU）；
- [ ] **反事实门禁**：通过 `Test.DeepBase.HB.Voice.CF.pas` 6 大逆向断言测试；
- [ ] **令牌门禁**：全文无硬编码颜色（如 `$00FFFFFF`、`clRed`），全部通过 `Tokens.*` 取色；
- [ ] **DPI 缩放**：在 100%、125%、150%、200% DPI 下无文本截断、无图标模糊、无布局重叠；
- [ ] **五态齐备**：所有交互控件具备 `Normal` / `Hover` / `Pressed` / `Disabled` / `Focus` 视觉反馈；
- [ ] **对比度合规**：所有文本与背景对比度达到 WCAG 2.1 AA 级（正文 ≥ 4.5:1，大字 ≥ 3.0:1）；
- [ ] **Fail-Closed 闭环**：所有入库与配置覆写操作具备明确的人类确认态与取消回滚机制。
