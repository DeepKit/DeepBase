## 3. 公共部分 vs 业务部分拆分

**迁入 DeepBase（公共基础设施）**：

- `IPluginContract` 基接口（Initialize / Shutdown / ReloadConfig / GetMetadata / GetApiVersion / GetHealthStatus / IsHealthy，全 stdcall）；
- `TPluginType` / `TPluginState` / `TPluginMetadata` / `TPluginHealthStatus`；
- `PLUGIN_API_VERSION_*` 常量（主版本必须匹配才允许加载）；
- 当前实现保留 `TCreatePluginFunc = function: IPluginContract; stdcall;` 作为**实验性 Delphi 同编译器 ABI**；该接口不得作为产品线稳定 ABI 发布；`IPluginContract`、string、TBytes 和 Delphi 对象只能存在于宿主内部包装层；`r2` 必须迁移为纯 C 数据面：固定导出函数、不透明句柄、固定宽度整数、`PByte + Length + Capacity`、显式错误码及同模块 `FreeBuffer`。
- TPluginManager（泛化：插件类别从硬编码 5 类改为**注册制**——宿主自行 RegisterContractClass）；
- TPluginSafeGuard、TPluginVerifier。

**留在各宿主（业务契约）**：Assayer 的 IRouterPlugin/IPipelinePlugin/IAuthPlugin/IAuditPlugin/IStatsPlugin；DeepCompare 的 ISiteAdapterPlugin（见 §6）。

## 4. TPluginManager 泛化改造要点

现有实现的 5 个 `Get*Plugin` 便捷方法是 Assayer 业务，公共版改为：

```pascal
// 宿主注册业务契约类别（名称 -> 期望的导出函数名规则）
procedure RegisterPluginKind(const AKind: string;
  const ACreateFuncPrefix: string);  // 如 'Create' + Kind 名

// 按名称取已加载插件，宿主自行 Supports/QueryInterface 到业务接口
function GetPlugin(const APluginName: string): IPluginContract;
```

其余能力原样保留：
- **懒加载**（ASY-DLL-004）：RegisterPlugin 只声明，EnsureLoaded 首次使用时加载；
- **ReloadPlugin**：Unload → Load 原子序列，TCriticalSection 保护；
- **SafeGuard 联动**：加载失败/连续崩溃 → 状态 psError，自动降级不再加载；
- **事件钩子**：OnPluginLoaded / OnPluginUnloaded 保留（供宿主做 /admin/plugins 状态端点，Assayer 已有先例）。

新增能力（泛化改造同步引入）：
- **插件依赖声明**：RegisterPluginKind 增加可选参数 `ADependsOn: TArray<string>`，Manager 加载插件时先递归加载依赖项；依赖加载失败则当前插件跳过并标记 psError；**注册时对 ADependsOn 做 DFS 拓扑环检测，发现环（A→B→A）拒绝注册并告警，禁止运行时死递归**；
- **在途调用计数**：每个插件实例维护 `AtomicIncrement/Decrement` 调用计数，供 Unload 等待归零与 SafeGuard 熔断判断；
- **共享内存管理器**：宿主与插件 DLL 必须链接同一共享内存管理器（BorlndMM/ShareMem 模式），跨边界传递 string/TJSONObject 时由调用方分配、被调方只读，禁止被调方释放调用方内存。
- **Lease/Invoke 门禁**：Manager 不直接暴露 `IPluginContract` 接口引用给宿主业务代码，改为通过 `TPluginLease` 中间层：调用方 `AcquireLease(PluginName, Timeout)` 获得临时引用，用完 `ReleaseLease` 归还；**Lease drain 超时由 Manifest 配置，宿主强制限制在 10–300 秒，默认 300 秒；超时进入 psPendingRestart/psError、停止新调用并告警，禁止强制 FreeLibrary**——Windows 进程内无法安全地强制卸载引用非零的 DLL，强制卸载会导致后续访问野内存崩溃；

## 5. Delphi DLL 热重载工程约束（实现时必须遵守）

1. **接口 GUID 即 ABI**：宿主与 DLL 必须编译**同一份** Contracts 单元（公共化后天然满足）；GUID 一旦发布禁止改动；扩展契约**只能通过接口继承**新增（新接口新 GUID，旧插件无需改动即可继续加载），禁止修改已有接口方法签名；Contracts 单元须嵌入 `PLUGIN_ABI_MAJOR` / `PLUGIN_ABI_MINOR` 常量（主版本必须完全匹配，次版本宿主 ≥ 插件即可），加载时校验宿主与 DLL 的编译器版本与 RTL 标识，不匹配则拒绝加载并告警；
2. **同版本 RTL**：宿主与插件 DLL 用同一 Delphi 编译器版本构建（当前 Delphi 13，编译器路径见项目记忆），跨版本传递 string/TJSONObject 不保证兼容；
3. **FreeLibrary 前置条件**：卸载前必须确认接口引用全部归零（管理器通过 Lease 门禁持有插件引用，Unload 时先调 Shutdown 再等待所有 Lease 释放，**等待上限取 Manifest 的 `unload_timeout_ms`，宿主钳制在 10–300 秒，默认 300 秒；超时进入 pending restart 并告警，禁止强制 FreeLibrary**——Windows 进程内无法安全地强制卸载引用非零的 DLL，强制卸载会导致后续访问野内存崩溃）；**禁止插件向宿主传递跨边界长期引用**（如将自身接口存入宿主全局对象、注册长期回调），所有跨边界引用必须通过 Lease 门禁限定在单次调用生命周期内；
4. **禁止在 DLL 中使用 VCL 全局状态**（类注册表、Application 对象）——Gateway 的站点适配器插件只做无头逻辑 + 通过宿主回调驱动 WebView2，不自建窗口；
5. **调用约定与跨边界内存**：稳定 ABI 必须是纯 C 数据面并禁止异常越界传播。禁止跨 DLL 边界出现 Delphi interface、string、TBytes、动态数组、对象、Variant 或由另一模块释放的内存。变长输出采用两次调用：第一次返回所需长度，第二次由宿主分配 `PByte + Capacity`；或者由插件分配并由同一插件导出的 `FreeBuffer` 释放。现有 `IPluginContract/TBytes` 仅可作为同编译器、同 RTL、同共享内存管理器下的实验适配层，不得标为稳定 ABI。
6. **热重载时序**：新 DLL 文件先写到旁路目录 → 校验签名 → **暂停该插件新调用请求（排队或返回 503）** → 等待所有 Lease 释放（**等待上限 300 秒，与 Unload 语义一致；超时标记 psError 并告警人工介入，禁止强制卸载**） → 备份旧 DLL 到临时目录 → Unload 旧版 → 文件替换 → Load 新版 → Initialize → 恢复调用；失败则回滚旧文件并 psError；
7. **多线程安全**：Reload 全程持 TCriticalSection 排他锁；Reload 期间新调用请求返回 `PLUGIN_RELOADING` 错误码（宿主侧降级处理），确保不会在 Unload→Load 窗口期调用已卸载代码；每个插件实例通过 Lease 计数器管理并发调用，Unload 前必须等待所有 Lease 释放。

## 9. S0 包格式规范（契约冻结，78 严格按此打包）

> **归口声明**：zip 包格式（目录结构、签名规则、plugin_manifest.json schema）**归口本 S0 定义**；78 协议与 78a ADR 均严格按本规范打包与校验（78 §2.6 / 78a §2.6）。本文档 S1~S4 与 78 端到端的共同前置 = "本 S0 包格式规范 + 78 制品仓库就绪"。

### 9.1 包目录结构

config zip 采用**扁平结构 + 单一 manifest**，保持轻量：

```
config_<provider_key>_<version>.zip
├── config.json              # 单站点配置（UTF-8，RFC 8785 JCS 规范化后写入）
├── provider_meta.json       # 供应商元信息（provider_key、version、generation、issued_at、expires_at）
└── plugin_manifest.json     # DLL 制品引用清单（不含 DLL 实体，见 9.3）
```

- zip 内**不内嵌 DLL 实体**；DLL 由制品仓库按 `plugin_manifest.json` 中的 URL 提供（独立生命周期，可单独更新/回滚/删除）。
- 所有 JSON 写入前经 RFC 8785 JCS 规范化（键排序、固定转义），保证双端哈希一致。

### 9.2 签名规则（RSA-SHA256，法源 78a r1 §2.7）

- 算法：**RSA-SHA256（PKCS#1 v1.5, 2048-bit, Windows CNG 原生）**；`sig_alg` 当前仅接受 `rsa-sha256`（Ed25519 为可选演进，当前禁用）。
- 签名对象：`config.json` 规范化字节 + `provider_meta.json` 规范化字节 的**拼接**（顺序固定），经 RSA-SHA256 签名。
- 签名存放：`config.sig`（原始字节，Base64 编码存储于 zip 根）。
- 密钥架构（78a r1 §2.7）：
  - 公钥信任根随可信安装交付，或由已信任旧密钥签署 keyset 更新；禁止未验证 Manifest 自带公钥自证。
  - 私钥托管于 KMS/HSM/受控签名服务，具备审批、审计、轮换和吊销。
  - 客户端持久化最高 generation；除独立签名且有审计的 rollback token 外，拒绝 generation 降低。
- 下载 URL 必须 HTTPS；正式部署支持域名白名单与短期签名 URL。

### 9.3 plugin_manifest.json schema

```json
{
  "schema_version": 1,
  "sig_alg": "rsa-sha256",
  "plugins": {
    "<plugin_name>": {
      "url": "https://artifacts.example.com/plugins/<plugin_name>/<dll_version>/<plugin_name>.dll",
      "sha256": "<hex-sha256-of-dll>",
      "dll_version": "1.4.2",
      "compatible_config_version_range": ">=1.0.0 <2.0.0"
    }
  }
}
```

字段约定：
- `schema_version`：固定 `1`；新增字段必须向后兼容，不破坏已发布契约。
- `sig_alg`：签名算法标识；当前仅 `rsa-sha256`。
- `plugins.<name>.url`：制品仓库中 DLL 的下载 URL（HTTPS）。
- `plugins.<name>.sha256`：DLL 二进制 SHA-256，Gateway 下载后校验。
- `plugins.<name>.dll_version`：DLL 版本（单调递增；单独更新 DLL 时递增，见 78 §3.3-4）。
- `plugins.<name>.compatible_config_version_range`：兼容配置版本范围；Gateway 加载 DLL 前校验当前配置版本在范围内，不匹配拒绝加载并告警。

### 9.4 Gateway 校验顺序（消费契约）

1. 下载 config zip → 校验整体 RSA-SHA256 签名（9.2）→ 失败拒绝并继续 LKG。
2. 解压 → 校验 `config.json` 的 sha256 与 `provider_configs` 表比对 → 不一致拒绝。
3. 按 `plugin_manifest.json` 的 URL 从制品仓库下载 DLL → 校验 DLL sha256 与签名 → 触发��重载。
4. 制品仓库不可用时降级：保留本地旧版 DLL 继续运行 + 告警；**禁止回退到无签名 DLL、禁止跳过校验**。

### 9.5 验收标准（S0 契约冻结证据）

- [ ] zip 结构符合 9.1；config.json/provider_meta.json 为 JCS 规范化字节。
- [ ] 签名规则符合 9.2：RSA-SHA256、拼接顺序固定、key_id/keyset 注入、generation 防回滚。
- [ ] plugin_manifest.json schema 符合 9.3；未知字段不破坏解析（向后兼容）。
- [ ] 校验顺序符合 9.4：篡改、过期、目标不符、generation 降低、制品仓库不可用均拒绝并 LKG。
- [ ] 双端（服务端打包 / 客户端验签）JCS 哈希相等；`sig_alg=rsa-sha256` 门禁生效。
