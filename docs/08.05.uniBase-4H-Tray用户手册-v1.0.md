# UniBase Tray 工作台用户手册

> 版本: 1.0 | 最后更新: 2025-11-29

UniBase Tray 是一个轻量级的系统托盘工具，提供悬浮窗口、开发日志、系统监控、定时任务等功能，帮助开发者提高日常工作效率。

## 快速入门

### 启动 Tray

1. 运行 `UniBaseTray.exe`
2. 程序启动后最小化到系统托盘
3. 双击托盘图标显示/隐藏悬浮窗口

### 系统要求

- Windows 7/8/10/11
- 管理员权限（部分功能需要）

### 托盘图标菜单

右键点击托盘图标显示菜单：
- **显示工作台** - 显示悬浮窗口
- **隐藏** - 隐藏悬浮窗口
- **退出** - 关闭程序

## 开发日志

### 功能概述

开发日志模块提供快速记录开发过程中的想法、问题和进展。

### 操作指南

#### 添加日志
1. 切换到 **DevLog** 标签
2. 在输入框中输入日志内容
3. 按 **Enter** 或点击 **Add** 保存

#### 日志分类
选择日志类型：
- 📝 **记录** - 一般记录
- 💡 **想法** - 灵感和想法
- 🐛 **Bug** - 问题和缺陷
- ✅ **完成** - 已完成的任务
- ⚠️ **待办** - 待处理事项

#### 查看历史
- 日志按时间倒序显示
- 显示：时间、类型、内容
- 滚动查看更多历史记录

#### 搜索日志
1. 在搜索框输入关键字
2. 自动过滤匹配的日志
3. 清空搜索框显示全部

#### 导出日志
1. 点击 **Export** 按钮
2. 选择导出格式（TXT/JSON）
3. 选择保存位置

## 常用命令

### 功能概述

常用命令面板提供预定义的命令快捷执行。

### 内置命令

| 命令 | 说明 |
|------|------|
| Git Status | 显示 Git 状态 |
| Git Pull | 拉取最新代码 |
| Git Push | 推送代码 |
| Git Log | 查看提交历史 |
| NPM Install | 安装 NPM 依赖 |
| NPM Start | 启动 NPM 项目 |

### 自定义命令

#### 添加命令
1. 点击 **Add** 按钮
2. 输入命令名称
3. 输入命令内容
4. 选择工作目录（可选）
5. 点击保存

#### 编辑命令
1. 右键点击命令
2. 选择 **Edit**
3. 修改命令信息
4. 保存更改

#### 执行命令
- **单击** - 在默认目录执行
- **Ctrl+单击** - 选择目录后执行
- **双击** - 在新窗口执行

## 系统监控

### 功能概述

系统监控模块实时显示系统资源使用情况。

### 监控指标

#### CPU 使用率
- 进度条显示当前使用率
- 颜色指示：
  - 绿色: 0-60%
  - 黄色: 60-80%
  - 红色: 80-100%

#### 内存使用率
- 显示已用/总量
- 进度条显示百分比
- 单位自动转换（GB/MB）

#### 磁盘使用率
- 显示系统盘使用情况
- 已用空间/总空间
- 进度条显示百分比

### 刷新频率

- 默认每秒更新一次
- 可在设置中调整刷新间隔
- 暂停/恢复监控

## 开发笔记

### 功能概述

开发笔记模块用于记录想法、TODO 和提醒事项。

### 笔记分类

| 分类 | 图标 | 用途 |
|------|------|------|
| 想法 | 💡 | 灵感和创意 |
| TODO | ☑️ | 待办任务 |
| 问题 | ❓ | 需要解决的问题 |
| 会议 | 📅 | 会议记录 |
| 其他 | 📝 | 其他笔记 |

### 优先级

- 🔴 **高** - 紧急重要
- 🟡 **中** - 正常优先
- 🟢 **低** - 可以延后

### 操作指南

#### 添加笔记
1. 点击 **Add Note** 按钮
2. 输入笔记内容
3. 选择分类和优先级
4. 设置提醒时间（可选）
5. 点击保存

#### 设置提醒
1. 编辑笔记
2. 启用提醒
3. 设置提醒时间
4. 到时间后弹出通知

#### 完成笔记
- 点击笔记前的复选框
- 或按 **空格键** 切换状态
- 已完成的笔记显示删除线

#### 过滤笔记
- **全部**: 显示所有笔记
- **未完成**: 仅显示未完成的
- **已完成**: 仅显示已完成的
- **有提醒**: 显示设置了提醒的
- **今日**: 显示今日的笔记

#### 搜索笔记
- 输入关键字实时过滤
- 搜索匹配标题和内容

## 定时任务

### 功能概述

定时任务模块用于设置自动执行的任务。

### 任务类型

| 类型 | 说明 |
|------|------|
| 命令 | 执行 CMD 命令 |
| 程序 | 启动程序 |
| 脚本 | 执行脚本文件 |

### 定时方式

| 方式 | 说明 | 示例 |
|------|------|------|
| 一次性 | 仅执行一次 | 2025-12-01 10:00 |
| 每日 | 每天固定时间 | 每天 09:00 |
| 每周 | 每周固定时间 | 每周一 09:00 |
| 间隔 | 固定间隔执行 | 每 30 分钟 |

### 操作指南

#### 添加任务
1. 点击 **Add Task** 按钮
2. 输入任务名称
3. 选择任务类型
4. 输入执行命令/程序路径
5. 选择定时方式
6. 设置执行时间
7. 点击保存

#### 管理任务
- **启用/禁用**: 切换任务状态
- **立即执行**: 手动触发一次
- **编辑**: 修改任务设置
- **删除**: 移除任务

#### 任务日志
- 查看任务执行历史
- 显示执行时间、结果、输出
- 失败时显示错误信息

## 项目切换器

### 功能概述

项目切换器帮助快速在多个项目之间切换。

### 功能特性

- **最近项目**: 自动记录最近打开的项目
- **类型检测**: 自动识别项目类型
- **收藏功能**: 收藏常用项目
- **快速操作**: 打开文件夹/IDE/终端

### 支持的项目类型

| 类型 | 检测方式 | 图标 |
|------|---------|------|
| Delphi | *.dproj, *.dpr | 🔶 |
| Visual Studio | *.sln, *.csproj | 🔷 |
| Python | requirements.txt, setup.py | 🐍 |
| Node.js | package.json | 📦 |
| Go | go.mod | 🐹 |
| Rust | Cargo.toml | 🦀 |

### 操作指南

#### 添加项目
1. 点击 **Add Project** 按钮
2. 选择项目文件夹
3. 系统自动检测项目类型
4. 项目添加到列表

#### 项目操作
- **双击**: 打开项目文件夹
- **右键 → Open Folder**: 打开文件夹
- **右键 → Open in IDE**: 使用 IDE 打开
- **右键 → Open Terminal**: 在项目目录打开终端

#### 收藏项目
- 点击项目右侧的星标
- 收藏的项目显示在列表顶部

#### 搜索项目
- 输入项目名称过滤
- 支持模糊匹配

## 全局快捷键

### 功能概述

全局快捷键允许在任何应用程序中快速调用 Tray 功能。

### 默认快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl+Alt+U | 显示/隐藏工作台 |
| Ctrl+Alt+N | 新建笔记 |
| Ctrl+Alt+S | 打开 Studio |
| Ctrl+Alt+C | 打开命令面板 |
| Ctrl+Alt+P | 打开项目切换器 |

### 自定义快捷键

1. 打开设置
2. 进入 **快捷键** 选项卡
3. 点击要修改的快捷键
4. 按下新的键组合
5. 保存设置

### 注意事项

- 避免与系统快捷键冲突
- 避免与常用程序快捷键冲突
- 某些快捷键可能被其他程序占用

## 设置选项

### 访问设置

- 右键托盘图标 → **设置**
- 或在主窗口菜单 → **Settings**

### 常规设置

| 选项 | 说明 | 默认值 |
|------|------|--------|
| 开机启动 | 系统启动时自动运行 | 关闭 |
| 最小化启动 | 启动时最小化到托盘 | 开启 |
| 显示通知 | 是否显示通知消息 | 开启 |

### 外观设置

| 选项 | 说明 | 默认值 |
|------|------|--------|
| 不透明度 | 窗口不透明度 | 85% |
| 始终置顶 | 窗口保持在最前 | 开启 |
| 深色主题 | 使用深色界面 | 开启 |

### 监控设置

| 选项 | 说明 | 默认值 |
|------|------|--------|
| 刷新间隔 | 监控数据刷新频率 | 1 秒 |
| CPU 警告阈值 | CPU 超过此值警告 | 80% |
| 内存警告阈值 | 内存超过此值警告 | 80% |

### 数据设置

| 选项 | 说明 | 默认值 |
|------|------|--------|
| 数据目录 | 数据存储位置 | %APPDATA%/UniBase |
| 日志保留天数 | 自动清理旧日志 | 30 天 |
| 备份频率 | 自动备份频率 | 每日 |

## 常见问题

### Q: 托盘图标不显示？

**A:**
1. 检查系统托盘区域是否折叠
2. 点击托盘区域的展开箭头
3. 将 UniBase Tray 图标拖到可见区域

### Q: 窗口位置无法保存？

**A:**
1. 检查 %APPDATA%/UniBase 目录权限
2. 手动删除 tray_settings.ini 文件
3. 重启程序

### Q: 全局快捷键不工作？

**A:**
1. 检查是否与其他程序冲突
2. 以管理员身份运行
3. 更换其他快捷键组合

### Q: CPU/内存显示为 0？

**A:**
1. 需要管理员权限读取某些系统信息
2. 以管理员身份运行程序

### Q: 定时任务没有执行？

**A:**
1. 检查任务是否已启用
2. 检查执行时间设置
3. 检查命令/程序路径是否正确
4. 查看任务日志了解错误详情

### Q: 程序占用内存过高？

**A:**
1. 清理历史日志
2. 减少监控刷新频率
3. 关闭不需要的功能模块

### 备份数据

建议定期备份 `%APPDATA%/UniBase` 目录。
