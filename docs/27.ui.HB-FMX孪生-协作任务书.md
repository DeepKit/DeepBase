## 架构裁定（照此执行，有异议先报主控再动）

1. **共享核心下沉**：`Theme.pas` 目前 uses 了 `Winapi.Windows/Messages`（WM 广播）与 `System.UIConsts`——FMX 不能直接吃。抽一层无框架依赖的 `DeepBase.HB.Core.*`（纯 RTL：令牌结构、JSON 解析/继承、WCAG 校验、密度计算），VCL 与 FMX 双端共同 uses。**主题广播改双轨**：Windows 端保留 WM_HB_THEME_CHANGED，跨框架用 `TThread.Synchronize` 回调注册表或 RTL `System.Messaging.TMessageManager`。
2. **渲染对等不复制粘贴**：FMX 全矢量坐标系（TRectF/Single、原生 TAlphaColor），组件几何逻辑能下沉 Core 的下沉，绘制层各写各的。FMX 用内置 `FMX.Skia` 单元；**禁止安装第三方 Skia4Delphi 包**（防双 Skia 冲突）。
3. **十主题零改动**：Palettes 的 JSON 色板原样供两端消费；FMX 不新增也不修改任何主题值。若发现 WCAG 校验在 FMX 下结果不一致，报主控裁决，不许私自调色。
