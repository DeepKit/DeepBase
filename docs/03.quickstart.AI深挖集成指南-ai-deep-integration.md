## 0. 核心约束（不变）

1. **配置铁律**：唯一外部文件是 `root.txt`，其余配置进 DB1 ConfigDB。
2. **敏感数据**：API Key / Token / 支付密钥走 `DeepBase.Security`（Windows DPAPI / 跨平台 UBS2）。
3. **UI 线程**：禁止同步重试、长耗 LLM/语音调用、Sleep。Resilience 用 `ExecuteAsync` 或 `rmwRaise`。
4. **四库分层**：DB1 本地配置 / DB2 本地业务 / DB3 远程业务 / DB4 生产后端（客户端**不得直连 DB4**）。

## 1. IoC 容器

### 注册

```delphi
uses DeepBase.IoC;

// 注册接口-实现映射
TIoCContainer.Default.RegisterType<IMyService, TMyService>;

// 注册单例
TIoCContainer.Default.RegisterSingleton<IMyService, TMyService>(TMyService.Create);
```

### 解析

```delphi
var
  Svc: IMyService;
begin
  if TIoCContainer.Default.TryResolve<IMyService>(Svc) then
    Svc.DoSomething;
end;
```

### 生命周期

- `RegisterType` — 每次 Resolve 创建新实例
- `RegisterSingleton` — 全局单例（需注意线程安全）
- `RegisterInstance` — 外部传入已创建实例

## 2. EventBus 事件总线

```delphi
uses DeepBase.EventBus;

// 订阅
var
  Sub: ISubscription;
begin
  Sub := TEventBus.Default.Subscribe<TMyEvent>(
    procedure(const AEvent: TMyEvent)
    begin
      Log('Received: ' + AEvent.Message);
    end);
end;

// 发布
TEventBus.Default.Publish(TMyEvent.Create(Message));

// 异步发布（不进 drain tracker 则需手动管理）
TEventBus.Default.PublishAsync<TMyEvent>(TMyEvent.Create(Message));
```

### 注意

- 销毁 EventBus 前必须退订所有 `ISubscription`，否则悬空指针。
- 统计计数器在锁内访问，避免竞态。

## 3. Scheduler 任务调度

```delphi
uses DeepBase.Scheduler;

var
  Scheduler: TDeepBaseScheduler;
  JobId: string;
begin
  Scheduler := TDeepBaseScheduler.Create;
  try
    // Cron 表达式：每分钟执行
    JobId := Scheduler.Schedule('*/1 * * * *',
      procedure
      begin
        Log('Heartbeat');
      end);

    // 延迟执行
    JobId := Scheduler.ScheduleAfter(5000,  // 5 秒后
      procedure
      begin
        Log('Delayed task');
      end);

    Scheduler.Start;
  finally
    Scheduler.Stop;  // 务必先 Stop，再 Free
    Scheduler.Free;
  end;
end;
```

### 注意

- `Stop` 后 `Destroy` 前确保正在运行的任务已完成。
- `Delay` 方法不刷新 `NextRunAt`，fluent API 状态不可见。

## 4. WorkerQueue 工作队列

```delphi
uses DeepBase.WorkerQueue;

var
  Queue: TWorkerQueue;
begin
  Queue := TWorkerQueue.Create(4);  // 4 个工作线程
  try
    Queue.Enqueue(
      procedure
      begin
        ProcessLargeFile(FileName);
      end);

    // 等待所有任务完成
    Queue.WaitForCompletion;
  finally
    Queue.Free;
  end;
end;
```

## 5. Resilience 弹性策略

```delphi
uses DeepBase.Resilience;

// 重试策略
var
  Retry: TRetryPolicy;
begin
  Retry := TRetryPolicy.Create
    .MaxRetries(3)
    .ExponentialBackoff(100, 2.0, 5000)
    .MainThreadWaitMode(rmwRaise);

  Retry.Execute(
    procedure
    begin
      CallExternalAPI;
    end);

  // UI 线程异步版本
  Retry.ExecuteAsync(
    procedure
    begin
      CallExternalAPI;
    end,
    procedure(const E: Exception)
    begin
      ShowError(E.Message);
    end);
end;
```

### 断路器

```delphi
var
  CB: TCircuitBreaker;
begin
  CB := TCircuitBreaker.Create
    .FailureThreshold(5)
    .ResetTimeout(30000);  // 30 秒后尝试恢复

  if CB.CanExecute then
  try
    CallUnstableService;
    CB.RecordSuccess;
  except
    CB.RecordFailure;
    raise;
  end;
end;
```

### 超时

```delphi
TTimeoutPolicy.Create(5000)  // 5 秒超时
  .Execute(
    procedure
    begin
      PotentiallySlowCall;
    end);
```

## 6. StateMachine 状态机

```delphi
uses DeepBase.StateMachine;

var
  FSM: TStateMachine<TOrderState>;
begin
  FSM := TStateMachine<TOrderState>.Create(osPending);
  try
    FSM.AddTransition(osPending, osPaid, 'pay')
        .AddTransition(osPaid, osShipped, 'ship')
        .AddTransition(osShipped, osDelivered, 'deliver');

    if FSM.CanFire('pay') then
      FSM.Fire('pay');

    if FSM.IsInState(osPaid) then
      ProcessPaidOrder;
  finally
    FSM.Free;
  end;
end;
```

### 注意

- `FireIfInState` 持锁检查+执行，避免死锁。
- `IsInState` 有循环检测保护。

## 7. ObjectPool 对象池

```delphi
uses DeepBase.ObjectPool;

var
  Pool: TObjectPool<TConnection>;
  Conn: TConnection;
begin
  Pool := TObjectPool<TConnection>.Create(
    function: TConnection
    begin
      Result := TConnection.Create(ConnectionString);
    end);

  Conn := Pool.Acquire;
  try
    Conn.Execute('SELECT ...');
  finally
    Pool.Release(Conn);
  end;
end;
```

## 8. Cache 缓存

```delphi
uses DeepBase.Cache;

var
  Cache: TCache<string, TUser>;
  User: TUser;
begin
  Cache := TCache<string, TUser>.Create(100);  // 容量 100

  if not Cache.TryGet('user_123', User) then
  begin
    User := LoadUserFromDB('123');
    Cache.Put('user_123', User);
  end;
end;
```

## 9. WhenReady 延迟初始化

```delphi
uses DeepBase.Manager;

begin
  // 注册回调：Manager 初始化完成后执行
  DeepBase.WhenReady(
    procedure
    begin
      InitMyServices;
      LoadPlugins;
    end);

  DeepBase.InitializeOrRaise;
end;
```

## 10. 诊断

```delphi
uses DeepBase.Diagnose;

var
  Results: TDiagnoseResults;
begin
  Results := DiagnoseAll(ConfigDB);
  if Length(Results) > 0 then
  begin
    Log(GenerateDiagnoseReport(Results));
    AutoFix(ConfigDB, Results);
  end;
end;
```
