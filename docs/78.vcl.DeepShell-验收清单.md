# DeepShell 验收清单

> audience: ai, developer
> status: acceptance-contract

## 1. 编译验收

必须通过：

```text
DeepBaseVCL.dpk 编译
DeepBaseCore.dpk 编译
DeepBaseServices.dpk 编译
DeepBaseFeatures.dpk 编译
Tests/DeepBaseTests.dpr 编译
DeepMainFormDemo 编译
```

核心不得硬依赖：

```text
WebView2 / CEF / Playwright
LLM 实现
Db1 实现单元
doQry 实现单元
Connection Pool 实现单元
DeepBaseGovernance 实现单元
网络客户端
业务 Provider
第三方 Docking / 皮肤库
```

## 2. 启动验收

无业务 Provider 时：

- 程序能启动。
- 工作台可见。
- 设置窗体可打开。
- 状态栏可见。
- 日志区可展开。
- 左右悬浮窗可打开和关闭。

## 3. 三段折叠验收

验证：

- Top 展开 / 折叠。
- Middle 展开 / 折叠。
- Bottom 展开 / 折叠。
- 折叠后没有负高度。
- Splitter 不错位。
- 控件不重叠。
- 中区折叠后仍有恢复入口。
- 重启后状态恢复。

## 4. MRU 验收

验证：

- 添加最近项目。
- 重复打开去重。
- 最近项排序正确。
- MRU 数量上限有效。
- 中文路径正常。
- 路径不存在时不崩溃。
- 清空 MRU 不影响 Layout。

## 5. Layout 验收

验证：

- 主窗体位置和大小恢复。
- 最大化状态恢复。
- 左右工具窗位置恢复。
- Top / Middle / Bottom 状态恢复。
- 当前 Tab 恢复。
- 当前视图恢复失败时回到工作台。
- 多显示器缺失时窗口拉回可见区域。

## 6. Theme 验收

验证：

- 浅色主题。
- 深色主题。
- 跟随系统。
- 重启后恢复。
- 菜单、工具栏、状态栏、日志等级颜色一致。
- 缺失主题时回退默认主题。

## 7. i18n 验收

验证：

- Shell 内置文本走 key。
- 中文可用。
- 英文可用或有回退。
- 缺失 key 显示默认文本。
- 语言切换后菜单、按钮、设置窗、状态栏刷新。

## 8. Settings 验收

验证：

- 设置窗体可打开。
- OK 保存并关闭。
- Apply 保存不关闭。
- Cancel 不保存。
- Restore Defaults 有效。
- 下游设置页可注册。
- 业务设置页异常不影响 Shell 设置页。

## 9. Command 验收

验证：

- 菜单绑定 Command。
- 工具栏绑定 Command。
- 快捷键绑定 Command。
- 右键菜单绑定 Command。
- Enabled / Visible / Checked 刷新正确。
- 执行异常进入 Status/ErrorReporter。

## 10. EventBus 验收

验证：

- 可订阅。
- 可取消订阅。
- 重复订阅可区分。
- 窗体销毁后不再收到事件。
- UI 更新回主线程。
- 主线程 Publish 时 handler 同步执行。
- 后台线程 Publish 时 handler 通过 `TThread.Queue` 在主线程执行。
- 后台线程 Publish 不等待 UI handler 完成。
- handler 内抛异常时进入统一错误处理，不破坏后续订阅者。

## 11. Provider 验收

使用 fake provider 验证：

- StructureProvider 可显示树。
- MainViewProvider 可打开主视图。
- InspectorProvider 可显示属性。
- Provider 不返回业务对象指针。
- Provider 异常不导致 Shell 崩溃。

## 12. 可选服务验收

使用 fake service 验证：

- fake Db1 未配置时 Shell 仍可启动。
- fake QueryExecutor 报错时进入日志。
- fake Pool 状态可显示。
- fake Governance observe 不阻断命令。
- 真实 adapter 不在 Shell 核心 uses 中。

## 12.1 多实例验收

验证：

- 两个主窗体实例可同时运行。
- 两个实例同时写 MRU 不丢最近项。
- 同一项目在两个实例打开时，项目级 Layout 不互相覆盖当前视图。
- 全局 Layout last-write-wins 行为可预期。
- SettingsStore 写入失败或冲突时回退默认状态并记录 warning。

## 13. 安全验收

必须满足：

- 密码、Token、私钥不进入 MRU / Layout / 日志。
- 高风险命令有 RiskLevel / GateKey 字段。
- UI 线程不执行长 SQL、网络、LLM、浏览器自动化。
- 关闭窗体时后台任务能取消或安全结束。
- 不创建散落 JSON / INI / YAML 配置文件。

## 14. Demo 验收

DeepMainFormDemo 应展示：

- 工作台
- 三段折叠
- 左右悬浮窗
- MRU fake 数据
- 主题切换
- 语言切换
- 设置窗体
- 日志和任务进度
- fake Provider 主视图
- fake Governance observe
