## 0. 定位

让 FireDAC 能**只读**打开第三方加密 SQLite 数据库（如微信 PC 端的 SQLCipher 数据库），提供密钥派生、只读约束、body-zero 审计能力。

**子系统集成图：**

```
TExternalSQLiteReader (本模块)
    │  实现: IExternalDBReader + IBodyZeroAuditor
    │  产出: TExternalDBSchema + SchemaFingerprint
    │  SafeQuery 是唯一数据读取出口
    │  SafeQueryAsDict 桥接到 SchemaAdapter (33)
    ▼
SchemaAdapter (33.data)
    │  消费: SchemaFingerprint → 匹配版本适配器
    │  消费: SafeQueryAsDict → MapRow → TArray<Variant>
    ▼
UIA Engine (34.data)
    │  消费: SafeQueryAsDict → 获取话术数据
    │  使用: ClipboardGuard (35) → 粘贴到微信输入框
    ▼
消费方应用
```

**`SafeQueryAsDict` 是 32→33 之间的桥接层（v0.5 新增）：**

```delphi
function TExternalSQLiteReader.SafeQueryAsDict(const TableName: string;
  const ColumnNames: TArray<string>): TArray<TDictionary<string, Variant>>;
begin
  var Q := SafeQuery(TableName, ColumnNames);
  try
    var RowList := TList<TDictionary<string, Variant>>.Create;
    try
      while not Q.Eof do
      begin
        var RowDict := TDictionary<string, Variant>.Create(
          TIStringComparer.Ordinal);
        for var ColName in ColumnNames do
          RowDict.Add(ColName, Q.FieldByName(ColName).AsVariant);
        RowList.Add(RowDict);
        Q.Next;
      end;
      Result := RowList.ToArray;
    finally
      RowList.Free;  // 字典已拷贝到 Result，释放 List 本身
    end;
  finally
    Q.Free;
  end;
end;
```

## 3. SafeQuery — 核心方法（v0.5 QVer 修复）

```delphi
function TExternalSQLiteReader.SafeQuery(const TableName: string;
  const ColumnNames: TArray<string>): TFDQuery;
begin
  // === 审计（非阻塞） ===
  try
    for var Col in ColumnNames do
      FAuditor.RecordColumnAccess(Col);
    for var Col in ColumnNames do
      if FSchema.IsBodyColumn(TableName, Col) then
        Logger.Warn('BodyZero: body column %s.%s accessed', [TableName, Col]);
  except
    on E: Exception do
    begin
      Logger.Error('审计记录失败（非阻塞）: %s', [E.Message]);
      FAuditor.IncrementFaultCount;
      if FAuditor.IsFaulted then
        Logger.Critical('BodyZero 审计已因连续失败而禁用');
    end;
  end;

  // === Schema 版本变更检测 ===
  var QVer: TFDQuery;
  try
    QVer := TFDQuery.Create(FConnection);
    try
      QVer.Open('PRAGMA schema_version');
      var CurrentVer := QVer.Fields[0].AsInteger;
      if CurrentVer <> FSchemaVersionAtOpen then
      begin
        Logger.Warn('Schema 版本变更: %d → %d，刷新指纹',
          [FSchemaVersionAtOpen, CurrentVer]);
        FSchemaVersionAtOpen := CurrentVer;
        var NewFingerprint := GetSchemaFingerprint;
        if not TryResolveAdapter(NewFingerprint) then
          raise EExternalSchemaChanged.Create(
            'Schema changed but no matching adapter found');
      end;
    finally
      QVer.Free;  // v0.5：单一释放点，在 finally 中统一释放
    end;
  except
    on E: EExternalSchemaChanged do raise;
    on E: Exception do
      Logger.Warn('Schema 版本检测失败（非阻塞）: %s', [E.Message]);
  end;

  // === SQLITE_BUSY 自适应重试 ===
  var MaxRetries := 5;
  var BaseDelayMs := 200;
  for var Retry := 1 to MaxRetries + 1 do
  begin
    try
      // 写入拦截检查
      var SQL := Format('SELECT %s FROM %s',
        [string.Join(',', ColumnNames), TableName]);
      try
        if IsWriteStatement(SQL) then
        begin
          FAuditor.IncrementWriteAttempts;
          raise EWriteAttemptBlocked.Create('写入操作被阻止');
        end;
      except
        on E: EWriteAttemptBlocked do raise;
        on E: Exception do
          Logger.Error('写语句检查失败（非阻塞）: %s', [E.Message]);
      end;

      // 执行查询
      Result := TFDQuery.Create(FConnection);
      Result.Open(SQL);
      Exit;
    except
      on E: ESQLiteBusyError do
      begin
        if Retry > MaxRetries then
          raise EExternalDBError.Create(
            Format('数据库忙，已重试 %d 次（请等待微信完成数据操作后重试）',
              [MaxRetries]));
        Sleep(BaseDelayMs shl (Retry - 1));
      end;
      on E: EWriteAttemptBlocked do raise;
      on E: EExternalSchemaChanged do raise;
    end;
  end;
end;
```

## 8. 安全约束

1. 密钥使用 `TBytes` 传递，使用后 `FillChar` 清零
2. **三层只读防线** + C 层 authorizer 对 SELECT 也记录审计
3. **SafeQuery/SafeQueryAsDict 是唯二数据读取出口** — `OpenReadOnly` 返回 `IExternalDBReader` 接口
4. **审计降级不阻塞查询** — 审计代码包裹在 `try/except` 中
5. SQLITE_BUSY 5 次自适应重试 + EXCLUSIVE 模式快速失败
6. **Schema 版本变更检测** — SafeQuery 前检测 `PRAGMA schema_version`
7. C API 返回值全部检查
8. `GetRawSQLiteHandle` 不暴露给调用方
9. SafeQuery 线程亲和性声明
10. **v0.5**：`SafeQueryAsDict` 桥接层提供 TFDQuery→TDictionary 的标准转换，消费者无需手动编写转换代码
