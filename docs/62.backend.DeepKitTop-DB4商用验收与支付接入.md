## 1. 结论

DeepKit.top 是 Deep 系列工具统一认证和支付入口。下游工具不再各自实现 DB4，也不各自保存支付密钥。

服务器上的 `heyue.fyi` 不再作为统一认证/支付中台使用。DB4 后续统一命名和部署为 `deepkit` / `deepkit.top`。

本地合约冒烟测试已经跑通，但生产商用还需要接入真实 PostgreSQL、真实支付商户配置，并完成公网回调验收。

## 2. 架构边界

```text
Deep 系列桌面工具
    |
    | DeepBase SafeClient / DesktopLifecycle
    v
https://deepkit.top/dk/*
    |
    +-- PostgreSQL DB4: deepKit
    +-- WeChat Pay / Alipay / Stripe / PayPal
    +-- entitlement truth source
    +-- Ed25519 license snapshot signing
```

DeepBase 只做框架能力:

- 客户端登录态持有
- 安全 API 调用
- 权限判断和 quota 消耗
- paid upgrade flow
- license snapshot 验签

DeepKit.top 后端做可信能力:

- 用户身份和 refresh token
- 商品价格
- 订单状态
- 支付回调验签
- 权益发放和核销
- 授权快照签名
- 更新通道控制

## 4. 需要你提供的生产信息

当准备连接真实 DB4 时，需要:

- PostgreSQL 地址、端口、库名
- 数据库账号和密码，或完整 `DATABASE_URL`
- 公网 API 地址，例如 `https://deepkit.top`
- 是否先用测试库，还是直接连生产库

当准备接入微信支付时，需要:

- `WECHAT_APP_ID`
- `WECHAT_APP_SECRET`
- `WECHAT_PAY_MCH_ID`
- `WECHAT_PAY_API_V3_KEY`
- 商户 API 证书序列号
- 商户私钥 PEM 路径或安全注入方式
- 微信支付平台公钥/证书 PEM 路径
- 支付回调地址: `https://deepkit.top/dk/commerce/payments/wechat_pay/notify`

当准备接入支付宝时，需要:

- 支付宝 `APP_ID`
- 应用私钥
- 支付宝公钥/证书
- notify URL
- sandbox/production 环境选择
