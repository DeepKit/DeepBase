# DeepShell 新 VCL 程序接入指南

> audience: ai, developer
> status: design-contract

## 1. 适用场景

当你要开发一个新的 Windows VCL 工具软件时，从 `TDeepMainForm` 起步。

适合：

```text
DeepSpec
DeepCompare
DeepUITest
DeepConfig
DeepGuide Studio
DeepDev
治理/分析/配置/测试类桌面工具
```

不适合：

```text
纯控制台工具
纯服务端进程
极简单对话框工具
游戏或强定制 UI 产品
```

## 2. 新程序主窗体

```pascal
type
  TMainForm = class(TDeepMainForm)
  protected
    procedure RegisterServices; override;
    procedure RegisterCommands; override;
    procedure RegisterProviders; override;
  end;
```

不要从空 `TForm` 开始重复搭工具栏、日志、设置、MRU、布局。

## 3. 注册服务

```pascal
procedure TMainForm.RegisterServices;
begin
  inherited;
  Services.RegisterService('app.project', TMyProjectService.Create);
  Services.RegisterService('app.settings', TMySettingsService.Create);
end;
```

如果需要数据库：

```pascal
Services.RegisterService('db.connection', TMyDb1ConnectionService.Create);
Services.RegisterService('db.query', TMyDoQryExecutor.Create);
Services.RegisterService('db.pool', TMyPoolService.Create);
```

数据库服务是可选服务，不是 DeepMainForm 核心依赖。

## 4. 注册命令

```pascal
procedure TMainForm.RegisterCommands;
begin
  inherited;

  Commands.RegisterCommand(
    ShellCommand('app.project.open', 'Open Project')
      .Category('File')
      .Shortcut('Ctrl+O')
      .OnExecute(OpenProject));

  Commands.RegisterCommand(
    ShellCommand('app.scan.run', 'Run Scan')
      .Category('Run')
      .RiskLevel(1)
      .OnExecute(RunScan));
end;
```

高风险命令：

```pascal
Commands.RegisterCommand(
  ShellCommand('app.delete', 'Delete')
    .RiskLevel(3)
    .GateKey('app.delete_gate')
    .PurposeKey('app.manage')
    .OnExecute(DeleteSelected));
```

注意：`ShellCommand(...)` 是 DeepShell 建议实现的 fluent builder。如果当前代码尚未实现 builder，必须改用实际 API 注册命令，不要生成不可编译代码。

## 5. 注册 Provider

```pascal
procedure TMainForm.RegisterProviders;
begin
  inherited;
  RegisterStructureProvider(TMyStructureProvider.Create);
  RegisterMainViewProvider(TMyMainViewProvider.Create);
  RegisterInspectorProvider(TMyInspectorProvider.Create);
  RegisterSettingsPageProvider(TMyBusinessSettingsPage.Create);
end;
```

Provider 负责业务内容。DeepMainForm 只负责宿主和调度。

## 6. 主工作区

下游可以：

- 返回一个 Frame。
- 返回 HTML / Markdown / Text。
- 返回一个 WebView2 adapter。
- 返回自定义控件。

但不要让 DeepMainForm 核心直接依赖这些控件。

Provider 返回 `svkControl` / `svkFrame` 时，由 Provider 创建控件，Shell 挂载到 `MainHost`：

```pascal
View.Control.Parent := MainHost;
View.Control.Align := alClient;
```

第一版建议控件交给 Shell 拥有并释放。需要缓存视图时，由下游 Provider 明确管理生命周期。

## 7. 设置页

Shell 自带：

```text
常规
外观
语言
MRU
布局
日志
快捷键占位
服务状态
```

下游追加：

```text
项目规则
扫描配置
数据库连接
LLM 配置
浏览器配置
导出设置
```

## 8. 状态和日志

下游只调用统一状态接口：

```pascal
Status.Info('Scan started');
Status.Progress('scan', 30, 'Parsing files');
Status.Error('Scan failed', E);
```

不要每个软件自己做日志面板。

## 9. 最小验收

新程序完成最小接入后应能：

- 启动到工作台。
- 打开设置窗体。
- 切换主题和语言。
- 展开/折叠上中下三区。
- 打开/关闭左右悬浮窗。
- 注册并执行一个业务命令。
- 注册一个 fake Provider 并显示主视图。
- 关闭后恢复窗口和折叠状态。

## 10. 最小 Demo 项目结构

建议提供一个可运行 Demo，作为 AI scaffold 新程序时的模板。

```text
Examples/VCLDeepShellDemo/
├── VCLDeepShellDemo.dpr
├── VCLDeepShellDemo.dproj
├── Demo.MainForm.pas
├── Demo.Providers.pas
├── Demo.Services.pas
├── Demo.Commands.pas
└── README.md
```

文件职责：

```text
VCLDeepShellDemo.dpr
  初始化 DeepBase，创建 TDemoMainForm，关闭时 Finalize。

Demo.MainForm.pas
  TDemoMainForm = class(TDeepMainForm)
  只覆盖 RegisterServices / RegisterCommands / RegisterProviders。

Demo.Services.pas
  fake Recent / fake Layout / fake Settings / fake Theme / fake i18n。

Demo.Commands.pas
  注册 open, save, run, toggle panels, fake delete 等命令。

Demo.Providers.pas
  fake StructureProvider / MainViewProvider / InspectorProvider。

README.md
  说明这个 Demo 是新 VCL 软件起点，不是业务产品。
```

Demo 必须不依赖真实 Db1、doQry、LLM、WebView2、Governance。需要展示这些能力时，只注册 fake service 或 optional adapter。
