## 数据库错�?

### DeepBase initialization failed: No DB connection adapter registered

**完整提示**:

```text
DeepBase initialization failed: No DB connection adapter registered.
Include DeepBase.Persistence.Manager.FireDAC.
```

**原因**: `DeepBase.Manager` 与 FireDAC 持久化适配器已经解耦。最终程序只链接了 `DeepBase.Manager` / `DeepBaseCore`，没有链接 `DeepBase.Persistence.Manager.FireDAC`，所以 Manager 的 DB1 连接工厂没有在 unit initialization 阶段注册。

**解决方案**:

1. 源码直编时，在最终 `.dpr` 或启动 bootstrap 单元加入：
   ```pascal
   uses
     DeepBase.Manager,
     DeepBase.Persistence.Manager.FireDAC;
   ```
2. 确保该单元在第一次 `DeepBase.Initialize*` / `InitializeWithDB*` 前已经被链接。
3. 运行时包模式下，部署并依赖 `DeepBasePersistence.bpl`，不要只带 `DeepBaseCore.bpl`。
4. 不要用 `DeepBase.Persistence.RuntimeRegistration` 替代它；该单元只注册 RuntimeContext 的 DBPool 生命周期组件。
5. 如果已经加入仍报错，检查是否混用了源码版 `DeepBase.Manager` 和 package 版 `DeepBasePersistence`，导致 adapter 注册到了另一个 Manager 副本。
