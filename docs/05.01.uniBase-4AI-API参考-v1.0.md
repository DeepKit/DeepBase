## 1. 核心管理器

### UniBase.Manager

管理器单例，所有 UniBase 功能的入口点。

#### 属性

| 属性 | 类型 | 说明 |
|------|------|------|
| `Initialized` | `Boolean` | 系统是否已初始化 |
| `Config` | `TUniBaseConfig` | 配置管理器实例 |
| `i18n` | `TUniBasei18n` | 国际化实例 |
| `Log` | `TUniBaseLogging` | 日志管理器实例 |
| `Connection` | `TFDConnection` | 数据库连接 |
| `DatabasePath` | `string` | 数据库文件路径 |
| `Version` | `string` | 框架版本号 |

#### 方法

##### Initialize

```delphi
class function Initialize(const DatabasePath: string = ''): Boolean;
```

初始化 UniBase 系统。

**参数:**
- `DatabasePath`: 配置数据库路径，默认为 `config.db`

**返回值:** 初始化是否成功

**示例:**
```delphi
if not UniBase.Initialize('myapp.db') then
  raise Exception.Create('Failed to initialize UniBase');
```

##### Finalize

```delphi
class procedure Finalize;
```

释放所有 UniBase 资源。

**示例:**
```delphi
procedure TMainForm.FormDestroy(Sender: TObject);
begin
  UniBase.Finalize;
end;
```

##### GetConfig / SetConfig (便捷方法)

```delphi
class function GetConfig(const Key: string; const Default: string = ''): string;
class procedure SetConfig(const Key, Value: string);
```

配置读写的便捷方法。

## 4. 日志模块

### TUniBaseLogging

日志模块，支持多级别日志和多种输出目标。

#### 日志级别

```delphi
TLogLevel = (llDebug, llInfo, llWarn, llError, llFatal);
```

#### 方法

##### Debug / Info / Warn / Error / Fatal

```delphi
procedure Debug(const Message: string; const Category: string = '');
procedure Info(const Message: string; const Category: string = '');
procedure Warn(const Message: string; const Category: string = '');
procedure Error(const Message: string; const Category: string = ''); overload;
procedure Error(const Message: string; E: Exception); overload;
procedure Fatal(const Message: string; const Category: string = '');
```

记录不同级别的日志。

**示例:**
```delphi
Log.Debug('Processing started');
Log.Info('User logged in: ' + Username);
Log.Warn('Configuration file not found, using defaults');
Log.Error('Database connection failed', E);
Log.Fatal('Critical system error');
```

##### Log

```delphi
procedure Log(Level: TLogLevel; const Message: string; 
  const Category: string = ''; E: Exception = nil);
```

通用日志方法。

##### BeginTiming

```delphi
function BeginTiming(const Operation: string): ILogTimer;
```

开始性能计时。

**示例:**
```delphi
var Timer := Log.BeginTiming('DataLoad');
try
  LoadData;
finally
  Timer.Stop;  // 自动记录: "DataLoad completed in 123 ms"
end;
```

##### Query

```delphi
function Query(const Filter: TLogFilter): TArray<TLogEntry>;
```

查询日志记录。

##### Clear

```delphi
procedure Clear(BeforeDate: TDateTime = 0);
```

清除日志（可指定日期前的日志）。

#### 属性

| 属性 | 类型 | 说明 |
|------|------|------|
| `MinLevel` | `TLogLevel` | 最低日志级别 |
| `MaxFileSize` | `Int64` | 日志文件最大大小 |
| `MaxFiles` | `Integer` | 保留的日志文件数量 |
| `LogToFile` | `Boolean` | 是否写入文件 |
| `LogToDatabase` | `Boolean` | 是否写入数据库 |
| `LogFilePath` | `string` | 日志文件路径 |

## 6. 数据绑定

### TDataBinder

数据绑定器。

#### 方法

##### Bind

```delphi
procedure Bind(Source: TObject; const SourceProperty: string;
  Target: TObject; const TargetProperty: string;
  Mode: TBindingMode = bmOneWay;
  Converter: TValueConverter = nil);
```

绑定属性。

**参数:**
- `Source`: 数据源对象
- `SourceProperty`: 源属性名
- `Target`: 目标对象（通常是控件）
- `TargetProperty`: 目标属性名
- `Mode`: 绑定模式 (OneWay, TwoWay, OneWayToSource)
- `Converter`: 值转换器

**示例:**
```delphi
// 单向绑定
Binder.Bind(User, 'Name', edtName, 'Text');

// 双向绑定
Binder.Bind(User, 'Active', chkActive, 'Checked', bmTwoWay);

// 带转换器
Binder.Bind(User, 'BirthDate', lblAge, 'Caption', bmOneWay,
  function(Value: TValue): TValue
  begin
    Result := FormatDateTime('yyyy-mm-dd', Value.AsType<TDateTime>);
  end);
```

##### Unbind

```delphi
procedure Unbind(Target: TObject; const TargetProperty: string = '');
```

解除绑定。

##### UnbindAll

```delphi
procedure UnbindAll;
```

解除所有绑定。

##### UpdateSource

```delphi
procedure UpdateSource;
```

手动更新源对象。

##### UpdateTarget

```delphi
procedure UpdateTarget;
```

手动更新目标对象。

## 13. 指标收集模块

### UniBase.Metrics

应用指标收集系统。

#### TCounter

计数器指标（单调递增）。

```delphi
var Counter := TMetrics.Counter('http_requests_total');
Counter.Inc;       // +1
Counter.Inc(5);    // +5
```

#### TGauge

仪表盘指标（即时值）。

```delphi
var Gauge := TMetrics.Gauge('memory_usage_bytes');
Gauge.SetValue(1024 * 1024);
Gauge.Inc(100);
Gauge.Dec(50);
```

#### THistogram

直方图指标（分布统计）。

```delphi
var Hist := TMetrics.Histogram('response_time_seconds');
Hist.Observe(0.25);
var Mean := Hist.Mean;
var P99 := Hist.Buckets;
```

#### TMetricsRegistry

指标注册表。

```delphi
var JSON := Registry.ToJSON;           // JSON 格式
var Prom := Registry.ToPrometheus;     // Prometheus 格式
var Influx := Registry.ToInfluxLines;  // InfluxDB 行协议
```

> 详细的集成流程与运营规则，请参考《10.01.uniBase-4AI-发布、更新与解锁系统集成指南》与《10.03.uniBase-4H-私域流量运营指南》。

### 15.1 Unlock 管理器（TUnlockManager）

解锁与私域引流的核心管理类，通常通过全局实例 `UnlockMgr` 使用。

#### 枚举类型

```delphi
type
  TUnlockLevel = (ulFree, ulFollow, ulShare);
```

- `ulFree`  : 免费版（未解锁）
- `ulFollow`: 关注版（通过关注公众号获取解锁码）
- `ulShare` : 分享版（通过分享获取更高级解锁码）

#### 关键属性

| 属性 | 类型 | 说明 |
|------|------|------|
| `ProductCode` | `string` | 产品代码（如 'TK'、'OS'，对应解锁码前缀） |
| `ProductName` | `string` | 软件中文名（如『双键快启』『全能同步』） |
| `WeChatAccountId` | `string` | 公众号微信号（如 `aizhihuilab`） |
| `WeChatKeyword` | `string` | 用户在公众号内需要回复的关键词（如『双键』『同步』） |
| `QRCodeImage` | `string` | 用于展示在解锁弹窗中的公众号二维码图片路径 |

#### 关键方法

```delphi
function GetUnlockLevel: TUnlockLevel;
function IsFullUnlocked: Boolean;
procedure ShowUnlockDialog;
```

- `GetUnlockLevel`：根据当前设备已输入的解锁码，返回对应解锁等级。
- `IsFullUnlocked`：是否已处于最高解锁等级（通常对应 ulShare 或自定义最高级）。
- `ShowUnlockDialog`：弹出统一的解锁对话框，引导用户扫码关注公众号并输入解锁码。

#### 使用示例

```delphi
uses UniBase.Unlock;

procedure TMainForm.FormCreate(Sender: TObject);
begin
  // 初始化 Unlock 参数（建议在程序启动时配置一次）
  UnlockMgr.ProductCode    := 'TK';          // TwoKeyRun
  UnlockMgr.ProductName    := '双键快启';
  UnlockMgr.WeChatAccountId:= 'aizhihuilab';
  UnlockMgr.WeChatKeyword  := '双键';
  UnlockMgr.QRCodeImage    := 'res\\wechat_qr.png';
end;

procedure TMainForm.UpdateSlotsByUnlock;
begin
  case UnlockMgr.GetUnlockLevel of
    ulFree:   Slots := 24;
    ulFollow: Slots := 58;  // 关注版
    ulShare:  Slots := 60;  // 分享版（完整功能）
  end;
end;

procedure TMainForm.BtnUnlockClick(Sender: TObject);
begin
  if not UnlockMgr.IsFullUnlocked then
    UnlockMgr.ShowUnlockDialog;
end;
```

> 约定：
> - `ProductCode` 必须与解锁码前缀一致（如 TK2601A / OS2601A）。
> - `WeChatKeyword` 必须与公众号自动回复中配置的关键词一致（如『双键』『同步』）。
> - 所有新程序应在主窗口或核心功能处调用 `ShowUnlockDialog`，保证用户易于发现解锁入口。
