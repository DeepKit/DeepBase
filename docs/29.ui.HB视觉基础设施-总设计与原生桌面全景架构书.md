## 1. 文档法位与事实分级原则

### 1.1 文档职责边界
- **本文件负责**：
  1. 冻结 HB 视觉语言基础规范（色彩、排版、间距、状态、图标、无障碍、动效）；
  2. 确立桌面原生能力架构、停靠/悬浮机制与多屏自适应规则；
  3. 提供全系组件的**精确成熟度分级、契约定义与可复现验证证据**。
- **本文件不负责**：
  1. 代替下游具体业务界面的 PRD 需求定义；
  2. 包含未经测量验证的营销化宣称；
  3. 将原型阶段（PROTOTYPE）或规划阶段（PLANNED）的组件作为已就绪 API 供下游生产环境直接引用。

### 3.4 交互十态矩阵 (Interaction State Matrix)

所有交互元素（Button, Node, Tab, Row, Card）必须实现确定性的十态反馈：

1. **Default**：基础面与标准描边；
2. **Hover**：背景提亮为 `SurfaceAlt`，鼠标指针切换为 `crHandPoint`；
3. **Pressed**：背景微暗，内容向右下偏移 1px 物理触感反馈；
4. **Focus-Visible**：外围渲染 **2px 独立高亮焦点环（`BorderFocus`）**，与内边保留 1px 呼吸间隙；
5. **Selected**：背景填充 `Primary`（低透明度），左侧或底部显示 3px 坚固指示光条；
6. **Disabled**：整体透明度降为 `0.4`，文字转为 `InkMuted`，阻断所有鼠标键盘事件；
7. **Loading**：右侧展示微型旋转等待环或呼吸脉冲，禁用连击；
8. **Error / Invalid**：边框变红（`Danger`），外加红框发光与气泡错误说明；
9. **Read-Only**：背景转为 `Sunken`，文字保持清晰但去除非必要光标与高亮；
10. **Drag / Drop Target**：外边框呈现 2px 虚线并填充 `Primary` 10% 柔和底色。

### 3.5 矢量图标规范（替换 Emoji 原型符号）
- **图标资产格式**：必须采用 **SVG Path 纯矢量几何数据** 或 **Delphi 内建 GDI+/Skia 矢量路径**；
- **尺寸档位**：标准提供 **16x16 px (S)**、**20x20 px (M)**、**24x24 px (L)** 三档；
- **线宽标准**：统一保持 **1.5 px**（常规）或 **2.0 px**（粗体）；
- **Emoji 限制令**：**禁止在系统主导航、操作按钮、错误报警与数据网格中使用系统彩色 Emoji**；Emoji 仅允许在用户自定义文本备注、欢迎页或宣传横幅中出现。

### 3.6 无障碍与动效减弱规范 (Accessibility & Reduced Motion)
1. **对比度硬门禁**：所有常规正文与背景必须达到 **WCAG 2.1 AA 级（≥ 4.5:1）**，大标题达到 **≥ 3.0:1**；
2. **键盘全可达**：所有功能必须可通过 `Tab`、`Shift+Tab`、`Enter`、`Space`、`Esc` 与方向键完整操作，禁止裸 `div onclick`；
3. **`prefers-reduced-motion` 响应策略**：
   - 当检测到 Windows 系统开启“在 Windows 中关闭动画”时，所有位移动画瞬时切换为单帧瞬切，过渡动效降级为简单淡入淡出（< 100ms）；
   - 呼吸灯频率锁定在 `< 1.0Hz`，严禁任何可能诱发光敏性癫痫的 > 3Hz 高频闪烁；
4. **后台节能降帧**：窗口处于后台或最小化至托盘时，**动效调度器（`THbAnimationTicker`）立即休眠并暂停全部渲染刷新**，CPU 占用归零。

## 6. 多显示器等比自适应与物理视觉一致性规范

针对 **4K 150%/200% 主屏 + 1080p 100% 副屏 + 超宽屏**，HB 确立三项确定性布局算法：

1. **动态 DPI 矢量自适应**：
   - 响应 `WM_DPICHANGED`，按 `NewDPI / 96.0` 浮点比例实时缩放 `SizeM`、`RadiusM`、`SpaceM`、`RowHeight`；
   - GDI+ 浮点坐标重算，严禁使用拉伸位图。
2. **工作区相对比例锚定 (`THbWindowProportion`)**：
   - 窗口声明期望比例：`WidthRatio = 0.65`（占当前屏幕可用宽度的 65%），`HeightRatio = 0.75`；
   - 跨屏移动触发 `OnMonitorChange` 时，基于目标显示器 `TMonitor.WorkareaRect` 自动等比调整尺寸并居中。
3. **屏幕拔插逃生机制（Off-Screen Window Rescue）**：
   - 监听 `WM_DISPLAYCHANGE` 消息，若发现窗口保存的历史坐标落在当前所有有效屏幕的可视区域之外（如副屏已被拔掉），**自动将窗口平滑移动至主显示器（Primary Monitor）安全居中位置**，杜绝“隐形窗口”故障。
