# DeepBase 架构全景

> 一份文档讲清楚 DeepBase 是什么、怎么组织的、怎么用。
> 更新：2026-06-02

---

## 1. 一句话定义

DeepBase 是 **Delphi 桌面应用基础框架**，相当于 Delphi 世界的 Spring Boot。它提供配置、日志、国际化、数据库访问、LLM 调用、语音识别、商业化流程、自动更新、AI 错误自动修复、VCL/FMX 控件等 30+ 通用能力，避免每个下游项目重复实现基础设施。

## 2. 仓库目录结构

```
DeepBase/
├── Core/              # 核心运行时（无 UI/DB 依赖）
├── Services/          # IoC / EventBus / Scheduler / Resilience
├── Persistence/       # FireDAC DB 适配 / DoQry / ORM
├── Governance/        # OCGS 治理（门禁 / 证据 / 路由）
├── Features/          # 可选功能（LLM / Speech / Commerce / Updater）
├── VCL/               # VCL 控件与适配器
├── FMX/               # FMX 控件
├── ThirdParty/        # 第三方 SDK 适配（支付 / 社交 / UI）
├── Tools/             # Studio / CLI / SeedTool / UniPublisher
├── Tests/             # 单元测试与集成测试（含 AutoFix 测试）
├── Examples/          # 示例工程
├── Scripts/           # 构建 / 测试 / AutoFix 自动化脚本
├── docs/              # 文档（50 个编号文件）
├── sql/               # Schema 创建与升级脚本
├── data/              # 样例数据库
│
├── ARCH-QUICKSTART.md # AI 入口指南
├── README.md          # 项目主页
├── bugfix.md          # 主 Bug 台账
├── history.md         # 开发历史
├── tasks.md           # 活跃任务
└── *.dpk / *.dproj    # 包定义文件
```

## 6. AutoFix — AI 驱动的运行时错误自动修复

AutoFix 是 DeepBase 内建的错误自动修复子系统，通过三层机制实现"崩溃→诊断→AI修复→验证"的闭环。

### 6.1 架构

```
应用程序崩溃 / 异常
        │
        ▼
┌───────────────────┐
│  VCL/FMX Hook     │  ← 全局异常拦截（Application.OnException）
└───────┬───────────┘
        │
        ▼
┌───────────────────┐
│  AIErrorHandler   │  ← 四级错误分类 + AI 分析
│  ├─ elIgnore      │     静默丢弃（EAbort 等用户取消操作）
│  ├─ elAutoFix     │     自动修复（类型转换错误、参数错误）
│  ├─ elAIAnalyze   │     LLM 生成用户友好的中文提示
│  └─ elFatal       │     致命错误（AV/OOM/栈溢出，安全退出）
└───────┬───────────┘
        │
        ▼
┌───────────────────┐
│  AutoFix Engine   │  ← 错误录制 + 场景验证 + 健康信号
│  ├─ ErrorRecorder │     录制错误上下文（异常类型、堆栈、操作名）
│  ├─ ScenarioRunner│     回放注册场景验证修复效果
│  ├─ HealthSignal  │     写入 health-signal.json（进程存活/退出码）
│  ├─ SelfTerminator│     超时或异常时自动终止进程
│  └─ StackWalker   │     Delphi 原生堆栈回溯（无 JCL 依赖）
└───────┬───────────┘
        │
        ▼
┌───────────────────┐
│  AI Bridge         │  ← LLM 调用 + 缓存
│  ├─ Claude/OpenAI │     多模型支持（通过 ai-call.ps1）
│  ├─ 缓存机制       │     相同错误不重复调用 AI
│  └─ LLMBridge     │     Pascal 侧 LLM 桥接
└───────────────────┘
```

### 6.2 核心模块

| 模块 | 文件 | 职责 |
|------|------|------|
| **AutoFix 入口** | `Core/DeepBase.AutoFix.pas` | 统一 facade：`Install` / `RegisterScenario` / `NotifyShellShown` |
| **ErrorRecorder** | `Core/DeepBase.AutoFix.ErrorRecorder.pas` | 录制错误上下文（异常类型、堆栈、操作名） |
| **ScenarioRunner** | `Core/DeepBase.AutoFix.ScenarioRunner.pas` | 回放场景验证修复效果 |
| **HealthSignal** | `Core/DeepBase.AutoFix.HealthSignal.pas` | 写入 `health-signal.json`（进程存活/退出码） |
| **SelfTerminator** | `Core/DeepBase.AutoFix.SelfTerminator.pas` | 超时或异常时自动终止进程 |
| **StackWalker** | `Core/DeepBase.AutoFix.StackWalker.pas` | Delphi 原生堆栈回溯（无 JCL 依赖） |
| **AIErrorHandler** | `Core/DeepBase.AIErrorHandler.pas` | 四级错误分类 + LLM 用户提示生成 |
| **AIErrorHandler.Bootstrap** | `Core/DeepBase.AIErrorHandler.Bootstrap.pas` | 启动引导 |
| **AIErrorHandler.LLMBridge** | `Core/DeepBase.AIErrorHandler.LLMBridge.pas` | LLM 调用桥接 |
| **VCL Hook** | `VCL/DeepBase.AutoFix.VclHook.pas` | VCL 全局异常拦截 |
| **FMX Hook** | `FMX/DeepBase.AutoFix.FmxHook.pas` | FMX 全局异常拦截 |

### 6.3 最小集成

```delphi
program MyApp;
uses
  DeepBase.Manager,
  DeepBase.AutoFix,               // AutoFix 引擎
  DeepBase.AIErrorHandler;        // AI 错误处理

begin
  Application.Initialize;

  // 1. AutoFix 引擎（命令行 --autofix-mode 激活，否则无操作）
  AutoFix.Install;
  AutoFix.RegisterScenario('smoke',
    procedure begin CheckCriticalFeatures; end);

  // 2. AI 错误处理器（全局异常拦截 + LLM 友好提示）
  TAIErrorHandler.Install;
  TAIErrorHandler.SetAICallback(
    function(const APrompt: string): string
    begin
      Result := LLM.Chat(TierFast, APrompt);
    end);

  DeepBase.InitializeOrRaise;
  Application.CreateForm(TMainForm, MainForm);
  Application.Run;
  DeepBase.Finalize;
end.
```

### 6.4 SafeRun — 业务代码零 try/except

```delphi
// 传统方式：
try
  SaveOrder(FOrder);
except
  on E: Exception do
    ShowMessage('保存失败：' + E.Message);
end;

// AutoFix 方式：
SafeRun('保存订单', procedure begin SaveOrder(FOrder) end);
// → 自动分类错误，AI 生成用户友好中文提示，无需手动 try/except
```

### 6.6 命令行激活


## 8. 配置铁律（必须遵守）

1. **唯一外部配置文件是 `root.txt`**
2. **所有配置进 DB1 ConfigDB**，不在下游项目散落 JSON/INI/YAML 文件
3. **敏感数据走 `DeepBase.Security`**（DPAPI / UBS2），不写明文
4. **UI 线程禁止同步重试 / 长耗时操作**
5. **客户端不直连 DB4**，支付只信任后端通知

## 9. 快速开始

### 最小集成

```delphi
program MyApp;
uses
  DeepBase.Manager,
  DeepBase.Persistence.Manager.FireDAC;
begin
  DeepBase.InitializeOrRaise;
  // 你的业务代码...
  DeepBase.Finalize;
end.
```

### 需要什么包

```
不需要 DB      → DeepBaseCore.dpk
需要 DB/DoQry  → + DeepBasePersistence.dpk
需要 IoC/EventBus/Scheduler → + DeepBaseServices.dpk
需要 Governance → + DeepBaseGovernance.dpk
需要 LLM/Commerce 基础能力 → + DeepBaseFeatures.dpk

语音合成(TTS)  → + DeepBaseSpeechTTS.dpk
声纹识别       → + DeepBaseSpeechVoice.dpk
唤醒词检测     → + DeepBaseSpeechWake.dpk
VCL 界面       → + DeepBaseVCL.dpk

```

| 测试框架 | DUnitX |
