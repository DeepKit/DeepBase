# DeepBase AutoFix — AI 驱动的运行时错误自动修复

> 面向接入 AutoFix 子系统的开发者。
> 更新：2026-06-02

---

## 1. 概述

AutoFix 是 DeepBase 内建的 **AI 驱动运行时错误自动修复子系统**，由三部分组成：

1. **AutoFix Engine**（Pascal 侧）— 错误录制、场景回放、健康信号、堆栈回溯
2. **AIErrorHandler**（Pascal 侧）— 四级错误分类 + LLM 用户提示生成
3. **autofix.ps1**（PowerShell 侧）— 编译→测试→收集错误→AI 修复→重试 的全自动循环

三者协同，实现"崩溃→诊断→AI 修复→验证"的闭环。

## 3. 核心模块

### 3.1 AutoFix Engine（Pascal 侧）

| 模块 | 文件 | 职责 |
|------|------|------|
| **AutoFix** | `Core/DeepBase.AutoFix.pas` | 统一 facade：`Install` / `RegisterScenario` / `NotifyShellShown` |
| **ErrorRecorder** | `Core/DeepBase.AutoFix.ErrorRecorder.pas` | 录制错误上下文：异常类型、堆栈、操作名、时间戳 |
| **ScenarioRunner** | `Core/DeepBase.AutoFix.ScenarioRunner.pas` | 回放已注册场景，验证修复效果 |
| **HealthSignal** | `Core/DeepBase.AutoFix.HealthSignal.pas` | 写入 `health-signal.json`（进程存活/退出码/耗时） |
| **SelfTerminator** | `Core/DeepBase.AutoFix.SelfTerminator.pas` | 超时或致命错误时自动终止进程 |
| **StackWalker** | `Core/DeepBase.AutoFix.StackWalker.pas` | Delphi 原生堆栈回溯（使用 `ExceptAddr`，无 JCL 依赖） |

### 3.2 AIErrorHandler（Pascal 侧）

| 模块 | 文件 | 职责 |
|------|------|------|
| **AIErrorHandler** | `Core/DeepBase.AIErrorHandler.pas` | 四级错误分类 + LLM 用户提示生成 + `SafeRun` 包装器 |
| **Bootstrap** | `Core/DeepBase.AIErrorHandler.Bootstrap.pas` | 启动引导：自动注册到 Application.OnException |
| **LLMBridge** | `Core/DeepBase.AIErrorHandler.LLMBridge.pas` | LLM 调用桥接：缓存、超时、降级 |

## 4. 集成方式

### 4.1 最小集成（AIErrorHandler 独立使用）

```delphi
program MyApp;
uses
  DeepBase.Manager,
  DeepBase.Persistence.Manager.FireDAC,
  DeepBase.AIErrorHandler;
begin
  Application.Initialize;

  // 安装 AI 错误处理器
  TAIErrorHandler.Install;
  TAIErrorHandler.SetAICallback(
    function(const APrompt: string): string
    begin
      Result := LLM.Chat(TierFast, APrompt);
    end);

  DeepBase.InitializeOrRaise;
  Application.CreateForm(TMainForm, MainForm);
  Application.Run;
  DeepBase.Finalize;
end.
```

### 4.2 完整集成（AutoFix Engine + AIErrorHandler）

```delphi
program MyApp;
uses
  DeepBase.Manager,
  DeepBase.Persistence.Manager.FireDAC,
  DeepBase.AutoFix,               // AutoFix 引擎
  DeepBase.AIErrorHandler;        // AI 错误处理

begin
  Application.Initialize;

  // 1. AutoFix 引擎
  AutoFix.Install;
  AutoFix.RegisterScenario('check_db',
    procedure begin DiagnoseAll(ConfigDB); end);
  AutoFix.RegisterScenario('check_llm',
    procedure begin LLM.TestConnection; end);

  // 2. AI 错误处理器
  TAIErrorHandler.Install;
  TAIErrorHandler.SetAICallback(
    function(const APrompt: string): string
    begin
      Result := LLM.Chat(TierFast, APrompt);
    end);

  DeepBase.InitializeOrRaise;

  Application.CreateForm(TMainForm, MainForm);
  Application.Run;

  // 通知 AutoFix 引擎主窗体已显示，触发场景回放
  AutoFix.NotifyShellShown;

  DeepBase.Finalize;
end.
```

### 4.3 SafeRun 包装器

```delphi
// 不需要 AutoFix 引擎，只需 AIErrorHandler 即可使用
// 自动分类错误，elAIAnalyze 级别调用 LLM 生成中文提示

// 传统方式：
try
  SaveOrder(FOrder);
except
  on E: Exception do
    ShowMessage('保存失败：' + E.Message);
end;

// SafeRun 方式（零 try/except）：
SafeRun('保存订单', procedure begin SaveOrder(FOrder) end);
```

## 5. 错误分类逻辑

| 级别 | 触发条件 | 行为 |
|------|---------|------|
| **elIgnore** | `EAbort`（用户取消操作） | 静默丢弃，不记录 |
| **elAutoFix** | `EConvertError`、`EArgumentException` | 记录日志，不打扰用户 |
| **elAIAnalyze** | 其他所有异常 | 调用 LLM 生成中文提示 → `MessageDlg` 显示给用户 |
| **elFatal** | `EStackOverflow`、`EOutOfMemory`、`EAccessViolation` | 记录 Fatal 日志 → 安全退出（`SilentMode` 下 `ExitCode=1; Halt(1)`） |

## 6. 命令行激活

```powershell
# 启动 AutoFix 模式（无此参数时 AutoFix.Install 是空操作）
MyApp.exe --autofix-mode --autofix-scenario=smoke

# PowerShell 全自动修复循环
Scripts\autofix\autofix.ps1 `
  -Project MyApp `
  -Scenario smoke `
  -MaxIterations 10 `
  -CI

# 参数说明：
#   -Project       项目名（对应 .dproj 文件）
#   -Scenario      场景名（对应 RegisterScenario 注册的场景）
#   -MaxIterations 最大修复迭代次数（默认 10）
#   -CI            CI 模式（无交互，ExitCode 反映结果）
```

## 7. 配置选项

### AIErrorHandler 配置

```delphi
var
  Config: TAIErrorConfig;
begin
  Config := TAIErrorConfig.Default;
  Config.AIEnabled := True;           // 启用 AI 分析（默认 True）
  Config.MaxCacheSize := 50;          // 缓存大小（默认 50）
  Config.AITimeoutMs := 8000;         // AI 调用超时（默认 8000ms）
  Config.ShowTechnicalDetails := False; // 向用户显示技术细节（默认 False）
  Config.SilentMode := False;         // 静默模式（测试/非交互用）
  TAIErrorHandler.Install(Config);
end;
```

### AutoFix 命令行参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--autofix-mode` | 激活 AutoFix 引擎 | 不激活 |
| `--autofix-scenario` | 指定要运行的场景名 | 无 |
| `--autofix-timeout` | 场景超时（秒） | 30 |
| `--autofix-health-signal` | 健康信号输出路径 | `health-signal.json` |

## 8. 设计约束

1. **AutoFix.Install 是无操作的安全调用**：当 `--autofix-mode` 不在命令行中时，所有 facade 方法都是空操作，零文件写入。
2. **AIErrorHandler 不依赖 LLM**：如果 `SetAICallback` 未设置或 LLM 不可用，自动降级为通用中文提示。
3. **AIErrorHandler 自身不崩溃**：`CallAI` 内部有 try/except，任何 AI 调用失败都返回空字符串。
4. **SafeRun 不吞异常**：`elFatal` 级别仍然会导致进程退出，只是先记录日志和友好提示。
5. **堆栈回溯无 JCL 依赖**：使用 Delphi 内置的 `ExceptAddr` 和 `System.SysUtils.Exception`，不依赖 JCL/JVCL。
6. **diff-guard 保护关键文件**：`.dpk`、`.dproj`、`.editorconfig` 等文件默认锁定，AI 不得修改。
