# 02. UniBase 开发指南

> 本文档整合了快速启动、架构理念、开发规范和最佳实践，是所有开发者的首选阅读材料。

---

## 1. 快速启动 Checklist

> 新项目落地前，逐项检查以下 10 点：

### 1.1 目录与锚点

- [ ] 已创建 `root.txt` 并指向项目根目录
- [ ] 项目根包含 `config.db`、`assets/`、（可选）`logs/`

### 1.2 程序入口

- [ ] `dpr` 中调用 `UniBase.InitializeEx`，失败弹出明确错误并退出
- [ ] 程序退出时调用 `UniBase.Finalize`

### 1.3 编码与资源

- [ ] 所有 `.pas/.dfm` 保存为 UTF-8，DFM 为"文本格式"
- [ ] 大资源文件放入 `assets/`，不嵌入 EXE

### 1.4 分层与命名

- [ ] 使用 View/Ctrl/Model/uDM 四层，禁止 View 直接访问数据库
- [ ] 接口单元采用 `*Intf.pas` 命名，避免循环引用

### 1.5 窗体状态与 UI

- [ ] 需要记忆状态的窗体放置 `TFormStateHelper`（AutoSave/AutoRestore=True）
- [ ] 设置窗体使用 `TConfig*` 系列控件绑定配置

### 1.6 国际化

- [ ] 代码中使用 `T()`/`TFmt()`，界面使用 `TI18n*` 控件
- [ ] 运行 Studio/CLI 完成源码扫描与翻译导入

### 1.7 日志

- [ ] 初始化日志级别与存储模式（DB/File/Both）
- [ ] 关键路径记录 INFO/ERROR，严禁记录明文敏感信息

### 1.8 数据库

- [ ] `uDM` 仅负责连接业务库（PostgreSQL/SQLite），事务显式管理
- [ ] 如使用 doQry，已配置查询与参数 Schema

### 1.9 安全

- [ ] 敏感配置通过 `SetConfigSecure/GetConfigSecure` 存取（DPAPI）
- [ ] Studio 侧启用 SQL 模板静态校验

### 1.10 测试

- [ ] 提供内存/独立测试库初始化路径（`InitializeWithDB(':memory:')`）
- [ ] FAQ/故障排除文档联通

## 2. 核心架构理念

### 2.1 双数据库策略

| 数据库     | 文件名         | 引擎            | 职责              | 托管方        |
| ------- | ----------- | ------------- | --------------- | ---------- |
| **配置库** | `config.db` | SQLite        | 配置、日志、i18n、窗体状态 | UniBase 框架 |
| **业务库** | 自定义         | PostgreSQL/其他 | 订单、用户等业务数据      | 开发者 (uDM)  |

**原则：**

- 禁止在 `config.db` 中创建业务表
- 禁止在业务库中存储"窗体位置"等本地状态

### 2.2 目录结构

```
{ProjectRoot}/
├── root.txt          # 锚点文件，内容为根目录路径
├── config.db         # UniBase 配置数据库
├── assets/           # 资源目录
│   ├── icons/
│   ├── images/
│   ├── flags/
│   └── styles/
└── logs/             # 日志目录（可选）
```

### 2.3 四层分层模型

```
View (UI) → Ctrl (业务逻辑) → uDM (数据访问) → 数据库
              ↓
         UniBase Core (配置/日志/i18n)
```

| 层级       | 职责            | 禁止                |
| -------- | ------------- | ----------------- |
| **View** | UI 交互、调用 Ctrl | 直接 SQL、引用 FireDAC |
| **Ctrl** | 业务逻辑          | 引用 Vcl.Forms      |
| **uDM**  | 连接业务库         | UI 代码             |

### 2.4 关键变更（对比旧规范）

- **废弃**：`TIniFile`、`TRegistry`、手动 `Languages/*.ini`
- **新增**：`root.txt` 机制、`UniBase.Initialize`

## 3. 命名规范

### 3.1 文件命名（零目录层级）

| 类别   | 前缀      | 示例                 |
| ---- | ------- | ------------------ |
| 视图层  | `View`  | `ViewMain.pas`     |
| 控制层  | `Ctrl`  | `CtrlOrder.pas`    |
| 模型层  | `Model` | `ModelUser.pas`    |
| 数据模块 | `uDM`   | `uDM.pas`          |
| 接口单元 | `*Intf` | `UserViewIntf.pas` |

### 3.2 控件命名

| 控件      | 前缀  | 示例          |
| ------- | --- | ----------- |
| TButton | btn | btnSubmit   |
| TEdit   | edt | edtUserName |
| TLabel  | lbl | lblStatus   |

### 3.3 变量命名

- **私有字段**：`F` 前缀（`FUser: TUser`）
- **局部变量**：`L` 前缀（`LCount: Integer`）
- **参数**：`A` 前缀（`AValue: string`）

## 4. 代码模板

### 4.1 标准窗体

```pascal
unit ViewUserList;

interface

uses
  Vcl.Forms, UniBase.VCL.Controls, UniBase.VCL.FormStateHelper,
  CtrlUser;

type
  TfrmUserList = class(TForm)
    btnSearch: TI18nButton;
    FormStateHelper1: TFormStateHelper;  // AutoSave=True
    procedure FormCreate(Sender: TObject);
    procedure btnSearchClick(Sender: TObject);
  private
    FCtrl: IUserCtrl;
  end;

implementation

uses UniBase.Manager;

procedure TfrmUserList.FormCreate(Sender: TObject);
begin
  FCtrl := TUserCtrl.Create;
end;

procedure TfrmUserList.btnSearchClick(Sender: TObject);
begin
  FCtrl.SearchUsers(edtKeyword.Text);
end;
```

### 4.2 Controller 模板

```pascal
unit CtrlUser;

interface

type
  IUserCtrl = interface
    procedure SearchUsers(const Keyword: string);
  end;

  TUserCtrl = class(TInterfacedObject, IUserCtrl)
  public
    procedure SearchUsers(const Keyword: string);
  end;

implementation

uses UniBase.Manager, uDM;

procedure TUserCtrl.SearchUsers(const Keyword: string);
begin
  LogInfo('Searching: ' + Keyword);
  var PageSize := UniBase.GetConfigInt('UI.PageSize', 20);
  try
    uDM.Default.SearchUsers(Keyword, PageSize);
  except
    on E: Exception do
    begin
      LogError('Search failed: ' + E.Message);
      raise;
    end;
  end;
end;
```

### 4.3 uDM 模板

```pascal
unit uDM;

interface

uses FireDAC.Comp.Client;

type
  TDM = class(TDataModule)
    FDConnection1: TFDConnection;
    procedure DataModuleCreate(Sender: TObject);
  end;

implementation

uses UniBase.Manager;

procedure TDM.DataModuleCreate(Sender: TObject);
begin
  FDConnection1.Params.Values['Server'] := UniBase.GetConfig('Db.Host', 'localhost');
  FDConnection1.Params.Values['Password'] := UniBase.GetConfigSecure('Db.Password');
end;
```

## 5. 国际化 (i18n)

### 5.1 代码翻译

```pascal
// 错误
ShowMessage('操作成功');

// 正确
ShowMessage(T('Operation successful'));
ShowMessage(TFmt('Deleted %d files', [Count]));
```

### 5.2 控件绑定

- 使用 `TI18nLabel`、`TI18nButton` 等控件
- 设置 `TextKey` 属性绑定翻译键

### 5.3 最佳实践

- 所有用户可见文本使用 `T()`/`TFmt()` 或 i18n 控件
- 日期/数字存储用标准格式，显示时本地化
- 预留界面空间，防止翻译后文本截断

## 6. 常见违规行为

| 违规                  | 修正                     |
| ------------------- | ---------------------- |
| 在 `config.db` 创建业务表 | 业务数据存入 PostgreSQL      |
| 使用 `TIniFile`       | 使用 `UniBase.GetConfig` |
| 硬编码中文字符串            | 使用 `T('...')`          |
| View 中执行 SQL        | 移至 uDM 或 Ctrl          |
| uDM 引用 Vcl.Forms    | uDM 只做数据访问             |

## 7. 高级模式（可选）

### 7.1 IView 接口模式

```pascal
type
  IViewUserList = interface
    procedure ShowUsers(const Json: string);
    procedure ShowError(const Msg: string);
  end;

  TUserCtrl = class
  private
    FView: IViewUserList;
  public
    constructor Create(const AView: IViewUserList);
  end;
```

### 7.2 事件总线

```pascal
// 发布
Events.Post<TUserLoggedIn>.Create(UserId);

// 订阅
Events.Subscribe<TUserLoggedIn>(
  procedure(const E: TUserLoggedIn)
  begin
    StatusBar.Text := 'User: ' + E.UserId.ToString;
  end);
```

### 7.3 异步模式

```pascal
procedure TUserCtrl.LoadUser(AId: Integer; OnSuccess: TProc<TUser>; OnError: TProc<string>);
begin
  if AId <= 0 then begin OnError('Invalid ID'); Exit; end;
  TTask.Run(procedure
  begin
    try
      var U := Repo.GetUser(AId);
      TThread.Queue(nil, procedure begin OnSuccess(U); end);
    except
      on E: Exception do
        TThread.Queue(nil, procedure begin OnError(E.Message); end);
    end;
  end);
end;
```

## 8. 公共库复用

优先使用已有公共单元：

| 前缀    | 用途         | 示例                       |
| ----- | ---------- | ------------------------ |
| `UT*` | 通用工具       | `UT001_MathUtils`        |
| `BT*` | 基础工具       | `BT001_ExceptionHandler` |
| `DB*` | 数据库访问      | `DBRepository`           |
| `PG*` | PostgreSQL | `PGQueue`                |

**原则**：先搜索公共库，无合适实现才新建。

## 9. 提交前自检

1. [ ] 所有 `.pas/.dfm` 为 UTF-8，DFM 为文本格式
2. [ ] 控件在设计时创建，非运行时动态创建
3. [ ] View 无业务逻辑或数据库访问
4. [ ] 无重复定义的公共类型
5. [ ] 关键改动已更新文档
