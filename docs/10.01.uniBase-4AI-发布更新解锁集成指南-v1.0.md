## 一、系统概览

UniBase 提供三个核心商业化模块：

| 模块 | 用途 | 状态 |
|------|------|------|
| **UniBase.Updater** | 自动更新 | ✅ 已实现 |
| **UniBase.Unlock** | 轻量解锁（引流+私域入口） | 🟡 试运行（TwoKeyRun / OmniSync 已接入） |
| **UniBase.VCL.AboutFrame** | 打赏/关于我 | 🔲 待移入 |

> 建议：**所有新程序默认接入 UniBase.Updater + UniBase.Unlock**，实现统一的更新与解锁逻辑。

## 二、UniBase.Updater 使用指南

### 2.1 初始化

```pascal
uses UniBase.Updater;

procedure TMainForm.FormCreate(Sender: TObject);
begin
  Updater.Initialize(
    'https://www.goodmem.cn/updates/twokeyrun',  // 更新服务器 URL
    '1.0.0'                                       // 当前版本
  );
  Updater.Channel := ucStable;  // 稳定版渠道
  Updater.AutoCheck := True;
  Updater.AutoCheckInterval := 24;  // 每24小时检查一次
end;
```

### 2.2 检查更新

```pascal
Updater.CheckForUpdates(
  procedure(Available: Boolean; const Info: TUpdateInfo)
  begin
    if Available then
    begin
      ShowMessage(Format('发现新版本: %s', [Info.Version.ToString]));
      // 可选：自动下载安装
      // Updater.DownloadAndInstall(Info);
    end;
  end);
```

### 2.3 版本清单格式 (version.json)

```json
{
  "version": "1.1.0",
  "release_date": "2025-12-09T10:00:00Z",
  "channel": "stable",
  "download_url": "https://github.com/user/repo/releases/download/v1.1.0/TwoKeyRun-1.1.0.zip",
  "download_size": 2345678,
  "package_hash": "sha256:abc123...",
  "release_notes": "新增功能...",
  "mandatory": false
}
```

## 三、UniBase.Unlock 集成指南

### 3.1 解锁等级设计（示例）

以 TwoKeyRun 为例：

| 等级 | 条件 | 功能 | 解锁码格式（示例，2026-01） |
|------|------|------|----------------------------|
| 免费版 | 默认 | 中间24格 | - |
| 关注版 | 关注公众号获取码 | +上下排(留1格) | `TK2601A` |
| 分享版 | 分享获取码 | +最后1格 | `TK2601S` |

> 说明：
> - 解锁等级和功能差异由各软件自行定义；上表仅为 TwoKeyRun 示例。
> - 解锁码示例中的 `2601` 代表「2026 年 01 月」，与《私域流量运营指南》中约定一致。

### 3.2 解锁码规则（统一约定）

```
格式: [产品代码][年][月][类型][校验位]
示例: TK2601A

含义:
  产品代码 (2 字符):
    TK = TwoKeyRun (双键快启)
    MC = MoveC
    TS = TransSuccess
    SV = SVGThing (SVG 工具)
    ST = Stocks (股票量化工具)
    OS = OmniSync (全能同步)

  年:   2 位年份简写，如 26 表示 2026 年
  月:   2 位月份，如 01 表示 1 月

  类型 (1 字符):
    A = 关注码 (Attention)
    S = 分享码 (Share)

  校验位:
    预留一位字符（0-9 / A-Z），由解锁码生成器内部使用，用于简单校验，可暂时固定为 '0' 或按后续实现更新。
```

> 更详细的解锁码运营规则与示例，请参考《10.03.uniBase-4H-私域流量运营指南-v1.0.md》中的相关章节。

### 3.3 集成方式（示例代码）

```pascal
uses UniBase.Unlock;

// 初始化
UnlockMgr.ProductCode := 'TK';
UnlockMgr.QRCodeImage := 'qrcode_wechat.png';

// 获取解锁等级
case UnlockMgr.GetUnlockLevel of
  ulFree:   Slots := 24;
  ulFollow: Slots := 58;  // 60-2
  ulShare:  Slots := 60;
end;

// 显示解锁弹窗
if not UnlockMgr.IsFullUnlocked then
  UnlockMgr.ShowUnlockDialog;
```

### 3.4 任意新程序接入 Unlock 的最小步骤清单

以下步骤适用于 **MoveC / TransSuccess / SVGThing / Stocks** 以及后续所有新程序，开发者只需依次完成即可完成接入：

1. **在产品列表中确定产品代码与关键词**
   - 在本文件的「5.2 公众号关键词配置」表中，为新程序确认：
     - `ProductCode`（2 字符，大写），例如：`MC`、`TS`、`SV`、`ST`、`OS`。
     - 公众号关键词（中文或短英文），例如：「移动」「码到」「SVG」「股票」「同步」。
   - 如需新增产品，请同时更新：
     - 《10.03.uniBase-4H-私域流量运营指南-v1.0.md》中的产品代码与关键词说明；
     - 统一落地页（如 OmniSync.goodmem.cn）上的工具列表文案。

2. **在公众号后台配置关键词自动回复**
   - 登录 mp.weixin.qq.com →「功能」→「自动回复」→「关键词回复」。
   - 为新程序配置对应关键词（如「移动」「码到」等），回复内容中至少包含：
     - 当前运营期的解锁码（如 `MC2601A`）。
   - 具体操作流程可直接参考《10.03 私域流量运营指南》中「2.2 及 2.2.1」章节。

3. **在程序中初始化 UnlockMgr 参数**
   - 在主窗体 `FormCreate` 或程序初始化位置，配置以下属性（示例）：

   ```pascal
   uses UniBase.Unlock;
   
   procedure TMainForm.FormCreate(Sender: TObject);
   begin
     UnlockMgr.ProductCode     := 'MC';              // 本程序的产品代码
     UnlockMgr.ProductName     := 'MoveC 文件移动';  // 本程序中文名
     UnlockMgr.WeChatAccountId := 'aizhihuilab';     // 统一公众号 ID
     UnlockMgr.WeChatKeyword   := '移动';            // 对应的公众号关键词
     UnlockMgr.QRCodeImage     := 'res\\wechat_qr.png';
   end;
   ```

4. **在核心功能处接入解锁逻辑**
   - 在决定功能等级的地方（如格子数量、菜单启用状态等），使用 `GetUnlockLevel`：
     - `ulFree`：免费版限制；
     - `ulFollow`：关注版扩展；
     - `ulShare`：完全解锁版。
   - 在需要弹出解锁提示的入口（如点击高级功能、首次启动或「关于」界面中），调用：

   ```pascal
   if not UnlockMgr.IsFullUnlocked then
     UnlockMgr.ShowUnlockDialog;
   ```

5. **在 UI 文案中加入统一引导语**
   - 解锁弹窗、About 页面或帮助文档中，使用统一模板：
     - 通用：`关注公众号，获取「{软件中文名}」解锁码`；
     - 例如 MoveC：`关注公众号，获取「MoveC 文件移动」解锁码`。
   - 确保文案中提到的关键词与公众号实际配置一致（如「移动」「码到」「SVG」「股票」「同步」）。

6. **（可选）在统一落地页中增加入口**
   - 在 `OmniSync.goodmem.cn` 或各自专属站点中，为新程序增加一个工具卡片：
     - 显示软件名称、简短描述、公众号关键词与「了解详情」按钮。
   - 具体结构可参考《10.03 私域流量运营指南》中「统一落地页结构示例」章节。

## 四、UniBase.VCL.AboutFrame 使用指南

### 4.1 功能与页面结构

`UniBase.VCL.AboutFrame` 提供统一的 About/打赏/公司公众号页面，典型布局为 **6 个 Tab**：

1. 公司公众号（official_gzh）
2. 微信打赏（wechat）
3. 支付宝打赏（alipay）
4. BTC 打赏（btc）
5. USDT 打赏（usdt）
6. 关于我 / 关于本工具（aboutme）

每个 Tab 的图像与文案均从应用配置数据库 DB1 的 `aboutMeImages` 表中加载，并通过 AntiTamper + SeedTool 做加密与防篡改保护。

> 推荐最小尺寸：**600 × 320**。宿主窗体为 AboutFrame 预留的 Panel/区域建议不小于该尺寸，否则二维码与文字区域可能发生重叠。

### 4.2 数据库规划（DB1 + aboutMeImages）

- **DB1（目标规范）**：`{AppName}Config.db`  
  - 示例：`TwoKeyRunConfig.db`, `MoveCConfig.db`, `SVGThingConfig.db`。
  - 现有老项目可能仍使用 `AppName.db` 等命名，后续逐步迁移为 `{AppName}Config.db`。

- **表结构**：
  - 表名：`aboutMeImages`（详见 `04.01.uniBase-4AI-数据库Schema说明-v1.0.md` 中第 24 表说明）。
  - 关键字段：
    - `ImageKey` (TEXT)：图像 key，如 `official_gzh`/`wechat`/`alipay`/`btc`/`usdt`/`aboutme`。
    - `ImageData` (BLOB)：AES-256 加密后的图像数据。
    - `AddressText` (TEXT)：地址或文字说明（收款地址、网站链接等）。
    - `Enabled` (INTEGER)：是否在 AboutFrame 中显示此项（1=显示，0=隐藏）。
    - `Sha256Hash` / `HmacSha256`：完整性与防篡改校验字段。

- **预置 key 建议**：
  - `official_gzh` : 公司公众号二维码（“付乙工具集公众号”，主体/ID 见 `10.03` 文档）
  - `wechat`      : 微信收款码
  - `alipay`      : 支付宝收款码
  - `btc`         : BTC 地址/二维码
  - `usdt`        : USDT 地址/二维码
  - `aboutme`     : 关于我/关于本工具的图像与文案

### 4.3 集成步骤（宿主应用）

1. **添加 uses 引用**：

```delphi
uses
  UniBase.VCL.AboutFrame,
  UniBase.AntiTamper;
```

2. **初始化 AntiTamper 与 DB1**（在主窗体 `FormCreate` 中）：

```delphi
uses
  UniBase.AntiTamper;

procedure TMainForm.FormCreate(Sender: TObject);
var
  Config: TAntiTamperConfig;
  DbPath: string;
begin
  // 1) 初始化防篡改配置（参数必须与 SeedTool 一致）
  Config := TAntiTamperPackage.GetDefaultConfig;
  Config.EncryptionKey := 'YourApp_UniqueKey_2025';
  Config.Salt          := 'YourApp_Salt_v1';
  Config.KdfIterations := 10000;
  Config.EnableHMAC    := True;
  TAntiTamperPackage.Initialize(Config);

  // 2) 计算 DB1 路径（目标命名：{AppName}Config.db）
  DbPath := ExtractFilePath(ParamStr(0)) + 'TwoKeyRunConfig.db';

  // 3) 创建并嵌入 AboutFrame
  FAboutFrame := TUniAboutFrame.Create(Self);
  FAboutFrame.Parent := pnlAbout;      // pnlAbout 为宿主面板，需预留足够空间（600×320）
  FAboutFrame.Align  := alClient;
  FAboutFrame.Initialize(DbPath);
end;
```

> 说明：
> - 对于尚未迁移到 `{AppName}Config.db` 的老项目，可暂时将 `DbPath` 指向当前实际使用的配置数据库文件，后续迁移时统一调整。
> - `TUniAboutFrame.Initialize(DbPath)` 内部会打开 DB1，并从 `aboutMeImages` 读取各 key 对应的图像和文字，根据 `Enabled` 决定是否显示 Tab。

### 4.4 播种与维护图像（使用 SeedTool）

建议使用 `00Common\\SeedTool` 中的播种工具统一维护 `aboutMeImages` 表：

1. 运行 `SeedTool.exe`，选择应用的 DB1（例如 `TwoKeyRunConfig.db`）。
2. 确认/设置 AntiTamper 参数（EncryptionKey / Salt / KdfIterations / EnableHMAC），必须与主程序中 `TAntiTamperPackage.Initialize` 保持一致。
3. 在图像列表中添加或修改以下 key 对应的图片：
   - `official_gzh`, `wechat`, `alipay`, `btc`, `usdt`, `aboutme`。
4. 在文字配置页签中编辑每个 key 的 `address_text` 与 `description`（如收款地址、网站链接、关于我介绍）。
5. 为每条记录设置 `enabled` 标志：
   - `1` 表示在 AboutFrame 中显示对应 Tab（**默认全部 6 个启用**）；
   - `0` 表示隐藏该 Tab（例如某些工具暂不提供 BTC/USDT）。
6. 点击“开始播种”，SeedTool 会负责加密 `image_data`，计算 `sha256_hash` 与 `hmac_sha256` 并写入 DB1。

> SeedTool 位置与版本约定：当前官方播种工具源码与可执行文件位于 `D:\_Progs\00Common\SeedTool` 目录，作为 UniBase 生态的一部分使用。后续如需升级或迁移路径，须同时更新本说明与各项目集成文档中的引用路径。

## 五、私域流量体系

### 5.1 三级结构

```
公众号 (入口层)           企微客服 (服务层)      个人微信 (核心层)
├── 自动回复解锁码        ├── 问题解答           ├── 深度用户
├── 产品介绍              ├── 群运营             └── 付费转化
└── 软件菜单              └── 批量触达
```

### 5.2 公众号关键词配置（与 Unlock 集成的统一约定）

所有接入 UniBase.Unlock 的软件，应复用统一的公众号关键词与解锁码规划，避免各程序各自为政。
详细运营配置见《10.03.uniBase-4H-私域流量运营指南-v1.0.md》，此处给出当前约定的一览表（以 2026-01 为示例）：

| 关键词 | 对应软件 | 示例解锁码（2026-01） |
|--------|----------|------------------------|
| 双键 | TwoKeyRun（双键快启） | TK2601A / TK2601S |
| SVG | SVGThing（SVG 工具） | SV2601A |
| 股票 | Stocks（股票量化工具） | ST2601A |
| 同步 | OmniSync（全能同步） | OS2601A |
| 码到 | TransSuccess | TS2601A |
| 移动 | MoveC | MC2601A |

> 注意：
> - 新软件在接入 Unlock 前，应先在本表中增加产品代码与关键词，并同步更新《10.03 私域流量运营指南》。
> - 统一关键词有利于用户记忆，也方便在统一落地页上做引导。
