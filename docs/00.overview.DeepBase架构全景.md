# DeepBase 架构全景

> 一份文档讲清楚 DeepBase 是什么、怎么组织的、怎么用。
> 更新：2026-06-02

---

## 1. 一句话定义

DeepBase 是 **Delphi 桌面应用基础框架**，相当于 Delphi 世界的 Spring Boot。它提供配置、日志、国际化、数据库访问、LLM 调用、语音识别、商业化流程、自动更新、VCL/FMX 控件等 30+ 通用能力，避免每个下游项目重复实现基础设施。

---

## 2. 仓库目录结构

```
DeepBase/
├── Core/              # 核心运行时（无 UI/DB 依赖）
├── Services/          # IoC / EventBus / Scheduler / Resilience
├── Persistence/       # FireDAC DB 适配 / DoQry / ORM
├── Governance/        # OCGS 治理（门禁 / 证据 / 路由）
├── Features/          # 可选功能（LLM / Speech / Commerce / Updater）
├── VCL/               # VCL 控件与适配器
├── FMX/               # FMX 控件
├── ThirdParty/        # 第三方 SDK 适配（支付 / 社交 / UI）
├── Tools/             # Studio / CLI / SeedTool / UniPublisher
├── Tests/             # 单元测试与集成测试
├── Examples/          # 示例工程
├── Scripts/           # 构建 / 测试 / AutoFix 脚本
├── docs/              # 文档（50 个编号文件）
├── sql/               # Schema 创建与升级脚本
├── data/              # 样例数据库
│
├── ARCH-QUICKSTART.md # AI 入口指南
├── README.md          # 项目主页
├── bugfix.md          # 主 Bug 台账
├── history.md         # 开发历史
├── tasks.md           # 活跃任务
└── *.dpk / *.dproj    # 包定义文件
```

## 3. 架构分层

```
┌─────────────────────────────────────────┐
│  VCL / FMX  UI 控件层                    │
│  TFormStateHelper, TWaitForm, TLogListView│
│  DeepShell 桌面壳框架                     │
├─────────────────────────────────────────┤
│  Features  可选功能层                     │
│  LLM / Speech/ASR / Commerce            │
│  AutoUpdate / AntiTamper / CloudSync     │
├─────────────────────────────────────────┤
│  Governance 治理层                        │
│  Gate / Action / Route / Evidence        │
├─────────────────────────────────────────┤
│  Persistence 持久化层                     │
│  DoQry / ORM / ConnectionPool / Migration│
├─────────────────────────────────────────┤
│  Services 服务层                          │
│  IoC / EventBus / Scheduler / Resilience │
├─────────────────────────────────────────┤
│  Core 核心层                              │
│  Manager / Config / i18n / Logging       │
│  Security / MRU / Hotkeys / Theme        │
└─────────────────────────────────────────┘
```

### 3.1 包依赖关系

```
                 DeepBaseCore.dpk (无外部依赖)
                      ↓
         ┌────────────┼────────────┐
         ↓            ↓            ↓
    Services.dpk  Persistence.dpk  Governance.dpk
         ↓            ↓
         └─────┬──────┘
               ↓
         Features.dpk
               ↓
         ┌─────┴─────┐
         ↓           ↓
    VCL.dpk      FMX.dpk
```

### 3.2 各层职责

| 层 | 包 | 职责 | 关键模块 |
|----|-----|------|---------|
| **Core** | `DeepBaseCore.dpk` | 配置、i18n、日志、安全、窗口状态 | Manager, Config, i18n, Logging, Security, FormState, MRU, Hotkeys, Theme |
| **Services** | `DeepBaseServices.dpk` | IoC 容器、事件总线、调度、弹性策略 | IoC, EventBus, Scheduler, WorkerQueue, Resilience, Crypto, RateLimiter |
| **Persistence** | `DeepBasePersistence.dpk` | 数据库访问、ORM、连接池、迁移 | DoQry, ORM, ConnectionPool, Factory, Migrations |
| **Governance** | `DeepBaseGovernance.dpk` | 操作门禁、证据记录、路由 | GateResolver, ActionGrid, EvidenceRecorder, RouteResolver |
| **Features** | `DeepBaseFeatures.dpk` | LLM、语音、商业、更新、云同步 | LLM, Speech/ASR, Commerce, AutoUpdate, AntiTamper, CloudSync |
| **VCL** | `DeepBaseVCL.dpk` | VCL 控件与平台适配 | 20+ 控件, ThemeAdapter, ExceptionAdapter, DeepShell |
| **FMX** | `DeepBaseFMX.dpk` | FMX 控件 | 20+ FMX 控件 |

## 4. 数据库拓扑（四库分层）

```
┌──────────────────────────────────────────────────────┐
│                    DeepBase 数据库拓扑                  │
├──────────────────────────────────────────────────────┤
│                                                      │
│  DB1  ConfigDB (SQLite 本地)                          │
│  ├── 框架配置、日志、i18n、MRU、Hotkeys                │
│  ├── LLM 配置与调用历史                                │
│  ├── Governance 规则与证据                             │
│  └── 每个应用独立一个 {AppName}Config.db               │
│                                                      │
│  DB2  本地业务库 (SQLite)                              │
│  ├── 应用自身业务数据                                  │
│  └── 离线缓存                                         │
│                                                      │
│  DB3  远程业务库 (PostgreSQL/MySQL)                    │
│  ├── 多端共享/协作业务数据                             │
│  └── 通过 DoQry + connection_profiles 访问            │
│                                                      │
│  DB4  认证与支付库 (后端 DB)                           │
│  ├── users / identities / orders / payments          │
│  ├── entitlements / payment_notifications             │
│  └── ⚠️ 客户端不得直连，只通过后端 HTTP API 访问       │
│                                                      │
└──────────────────────────────────────────────────────┘
```

## 5. 核心能力速览

### 5.1 配置管理

```delphi
// 读写配置（自动持久化到 DB1 ConfigDB）
DeepBase.Config.SetConfig('App.Language', 'zh-CN');
var Lang := DeepBase.Config.GetConfig('App.Language', 'en-US');

// 敏感信息走 Security（Windows DPAPI / 跨平台 UBS2）
DeepBase.Security.SaveSecret('LLM.ApiKey', Key);
var Key := DeepBase.Security.LoadSecret('LLM.ApiKey');
```

### 5.2 国际化

```delphi
Label.Caption := T('Welcome');                    // 简单翻译
ShowMessage(TFmt('Hello, %s!', [UserName]));      // 格式化翻译
Label.Caption := TPlural('1 file', '%d files', N); // 复数
DeepBase.I18n.SetLanguage('zh-CN');               // 切换语言
```

### 5.3 日志

```delphi
Logger.Debug('调试信息', 'Module');
Logger.Info('操作成功', 'Module');
Logger.Error('操作失败', Exception);
```

### 5.4 数据库访问（DoQry）

```delphi
// 参数化查询，杜绝 SQL 拼接
var Ctx := UniDbMakeContext(Connection, udbSQLite);
UniDbSelect('SELECT * FROM Users WHERE Id = :id', '{"id": 1}', Data, Ctx);
UniDbExec('UPDATE Users SET Name = :name WHERE Id = :id', '{"name":"张三","id":1}', Ctx);
```

### 5.5 LLM 调用

```delphi
uses DeepBase.LLM.Service;
var Response := LLM.Chat(TierSmart, '解释这段代码');
```

### 5.6 语音识别

```delphi
uses DeepBase.Speech.Service, DeepBase.Speech.ASR.Baidu;
var Speech := TDeepBaseSpeechService.CreateBaidu(Config);
Speech.StartRecording;
// ... UI timer 检查 ShouldAutoStop ...
var Result := Speech.StopAndRecognize;
```

### 5.7 Commerce 商业流程

```delphi
uses DeepBase.Commerce.Service, DeepBase.Commerce.SafeClient;
var Client := TDeepKitSafeClient.Create(Config);
Commerce.EnsureUserForIdentity(Identity);
Commerce.CreateOrder(ProductId);
Commerce.BeginPayment(OrderId, cppWeChatPay);
```

### 5.8 高级基础设施

```delphi
// IoC 容器
TIoCContainer.Default.RegisterType<IMyService, TMyService>;

// EventBus 事件总线
TEventBus.Default.Subscribe<TMyEvent>(Handler);

// Resilience 弹性策略
TRetryPolicy.Create.MaxRetries(3).ExponentialBackoff(100, 2.0, 5000).Execute(Proc);

// Scheduler 任务调度
Scheduler.Schedule('*/5 * * * *', HeartbeatProc);

// StateMachine 状态机
FSM.AddTransition(osPending, osPaid, 'pay').Fire('pay');
```

## 7. 配置铁律（必须遵守）

1. **唯一外部配置文件是 `root.txt`**（放 EXE 同目录，第一行写项目根路径）
2. **所有配置进 DB1 ConfigDB**，不在下游项目散落 JSON/INI/YAML 文件
3. **敏感数据走 `DeepBase.Security`**（DPAPI / UBS2），不写明文
4. **UI 线程禁止同步重试 / 长耗时操作**
5. **客户端不直连 DB4**，支付只信任后端通知

## 8. 快速开始

### 最小集成

```delphi
program MyApp;
uses
  DeepBase.Manager,
  DeepBase.Persistence.Manager.FireDAC;  // 注册 DB1 连接适配器
begin
  DeepBase.InitializeOrRaise;
  // 你的业务代码...
  DeepBase.Finalize;
end.
```

### 需要什么包

```
不需要 DB      → DeepBaseCore.dpk
需要 DB/DoQry  → + DeepBasePersistence.dpk
需要 IoC/EventBus/Scheduler → + DeepBaseServices.dpk
需要 Governance → + DeepBaseGovernance.dpk
需要 LLM/Speech/Commerce   → + DeepBaseFeatures.dpk
VCL 界面       → + DeepBaseVCL.dpk
FMX 界面       → + DeepBaseFMX.dpk
```

## 10. 技术栈

| 维度 | 选型 |
|------|------|
| 语言 / 编译器 | Delphi 13.1 (Compiler 37) |
| 目标平台 | Windows (主要), macOS/Linux (FMX 扩展) |
| 本地数据库 | SQLite (WAL 模式) |
| 远程数据库 | PostgreSQL / MySQL / MSSQL (通过 FireDAC) |
| ORM / 数据访问 | DoQry (自研参数化查询门面) |
| UI 框架 | VCL (Windows 原生), FMX (跨平台) |
| 加密 | Windows DPAPI / UBS2 (AES-256-GCM + PBKDF2) |
| SVG 渲染 | Image32 |
| 测试框架 | DUnitX |
| 构建工具 | MSBuild + PowerShell 脚本 |
