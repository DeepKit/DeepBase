# DB4 支付渠道接入配置

> 日期: 2026-05-13  
> 实现目录: `D:\_Progs\02Business\BetterCiv\DeepKit.top\backend`  
> 服务器目录: `/srv/deepkit.top/app/current/backend`  
> 文档归属: DeepBase `docs/`

## 1. 原则

所有 Deep 系列工具统一走 DeepKit.top DB4 支付模块。

服务器端统一使用 `deepkit` 命名:

- 服务目录: `/srv/deepkit.top`
- API 服务: `deepkit-api.service`
- 业务数据库: `deepkit`
- 环境文件: `/srv/deepkit.top/env/deepkit.env`

禁止:

- 桌面端保存商户私钥
- 桌面端直连生产数据库
- 下游工具各自实现支付回调
- 客户端上传最终价格
- 客户端把订单状态改成 paid

必须:

- 商品价格来自 DB4 `products`
- 支付结果以服务端回调验签为准
- 支付通知原文落库
- 发权益使用 `source_order_id` 唯一约束防重复
- quota 消耗必须支持幂等

## 2. 微信支付 V3

生产环境变量:

```text
WECHAT_APP_ID=
WECHAT_APP_SECRET=
WECHAT_PAY_MCH_ID=
WECHAT_PAY_API_V3_KEY=
WECHAT_PAY_MERCHANT_SERIAL=
WECHAT_PAY_MERCHANT_PRIVATE_KEY_PATH=
WECHAT_PAY_PLATFORM_PUBLIC_KEY_PATH=
WECHAT_PAY_NOTIFY_URL=https://deepkit.top/dk/commerce/payments/wechat_pay/notify
```

预下单验收要求:

1. Native 通道返回 `qr_code_data`。
2. H5 通道返回 `pay_url`。
3. JSAPI/小程序/App 通道返回 `prepay_id` 和 `client_params_json`。
4. `out_trade_no` 使用 DB4 订单号，不由客户端生成。
5. `amount.total` 来自 DB4 `orders.amount_minor`。
6. `notify_url` 指向 DeepKit.top 统一回调。

回调验收要求:

1. 校验 `Wechatpay-Timestamp`、`Wechatpay-Nonce`、`Wechatpay-Signature`。
2. 使用微信支付平台公钥验证签名。
3. 使用 API v3 key 对 `resource` 做 AES-GCM 解密。
4. 校验 `mchid`、`out_trade_no`、金额、币种。
5. 在事务内更新 `payments/orders/payment_notifications`。
6. 使用 `entitlements.source_order_id` 保证重复回调不重复发权益。
7. 返回微信要求的成功 JSON。

## 3. 支付宝

支付宝接入顺序排在微信支付之后。需要补:

- 支付宝下单参数生成
- notify 签名验证
- notify 原文落库
- 订单金额/币种校验
- 幂等发权益

配置项:

```text
ALIPAY_APP_ID=
ALIPAY_APP_PRIVATE_KEY_PATH=
ALIPAY_PUBLIC_KEY_PATH=
ALIPAY_NOTIFY_URL=https://deepkit.top/dk/commerce/payments/alipay/notify
ALIPAY_GATEWAY=https://openapi.alipay.com/gateway.do
```

## 4. Stripe / PayPal

海外支付可后置。DeepBase 客户端契约已经允许 provider 为:

- `stripe`
- `paypal`
- `external`

生产要求:

- webhook secret 不进客户端
- webhook 验签失败必须拒绝
- 原文落库
- 金额/币种/订单号校验
- 统一发放 DB4 entitlement

## 5. License Signing

DB4 必须使用 Ed25519 非对称签名:

- 私钥只放服务器
- 公钥进入 DeepBase 客户端配置
- `payload` 使用 canonical JSON
- 客户端只验签，不参与签名

环境变量:

```text
LICENSE_ED25519_PRIVATE_KEY_B64=
LICENSE_KEY_ID=dk4-2026-01
```
