# 前端需要后端提供用户认证、计费的 API 要求

> **文档版本**: 1.0
> **创建日期**: 2025-12-15
> **用途**: 定义 Delphi 桌面端与 AipexBase 后端对接的 API 接口规范

---

## 概述

本文档定义了 UniBase 桌面客户端（VCL/FMX）需要的用户认证和计费相关 API 接口。

### 通用约定

- **Base URL**: `https://api.aipexbase.com` (生产) / `https://dev.aipexbase.com/api` (开发)
- **Content-Type**: `application/json`
- **认证方式**: Bearer Token (`Authorization: Bearer {access_token}`)
- **日期格式**: ISO 8601 (`yyyy-mm-ddThh:nn:ss.sssZ`)
- **货币单位**: CNY（人民币），精度 2 位小数

### 通用响应格式

```json
{
  "success": true,
  "message": "操作成功",
  "error_code": "",
  "data": { ... }
}
```

### 错误响应格式

```json
{
  "success": false,
  "message": "错误描述",
  "error_code": "ERROR_CODE"
}
```

### HTTP 状态码

| 状态码 | 含义 |
|--------|------|
| 200 | 成功 |
| 400 | 参数错误 (EAipexBaseValidationError) |
| 401 | 认证失败 (EAipexBaseAuthError) |
| 404 | 资源不存在 (EAipexBaseNotFoundError) |
| 500 | 服务器错误 (EAipexBaseError) |

## 一、用户认证 API

### 1.1 用户登录

**请求**
```
POST /api/auth/login
Content-Type: application/json
```

```json
{
  "email": "user@example.com",
  "password": "password123",
  "remember_me": true
}
```

**响应**
```json
{
  "success": true,
  "data": {
    "access_token": "eyJhbGciOiJIUzI1NiIs...",
    "refresh_token": "dGhpcyBpcyBhIHJlZnJlc2g...",
    "expires_in": 3600,
    "user": {
      "user_id": "usr_123456",
      "username": "张三",
      "email": "user@example.com",
      "phone": "13800138000",
      "avatar": "https://cdn.example.com/avatar/123.png",
      "status": "active"
    }
  }
}
```

**字段说明**
| 字段 | 类型 | 说明 |
|------|------|------|
| access_token | string | JWT 访问令牌 |
| refresh_token | string | 刷新令牌 |
| expires_in | integer | 访问令牌有效期（秒） |
| user.user_id | string | 用户唯一 ID |
| user.username | string | 用户名 |
| user.email | string | 邮箱 |
| user.phone | string | 手机号（可选） |
| user.avatar | string | 头像 URL（可选） |
| user.status | string | 状态：active/inactive/suspended |

---

### 1.2 用户注册

**请求**
```
POST /api/auth/register
Content-Type: application/json
```

```json
{
  "username": "张三",
  "email": "user@example.com",
  "password": "password123"
}
```

**响应**
```json
{
  "success": true,
  "data": {
    "access_token": "eyJhbGciOiJIUzI1NiIs...",
    "refresh_token": "dGhpcyBpcyBhIHJlZnJlc2g...",
    "user": {
      "user_id": "usr_123456",
      "username": "张三",
      "email": "user@example.com"
    }
  }
}
```

**验证规则**
- username: 2-50 字符
- email: 有效邮箱格式，不可重复
- password: 至少 6 字符

---


## 三、余额与充值 API

### 3.1 获取余额

**请求**
```
GET /api/billing/balance
Authorization: Bearer {access_token}
```

**响应**
```json
{
  "success": true,
  "data": {
    "balance": 1000.50,
    "currency": "CNY",
    "frozen_amount": 0.00,
    "available_amount": 1000.50
  }
}
```

**字段说明**
| 字段 | 类型 | 说明 |
|------|------|------|
| balance | number | 总余额 |
| currency | string | 货币类型 |
| frozen_amount | number | 冻结金额 |
| available_amount | number | 可用余额 |

---

### 3.2 获取充值选项

**请求**
```
GET /api/billing/recharge-options
Authorization: Bearer {access_token}
```

**响应**
```json
{
  "success": true,
  "data": [
    { "amount": 50.00, "bonus": 0.00, "description": "¥50" },
    { "amount": 100.00, "bonus": 5.00, "description": "¥100 送 ¥5" },
    { "amount": 200.00, "bonus": 15.00, "description": "¥200 送 ¥15" },
    { "amount": 500.00, "bonus": 50.00, "description": "¥500 送 ¥50" },
    { "amount": 1000.00, "bonus": 120.00, "description": "¥1000 送 ¥120" }
  ]
}
```

---

### 3.3 创建充值订单

**请求**
```
POST /api/billing/recharge
Authorization: Bearer {access_token}
Content-Type: application/json
```

```json
{
  "amount": 100.00,
  "payment_method": "alipay"
}
```

**payment_method 可选值**
- `alipay` - 支付宝
- `wechat` - 微信支付
- `bank_card` - 银行卡

**响应**
```json
{
  "success": true,
  "data": {
    "order_id": "ord_123456",
    "payment_url": "https://pay.example.com/qr/123456",
    "qr_code": "weixin://wxpay/bizpayurl?...",
    "expires_at": "2025-12-15T11:00:00Z"
  }
}
```

> 前端将跳转 `payment_url` 或显示 `qr_code` 二维码

---

### 3.4 获取交易记录

**请求**
```
GET /api/billing/transactions?page=1&page_size=20
Authorization: Bearer {access_token}
```

**响应**
```json
{
  "success": true,
  "data": {
    "total": 100,
    "page": 1,
    "page_size": 20,
    "items": [
      {
        "transaction_id": "txn_123456",
        "type": "recharge",
        "amount": 100.00,
        "balance": 1100.00,
        "description": "充值 ¥100",
        "status": "completed",
        "created_at": "2025-12-15T10:00:00Z"
      },
      {
        "transaction_id": "txn_123457",
        "type": "consume",
        "amount": -0.50,
        "balance": 1099.50,
        "description": "API 调用 - gpt-4",
        "status": "completed",
        "created_at": "2025-12-15T10:05:00Z"
      }
    ]
  }
}
```

**type 枚举值**
- `recharge` - 充值
- `consume` - 消费
- `refund` - 退款
- `bonus` - 赠送

**status 枚举值**
- `pending` - 处理中
- `completed` - 已完成
- `failed` - 失败
- `cancelled` - 已取消

## 四、发票管理 API

### 4.1 获取发票列表

**请求**
```
GET /api/billing/invoices?page=1&page_size=20&status=pending
Authorization: Bearer {access_token}
```

**参数**
| 参数 | 类型 | 说明 |
|------|------|------|
| page | integer | 页码 |
| page_size | integer | 每页数量 |
| status | string | 筛选状态 (可选): pending/invoiced/cancelled |

**响应**
```json
{
  "success": true,
  "data": {
    "total": 10,
    "page": 1,
    "page_size": 20,
    "items": [
      {
        "invoice_id": "inv_123456",
        "invoice_no": "INV202512001",
        "period_start": "2025-12-01T00:00:00Z",
        "period_end": "2025-12-31T23:59:59Z",
        "amount": 500.00,
        "status": "invoiced",
        "invoice_url": "https://cdn.example.com/invoices/123.pdf",
        "created_at": "2025-12-15T10:00:00Z"
      }
    ]
  }
}
```

**status 枚举值**
- `pending` - 待开票
- `invoiced` - 已开票
- `cancelled` - 已取消

---

### 4.2 申请开票

**请求**
```
POST /api/billing/invoices/{invoice_id}/request
Authorization: Bearer {access_token}
Content-Type: application/json
```

```json
{}
```

**响应**
```json
{
  "success": true,
  "message": "开票申请已提交"
}
```

---

### 4.3 下载发票

**请求**
```
GET /api/billing/invoices/{invoice_id}/download
Authorization: Bearer {access_token}
```

**响应**
- Content-Type: `application/pdf`
- 返回 PDF 文件流

## 五、错误码参考

| 错误码 | HTTP 状态码 | 说明 |
|--------|-------------|------|
| AUTH_INVALID_CREDENTIALS | 401 | 邮箱或密码错误 |
| AUTH_TOKEN_EXPIRED | 401 | Token 已过期 |
| AUTH_TOKEN_INVALID | 401 | Token 无效 |
| USER_NOT_FOUND | 404 | 用户不存在 |
| USER_EMAIL_EXISTS | 400 | 邮箱已注册 |
| USER_SUSPENDED | 403 | 账号已停用 |
| VALIDATION_ERROR | 400 | 参数验证失败 |
| BALANCE_INSUFFICIENT | 400 | 余额不足 |
| INVOICE_NOT_FOUND | 404 | 发票不存在 |
| INTERNAL_ERROR | 500 | 服务器内部错误 |
