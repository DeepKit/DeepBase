# DeepBase ← OCGS 治理框架集成规划

> 版本：v1.0 | 最后更新：2025-01
> 适用：Delphi 13.1 (Compiler 37) | DeepBase 主仓 + DeepBaseGovernance.dpk

---

## 1. 概述

本文档规划将 OCGS（能力有序治理层）框架从当前独立 demo 工程迁移到 DeepBase 主仓库，
使其成为 DeepBase 包链中的正式一环。集成后：

- **DeepBaseGovernance.dpk** 作为独立包插入 DeepBase 包链（位于 Services 之后、Features 之前）
- OCGS 复用 DeepBase 已有基础设施（EventBus、Authorization、StateMachine、DB Pool、i18n、Theme、FeatureFlags）
- 任何 DeepBase 项目可通过 `uses DeepBase.Governance.Runtime` 一行代码接入治理能力
- AI Steering 文件自动导出到 `.kiro/steering/` 目录

**包链变更：**

```
DeepBaseCore.dpk
  → DeepBasePersistence.dpk
    → DeepBaseServices.dpk
      → DeepBaseGovernance.dpk  ← 新增
        → DeepBaseFeatures.dpk
          → DeepBaseVCL.dpk / DeepBaseFMX.dpk
```

## 5. 复用 vs 替换

### 5.1 Demo.I18n → DeepBase.I18n

**当前状态：** Demo 工程有独立的 `Demo.I18n` 单元，硬编码中英文字符串。

**集成方案：**
```delphi
// 替换前（Demo.I18n）
function T(const AKey: string): string;  // 硬编码 map

// 替换后（使用 DeepBase.I18n）
uses DeepBase.I18n;

// 治理层文本注册到 DeepBase i18n 系统
procedure RegisterGovernanceI18n;
begin
  TDeepBaseI18n.Instance.RegisterBundle('governance', 'zh-CN',
    TPath.Combine(AppConfigDir, 'i18n\governance.zh-CN.json'));
  TDeepBaseI18n.Instance.RegisterBundle('governance', 'en',
    TPath.Combine(AppConfigDir, 'i18n\governance.en.json'));
end;

// 使用
var LMsg := TDeepBaseI18n.Instance.T('governance.gate_blocked');
```

**影响范围：** 仅 UI 层（Form.Main.pas 等），框架层不直接使用 i18n。

### 5.2 Demo.GlobalSets → DeepBase.RuntimeContext + FeatureFlags

**当前状态：** `Demo.GlobalSets` 存放全局开关和运行时状态。

**集成方案：**
```delphi
// 替换前
TGlobalSets.GovernanceEnabled := True;
TGlobalSets.DryRunMode := True;

// 替换后 — 使用 FeatureFlags
uses DeepBase.FeatureFlags;

TFeatureFlagManager.Instance.SetFlag('governance.enabled', True);
TFeatureFlagManager.Instance.SetFlag('governance.dry_run', True);

// 运行时检查
if TFeatureFlagManager.Instance.IsEnabled('governance.enabled') then
  LRuntime.EnterGate(...)
```

**Targeting 支持：** DeepBase FeatureFlags 支持按用户/角色/环境 targeting，
可实现"仅管理员启用治理"等场景。

### 5.3 OCGS Actor/Authorization → DeepBase.Authorization

**当前状态：** OCGS 有独立的 `TActor`、`TActorRegistry`、`TAccountabilityRecord`。

**集成方案：** 保留 `TActor` 作为治理层专用模型，但通过适配器桥接 DeepBase RBAC：

```delphi
// 新增适配器
type
  TDeepBaseActorAdapter = class(TInterfacedObject, IActorResolver)
  private
    FAuthManager: TAuthorizationManager;
  public
    constructor Create(AAuthManager: TAuthorizationManager);
    function GetCurrentActor: TActor;
    function ResolveActor(const AKey: string): TActor;
  end;

implementation

function TDeepBaseActorAdapter.GetCurrentActor: TActor;
var
  LUser: IAuthUser;
  LRoles: TArray<string>;
begin
  LUser := FAuthManager.GetCurrentUser;
  LRoles := FAuthManager.GetUserRoles(LUser.Id);
  Result := TActor.Create(
    LUser.Id,
    atHuman,
    LUser.DisplayName,
    LRoles,
    FAuthManager.GetUserScope(LUser.Id));
end;
```

**权限检查集成：**
```delphi
// GateResolver 条件中的 permission 类型，委托给 DeepBase.Authorization
function TGateResolver.CheckPermission(const AExpr: string;
  AContext: TJSONObject): Boolean;
begin
  // AExpr 格式: "permission:customer.delete"
  var LPerm := AExpr.Replace('permission:', '');
  var LUserId := AContext.GetValue<string>('user_id', '');
  Result := FAuthManager.HasPermission(LUserId, LPerm);
end;
```

### 5.4 OCGS EventBridge → DeepBase.EventBus

**当前状态：** `TEventBridge` 自己维护 `TList<TEventBridgeBinding>`，手动 Fire。

**集成方案：** EventBridge 内部改用 `TEventBus` 发布/订阅：

```delphi
type
  // 治理事件类型
  TGovernanceEvent = record
    EventType: string;       // 'gate.entered', 'gate.blocked', 'action.executed'
    GateKey: string;
    ActionKey: string;
    ActorKey: string;
    Timestamp: TDateTime;
    Payload: TJSONObject;
  end;

// EventBridge 改造
constructor TEventBridge.Create(ARuntime: IOCGSRuntime; AEventBus: TEventBus);
begin
  FRuntime := ARuntime;
  FEventBus := AEventBus;
  // 订阅 DeepBase 事件总线上的原生事件
  FEventBus.Subscribe<TNativeButtonClickEvent>(HandleNativeEvent);
end;

// 治理结果发布回事件总线
procedure TEventBridge.PublishResult(const AResult: TActionResult);
var
  LEvent: TGovernanceEvent;
begin
  LEvent.EventType := 'action.executed';
  LEvent.ActionKey := AResult.ActionKey;
  LEvent.Timestamp := Now;
  FEventBus.Publish<TGovernanceEvent>(LEvent);
end;
```

### 5.5 OCGS GateState → DeepBase.StateMachine

**当前状态：** `TGateState` 是简单枚举 (gsOpen, gsClosed, gsConditional)。

**集成方案：** 对于需要复杂状态流转的门禁，使用 DeepBase StateMachine：

```delphi
type
  TGateStateTrigger = (
    trgEvaluate,    // 重新评估条件
    trgOverride,    // 管理员覆盖
    trgTimeout,     // 超时关闭
    trgReset        // 重置
  );

// 为复杂门禁创建状态机
var LGateSM := TStateMachine<TGateState, TGateStateTrigger>.Create(gsClosed);
LGateSM.Configure(gsClosed)
  .Permit(trgEvaluate, gsConditional)
  .Permit(trgOverride, gsOpen);
LGateSM.Configure(gsConditional)
  .PermitIf(trgEvaluate, gsOpen, CheckAllConditions)
  .Permit(trgTimeout, gsClosed);
LGateSM.Configure(gsOpen)
  .Permit(trgTimeout, gsClosed)
  .Permit(trgReset, gsClosed);
```

**注意：** 简单门禁仍使用 `TGateResolver.Resolve` 直接返回状态，
StateMachine 仅用于需要持久化状态流转的高级场景（如审批流）。

### 5.6 OCGS EvidenceStore.SQLite → DeepBase.DB.Pool

**当前状态：** `TEvidenceStoreSQLite` 直接持有 `TFDConnection`。

**集成方案：** 改用 DeepBase 连接池：

```delphi
type
  TEvidenceStore = class(TInterfacedObject, IEvidenceStore)
  private
    FPoolName: string;  // 连接池名称，默认 'governance'
  public
    constructor Create(const APoolName: string = 'governance');
    procedure Save(const AEntry: TEvidenceEntry);
    function Query(const AActionKey: string; ALimit: Integer): TArray<TEvidenceEntry>;
  end;

implementation

procedure TEvidenceStore.Save(const AEntry: TEvidenceEntry);
var
  LConn: IPooledConnection;
begin
  LConn := TUniConnectionPool.Acquire(FPoolName);
  try
    // 使用 LConn.Connection 执行 SQL
    LConn.Connection.ExecSQL(SQL_INSERT, [...]);
  finally
    LConn.Release;
  end;
end;
```

**连接池配置（在 DeepBase 初始化时）：**
```delphi
TUniConnectionPool.Configure('governance',
  TPoolConfig.Create
    .Driver('SQLite')
    .Database(TPath.Combine(AppDataDir, 'governance.db'))
    .MinSize(1)
    .MaxSize(5));
```

## 6. 初始化集成

### 6.1 TGovernanceLifecycle — IRuntimeComponent 实现

```delphi
unit DeepBase.Governance.Lifecycle;

interface

uses
  DeepBase.Core.RuntimeComponent,  // IRuntimeComponent
  DeepBase.Governance.Runtime,
  DeepBase.Governance.ConfigLoader,
  DeepBase.Governance.KeyResolver,
  DeepBase.Governance.AI.SteeringExporter;

type
  TGovernanceLifecycle = class(TInterfacedObject, IRuntimeComponent)
  private
    FRuntime: TOCGSRuntime;
    FConfigLoader: TConfigLoader;
    FKeyResolver: TKeyResolver;
    FSteeringExporter: TSteeringExporter;
    FConfigDir: string;
    FEnabled: Boolean;
  public
    // IRuntimeComponent
    procedure Configure(AConfig: TJSONObject);
    procedure Initialize;
    procedure Start;
    procedure Stop;
    procedure Shutdown;

    property Runtime: TOCGSRuntime read FRuntime;
    property Enabled: Boolean read FEnabled;
  end;

implementation

procedure TGovernanceLifecycle.Configure(AConfig: TJSONObject);
begin
  // 从 ConfigDB 或 JSON 读取治理配置路径
  FConfigDir := AConfig.GetValue<string>('governance.config_dir',
    'config\governance');
  FEnabled := AConfig.GetValue<Boolean>('governance.enabled', True);
end;

procedure TGovernanceLifecycle.Initialize;
begin
  if not FEnabled then Exit;

  // 1. 创建核心组件
  FKeyResolver := TKeyResolver.Create;
  // 2. 创建所有 Engine（DueChecker, RouteResolver 等）
  // 3. 组装 TOCGSRuntime
  // 4. 创建 ConfigLoader
  FConfigLoader := TConfigLoader.Create(FConfigDir, FKeyResolver, ...);
end;

procedure TGovernanceLifecycle.Start;
begin
  if not FEnabled then Exit;

  // 1. 加载所有配置
  FConfigLoader.LoadAll;
  // 2. 导出 Steering 文件
  FSteeringExporter.ExportToFile;
  // 3. 注册到 EventBus
  // 4. 发布 GovernanceReady 事件
end;

procedure TGovernanceLifecycle.Stop;
begin
  // 停止接受新的 EnterGate 请求
  // 等待进行中的 Action 完成
end;

procedure TGovernanceLifecycle.Shutdown;
begin
  // 释放所有资源
  FreeAndNil(FSteeringExporter);
  FreeAndNil(FConfigLoader);
  FreeAndNil(FRuntime);
  FreeAndNil(FKeyResolver);
end;
```

### 6.2 在 DeepBase 初始化流程中的位置

```delphi
// 项目 .dpr 或启动单元
uses
  DeepBase.Bootstrap,
  DeepBase.Persistence.Manager.FireDAC,
  DeepBase.Governance.Lifecycle;

begin
  // DeepBase 标准初始化
  DeepBase.InitializeOrRaise;  // 读取 root.txt, 连接 ConfigDB

  // 治理层自动作为 IRuntimeComponent 被发现和初始化
  // 或手动注册：
  DeepBase.RuntimeContext.RegisterComponent('governance',
    TGovernanceLifecycle.Create);

  // 启动所有组件（按依赖顺序）
  DeepBase.RuntimeContext.StartAll;
  // → Configure → Initialize → Start 依次调用
end.
```

### 6.3 生命周期时序

```
DeepBase.InitializeOrRaise
  ├── 读取 root.txt → 确定项目根目录
  ├── 连接 ConfigDB → 读取全局配置
  ├── SetConnectionStorageFactory → 配置存储
  └── SetPlatformAdapter → 配置平台

RuntimeContext.StartAll
  ├── [Core 组件] Configure → Initialize → Start
  ├── [Persistence 组件] Configure → Initialize → Start
  ├── [Governance 组件]                              ← 在此
  │   ├── Configure: 读取 governance.config_dir
  │   ├── Initialize: 创建 Runtime + 所有 Engine
  │   └── Start: LoadAll + ExportSteering + 发布 GovernanceReady
  └── [Feature 组件] Configure → Initialize → Start
```

```json
        "kind": "evidence",
        "expression": "{ \">\": [{\"var\": \"customer.order_count\"}, 0] }",
```

### 步骤 5：在业务代码中使用

```delphi
uses

procedure TFormCustomer.btnDeleteClick(Sender: TObject);
var
  LContext: TJSONObject;
  LResult: TActionResult;
begin
  LContext := TJSONObject.Create;

    LContext.AddPair('user_id', CurrentUser.Id);
    LContext.AddPair('customer_id', FCustomerId);
```

## 8. 老项目改造指南

### 8.1 渐进式接入策略

老项目不需要一次性改造所有功能。推荐分三阶段：

**阶段 A：观察模式（1-2 天）**

```delphi
// governance.json
{
  "mode": "observe",           // observe | enforce | strict
  "dry_run_default": true,     // 所有 Gate 默认 DryRun
  "log_all_events": true       // 记录所有事件但不阻止
}
```

此阶段治理层只记录 Evidence，不阻止任何操作。用于收集数据。

**阶段 B：选择性执行（1 周）**

```delphi
// 仅对高风险操作启用治理
TFeatureFlagManager.Instance.SetFlag('governance.enforce.L3', True);
TFeatureFlagManager.Instance.SetFlag('governance.enforce.L2', False);
TFeatureFlagManager.Instance.SetFlag('governance.enforce.L1', False);
```

**阶段 C：全面执行**

```delphi
{
  "mode": "enforce",
  "dry_run_default": false
}
```

### 8.2 老代码包装（LegacyWrap）

对于无法立即重构的老代码，使用 `TLegacyWrap`：

```delphi
uses
  DeepBase.Governance.LegacyWrap;

// 包装老的删除过程
TLegacyWrap.Wrap(
  'customer_detail.delete_gate',   // Gate Key
  procedure(AContext: TJSONObject)  // 原始业务逻辑
  begin
    // 老代码原封不动放这里
    CustomerModule.DeleteCustomer(FCustomerId);
  end,
  function: TJSONObject              // 上下文构建器
  begin
    Result := TJSONObject.Create;
    Result.AddPair('user_id', CurrentUser.Id);
    Result.AddPair('customer_id', FCustomerId);
  end
);
```

### 8.3 EventBridge 自动绑定

对于使用 TAction/TActionList 的老项目：

```delphi
uses
  DeepBase.Governance.EventBridge,
  DeepBase.Governance.ComponentAdapter;

procedure TFormMain.FormCreate(Sender: TObject);
begin
  // 自动扫描 Form 上所有 TAction，绑定到对应 Gate
  FComponentAdapter := TComponentAdapter.Create(FNativeRegistry);
  FComponentAdapter.ScanDfmContent(Self);  // RTTI 扫描当前 Form

  // 自动绑定：ActionName → GateKey 映射
  FEventBridge.Bind('actDeleteCustomer', 'OnExecute',
    'customer_detail.delete_gate');
  FEventBridge.Bind('actSaveCustomer', 'OnExecute',
    'customer_detail.save_gate');
end;
```

### 8.4 迁移顺序建议

```
1. 添加 DeepBaseGovernance.dpk 依赖
2. 创建 config/governance/ 目录，定义 purposes.json
3. 识别 L3 (高风险) 操作 → 定义 gates.json + actions.json
4. 用 LegacyWrap 包装 L3 操作
5. 观察模式运行 1 周
6. 逐步添加 L2、L1 操作
7. 切换到 enforce 模式
8. 重构：将 LegacyWrap 替换为原生 Bridge 实现
```
