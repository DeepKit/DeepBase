# 04. 安全与测试指南

> 本文档整合了安全防护策略和测试自动化规范。

---

## 第一部分：安全防护

### 1. 敏感配置加密

使用 Windows DPAPI 进行本机加密：

```pascal
// 写入 (自动加密)
UniBase.SetConfigSecure('LLM.ApiKey', 'sk-123456');

// 读取 (自动解密)
var Key := UniBase.GetConfigSecure('LLM.ApiKey');
```

**优势**：加密数据绑定当前 Windows 用户，即使 `config.db` 被盗也无法在其他机器解密。

### 2. 日志脱敏

```pascal
// 自动脱敏：password, key, token 等关键词自动替换为 ******
// 手动脱敏：
LogInfo('User login: ' + Sanitize(UserName));
```

**默认关键字**：`password`, `secret`, `apikey`, `token`, `bearer`, `authorization`

### 3. DPAPI 迁移（换机/换用户）

1. 旧环境：运行 Studio "安全迁移向导"，解密后暂存内存
2. 新环境：逐项调用 `SetConfigSecure` 写回
3. 完成后清空内存缓冲

### 4. License 验证

```pascal
// 验证流程
// 1. 用户输入激活码
// 2. 本地检查格式、签名
// 3. 在线验证状态
// 4. 本地缓存（加密）
```

**机器指纹**：`HMAC_SHA256(CPU_ID + BIOS_ID + MAC)`

### 5. 防篡改

- **Config 完整性**：启动时校验 `Settings` 表 Hash
- **EXE 签名**：使用代码签名证书
- **运行时校验**：AES-256-CBC + HMAC-SHA256

### 6. 安全编码规范

```pascal
// ❌ SQL 注入
Query.SQL.Text := 'SELECT * FROM Users WHERE Name = ' + Edit1.Text;

// ✅ 参数化
Query.SQL.Text := 'SELECT * FROM Users WHERE Name = :Name';
Query.ParamByName('Name').AsString := Edit1.Text;
```

**SQL 模板校验（Studio）**：
- 禁止无 WHERE 的 UPDATE/DELETE
- 强制参数化
- SELECT 默认 LIMIT

## 第二部分：测试自动化

### 1. 测试框架

使用 **DUnitX**：
- Attribute 风格（`[TestFixture]`, `[Test]`）
- NUnit XML 输出（CI/CD 友好）
- 内置内存泄漏检测

### 2. 目录结构

```
Tests/
├── UniBaseTests.dpr           # 主测试项目
├── Test.UniBase.Config.pas    # 单元测试
├── Test.UniBase.i18n.pas
├── Integration/               # 集成测试
└── Snapshots/                 # GUI 快照
```

### 3. 测试模板

```pascal
unit Test.UniBase.Config;

interface

uses DUnitX.TestFramework, UniBase.Manager;

type
  [TestFixture]
  TTestConfig = class
  public
    [Setup]
    procedure Setup;
    
    [TearDown]
    procedure TearDown;
    
    [Test]
    procedure Test_GetConfig_WithDefault_ReturnsDefault;
  end;

implementation

procedure TTestConfig.Setup;
begin
  UniBase.InitializeWithDB(':memory:');  // 内存数据库隔离
end;

procedure TTestConfig.TearDown;
begin
  UniBase.Finalize;
end;

procedure TTestConfig.Test_GetConfig_WithDefault_ReturnsDefault;
begin
  Assert.AreEqual('Default', UniBase.Config.GetConfig('Key', 'Default'));
end;
```

### 4. 命名规范

```pascal
// 格式：Test_<方法名>_<场景>_<预期结果>
procedure Test_Initialize_WithMemoryDB_ReturnsTrue;
procedure Test_GetConfig_KeyNotExists_ReturnsDefault;
```

### 5. 隔离测试（非单例）

```pascal
var M: TUniBaseManager;
begin
  M := TUniBaseManager.Create(nil);
  try
    M.InitializeWithDB(':memory:');
    // 测试逻辑
  finally
    M.Free;
  end;
end;
```

### 6. 命令行编译 (MSBuild)

```batch
:: 编译
msbuild Tests\UniBaseTests.dproj /p:Config=Release /p:Platform=Win32

:: 运行测试
UniBaseTests.exe -exitbehavior:Continue

:: 指定输出格式
UniBaseTests.exe -format:xml -output:test-results.xml
```

### 7. CI/CD 集成 (GitHub Actions)

```yaml
name: Test
on: [push, pull_request]
jobs:
  test:
    runs-on: windows-latest
    steps:
      - uses: actions/checkout@v3
      - name: Build
        run: msbuild Tests\UniBaseTests.dproj /p:Config=Release
      - name: Test
        run: Tests\Win32\Release\UniBaseTests.exe -format:xml -output:results.xml
      - name: Publish
        uses: actions/upload-artifact@v3
        with:
          name: test-results
          path: results.xml
```
