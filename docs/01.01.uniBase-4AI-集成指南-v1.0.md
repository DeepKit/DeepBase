## SECTION 0: CRITICAL CONSTRAINTS (READ FIRST)

### 0.1 DO NOT REINVENT - UniBase Already Provides These

**UniBase provides 23 infrastructure tables and corresponding modules. DO NOT create duplicate implementations!**

| Feature | UniBase Module | UniBase Table | DO NOT Create |
|---------|----------------|---------------|---------------|
| App configuration | `UniBase.Config` | Settings | INI files, Registry, JSON config, custom config tables |
| Multi-language/i18n | `UniBase.i18n`, `T()`, `TFmt()` | Languages, I18nTexts | Translation tables, hardcoded text |
| Logging | `UniBase.Logger` | Logs | Custom log tables, OutputDebugString |
| Window state | `UniBase.FormState` | FormStates | Custom window position tables |
| Recent files (MRU) | `UniBase.MRU` | MRU | Custom MRU tables |
| Keyboard shortcuts | `UniBase.Hotkeys` | Hotkeys | Custom hotkey tables |
| UI themes | `UniBase.Theme` | Themes | Custom theme tables |
| SQL queries | `UniBase.DB.DoQry` | Queries | Hardcoded SQL strings |
| Categories/Enums | - | Categories | Custom enum tables |
| Tags | - | Tags, TagMappings | Custom tag tables |
| LLM integration | `UniBase.LLM` | Providers, Models, LLMConfig, LLMCalls, LLMPrompts, LLMApiKeys | Custom LLM tables |
| Crash reports | `UniBase.Exception` | ExceptionReports | Custom exception tables |
| Animations | - | AnimationAssets | Custom animation tables |
| Attachments | - | Attachments | Custom attachment tables |
| Notifications | - | Notifications | Custom notification tables |

> **Full table schema**: See [04.01.uniBase-4AI-数据库Schema说明-v1.0.md](04.01.uniBase-4AI-数据库Schema说明-v1.0.md)

### 0.2 Mandatory Rules

```
MUST:
- Use UniBase.Config for ALL configuration (not INI/Registry/JSON files)
- Use T() / TFmt() for ALL user-facing text (i18n)
- Use UniBase.Logger for ALL logging (not OutputDebugString)
- Use DoQry or ORM for ALL database access (not raw SQL concatenation)
- Initialize UniBase before Application.CreateForm
- Call UniBase.Finalize before application exit
- Save all .pas/.dfm/.fmx files as UTF-8 with BOM
- Put business data in DB2 (separate from UniBase ConfigDB)

MUST NOT:
- Hardcode Chinese/English text in UI
- Use TIniFile, TRegistry, or custom JSON config
- Use Application.ProcessMessages in loops
- Use TThread.Synchronize (use TThread.Queue instead)
- Access TFDQuery directly in View layer
- Reference VCL/FMX units in DataModules
- Store business state in global variables
- Create tables that duplicate UniBase functionality (see 0.1)
- Put business tables in ConfigDB (use separate DB2)
```

### 0.3 Architecture Layers

```
┌─────────────────────────────────────────────────────┐
│  VIEW (Form/Frame)                                  │
│  - UI display only                                  │
│  - Uses TI18n* controls, TConfig* controls          │
│  - Calls Controller via interface                   │
├─────────────────────────────────────────────────────┤
│  CONTROLLER (Application Service)                   │
│  - Business flow orchestration                      │
│  - Uses UniBase.Config, Logger, DoQry               │
│  - Updates View via IView or callbacks              │
├─────────────────────────────────────────────────────┤
│  DOMAIN (Entity + Domain Service)                   │
│  - Pure business logic                              │
│  - No VCL/FMX/FireDAC/UniBase control dependencies  │
├─────────────────────────────────────────────────────┤
│  DATA ACCESS (uDM + DoQry)                          │
│  - Database connection and queries only             │
│  - No business rules, no UI references              │
└─────────────────────────────────────────────────────┘
```

## SECTION 1: INITIALIZATION

### 1.1 File Layout & Database Separation

```
{RootPath}/                     <- Defined in root.txt
├── {AppName}Config.db          <- DB1: UniBase infrastructure (23 tables)
├── data/
│   └── {AppName}Data.db        <- DB2: YOUR business tables (Users, Orders, etc.)
├── logs/                       <- Log files
└── root.txt                    <- Points to RootPath (in EXE dir)
```

**CRITICAL: DB1 vs DB2 Separation**

| Database | Purpose | Contains | Connection |
|----------|---------|----------|------------|
| **DB1 (ConfigDB)** | UniBase infrastructure | 23 UniBase tables (Settings, Logs, MRU, LLM...) | `UniBase.ConfigDB` |
| **DB2 (DataDB)** | Your business data | Your app's tables (Users, Products, Orders...) | Your own `TFDConnection` |

**Rules**:
- DO NOT add your business tables to DB1 (ConfigDB)
- DO NOT recreate UniBase tables in DB2
- Configure DB2 path in Settings: `DB2.Path` = `data\MyAppData.db`

> **Full DB1 schema**: See [04.01.uniBase-4AI-数据库Schema说明-v1.0.md](04.01.uniBase-4AI-数据库Schema说明-v1.0.md)

### 1.2 root.txt Resolution

```pascal
// Resolution order:
// 1. {EXE_DIR}\root.txt
// 2. %APPDATA%\{AppName}\root.txt

// root.txt content (MUST be absolute path, first line only):
D:\Projects\MyAppRoot
```

### 1.3 Config Database Path

```pascal
// AppName = EXE filename without extension
// ConfigDBPath = RootPath + '\' + AppName + 'Config.db'
// Example: MyApp.exe -> D:\Projects\MyAppRoot\MyAppConfig.db
```

### 1.4 Initialization Code Template

```pascal
program MyApp;

uses
  Vcl.Forms,
  UniBase.Manager,
  MainFormUnit in 'MainFormUnit.pas' {MainForm};

begin
  Application.Initialize;

  // Initialize UniBase BEFORE CreateForm
  if not UniBase.Initialize then
  begin
    ShowMessage('UniBase init failed: ' + UniBase.LastError);
    Halt(1);
  end;

  Application.CreateForm(TMainForm, MainForm);
  Application.Run;

  // Finalize AFTER Application.Run
  UniBase.Finalize;
end.
```

### 1.5 Alternative: InitializeWithDB (Direct Path)

```pascal
// Skip root.txt, specify database path directly
if not UniBase.InitializeWithDB('D:\Data\MyConfig.db') then
  Halt(1);
```

## SECTION 3: DATABASE ACCESS (DoQry)

### 3.1 Initialize DoQry

```pascal
uses UniBase.DB.DoQry;

// Called automatically by UniBase.Initialize
// Manual call if needed:
UniDbInit(UniBase.RootPath);
```

### 3.2 Create Query Context

```pascal
var Ctx := UniDbMakeContext(
  MyConnection,      // TFDConnection
  udbSQLite,         // or udbPostgreSQL
  30,                // Timeout seconds
  'CorrelationId'    // For log tracing (optional)
);
```

### 3.3 Execute Queries

```pascal
uses UniBase.DB.DoQry, Data.DB, Datasnap.DBClient;

var
  Ctx: TUniQueryContext;
  Data: TClientDataSet;
  RowCount: Integer;

// SELECT - returns row count
Data := TClientDataSet.Create(nil);
try
  RowCount := UniDbSelect(
    'SELECT * FROM Users WHERE Age > :age',
    '{"age": 18}',
    Data,
    Ctx
  );
  // Process Data...
finally
  Data.Free;
end;

// INSERT/UPDATE/DELETE - returns affected rows
RowCount := UniDbExec(
  'INSERT INTO Users (Name, Age) VALUES (:name, :age)',
  '{"name": "John", "age": 25}',
  Ctx
);

// INSERT with returning ID
var NewId := UniDbInsertReturningId(
  'INSERT INTO Users (Name) VALUES (:name)',
  '{"name": "Jane"}',
  Ctx
);

// Scalar query
var Count := UniDbScalar(
  'SELECT COUNT(*) FROM Users',
  '',
  Ctx
);
```

### 3.4 JSON Parameter Format

```pascal
// String
'{"name": "张三"}'

// Number
'{"amount": 100.5}'

// Boolean
'{"active": true}'

// NULL
'{"email": null}'

// Multiple params
'{"name": "John", "age": 25, "active": true}'

// Empty params
''
```

### 3.5 Using Queries Table (Recommended)

```sql
-- Define query in Queries table
INSERT INTO Queries (Name, SqlText, Description)
VALUES ('User.GetById', 'SELECT * FROM Users WHERE Id = :id', 'Get user by ID');
```

```pascal
// Call by name (NOT SQL)
UniDbSelect('User.GetById', '{"id": 1}', Data, Ctx);
```

### 3.6 Transactions

```pascal
// Option 1: Manual transaction
var Tx := UniDbBeginTx(Ctx);
try
  UniDbExec('INSERT INTO Orders ...', '...', Ctx);
  UniDbExec('UPDATE Inventory ...', '...', Ctx);
  Tx.Commit;
except
  Tx.Rollback;
  raise;
end;

// Option 2: Auto transaction (RECOMMENDED)
UniDbRunInTx(Ctx, procedure
begin
  UniDbExec('INSERT INTO Orders ...', '...', Ctx);
  UniDbExec('UPDATE Inventory ...', '...', Ctx);
  // Auto Commit on success, auto Rollback on exception
end);
```

### 3.7 Error Handling

```pascal
try
  UniDbExec('INVALID SQL', '', Ctx);
except
  on E: EUniBaseDbError do
  begin
    // E.ProcName - Query name
    // E.SQL - Actual SQL
    // E.ParamsJson - Parameters
    // E.DBType - Database type
    // E.CorrelationId - Trace ID
    // E.Message - Error message
    UniBase.Logger.Error('DB Error: ' + E.Message, E);
  end;
end;
```

```pascal
uses UniBase.LLM;

var
```

## SECTION 6: BUG FIXES & KNOWN ISSUES

### 6.1 Critical Fixes (Must Know)

| Bug ID | Issue | Fix |
|--------|-------|-----|
| BUG-001 | Config deadlock in concurrent writes | Use double-buffer cache |
| BUG-007 | Theme switch doesn't refresh all controls | Call RecreateWnd after ApplyTheme |
| BUG-009 | TI18nLabel empty after language switch | Reload from DB in OnLanguageChanged |
| BUG-018 | AutoUpdate SHA256 validation fails | Use lowercase hex format |
| BUG-021 | DoQry memory leak | Move Q.Free to finally block |
| BUG-039 | Manager missing MRU/Hotkeys properties | Added FMRU, FHotkeys fields |
| BUG-040 | License test uses wrong property | Use ConfigDB instead of Connection |

### 6.2 API Changes (Migration Notes)

| Old API | New API | Version |
|---------|---------|---------|
| `UniBase.Initialize(':memory:')` | `UniBase.InitializeWithDB(':memory:')` | v0.3 |
| `UniBase.Initialized` | `UniBase.IsInitialized` | v0.3 |
| `UniBase.Connection` | `UniBase.ConfigDB` | v0.3 |

### 6.3 Common Errors & Solutions

| Error | Cause | Solution |
|-------|-------|----------|
| `Config database not found` | root.txt path wrong or DB missing | Check root.txt points to valid directory with {AppName}Config.db |
| `Table 'XXX' not found` | Schema not initialized | Run `DiagnoseAll` then `AutoFix` |
| `Database is locked` | Concurrent write without WAL | Add `PRAGMA journal_mode=WAL` |
| `Unable to decrypt API key` | DPAPI key tied to old machine | Re-enter API key on new machine |
| `UNIQUE constraint failed` | Duplicate primary/unique key | Use `INSERT OR REPLACE` |

### 6.4 Performance Optimizations Applied

| Optimization | Result |
|--------------|--------|
| Config two-level cache | Cache hit rate 60% → 95% |
| i18n LRU cache | Query time < 0.1ms |
| Logging batch write | 10k logs: 8s → 3s |
| TLogListView virtual scroll | 100k logs still smooth |

## SECTION 7: CODE TEMPLATES

### 7.1 Form with Config Binding

```pascal
unit MainFormUnit;

interface

uses
  Vcl.Forms, Vcl.StdCtrls,
  UniBase.Manager, UniBase.i18n;

type
  TMainForm = class(TForm)
    lblWelcome: TLabel;
    edtUsername: TEdit;
    btnSave: TButton;
    procedure FormCreate(Sender: TObject);
    procedure FormClose(Sender: TObject; var Action: TCloseAction);
    procedure btnSaveClick(Sender: TObject);
  end;

implementation

procedure TMainForm.FormCreate(Sender: TObject);
begin
  // Restore window state
  UniBase.FormState.RestoreFormState(Self);
  
  // Load config
  edtUsername.Text := UniBase.GetConfig('User.Name', '');
  
  // Apply translations
  lblWelcome.Caption := T('Welcome');
  btnSave.Caption := T('Save');
end;

procedure TMainForm.FormClose(Sender: TObject; var Action: TCloseAction);
begin
  UniBase.FormState.SaveFormState(Self);
end;

procedure TMainForm.btnSaveClick(Sender: TObject);
begin
  UniBase.SetConfig('User.Name', edtUsername.Text);
  UniBase.Logger.Info('Username saved: ' + edtUsername.Text, 'MainForm');
  ShowMessage(T('Settings saved'));
end;

end.
```

### 7.2 Service with DoQry

```pascal
unit UserService;

interface

uses
  UniBase.DB.DoQry, FireDAC.Comp.Client, Datasnap.DBClient;

type
  TUserService = class
  private
    FConnection: TFDConnection;
  public
    constructor Create(AConnection: TFDConnection);
    function GetUserById(Id: Integer): TClientDataSet;
    function CreateUser(const Name: string; Age: Integer): Integer;
    procedure UpdateUser(Id: Integer; const Name: string);
    procedure DeleteUser(Id: Integer);
  end;

implementation

uses
  System.SysUtils, UniBase.Manager;

constructor TUserService.Create(AConnection: TFDConnection);
begin
  FConnection := AConnection;
end;

function TUserService.GetUserById(Id: Integer): TClientDataSet;
var
  Ctx: TUniQueryContext;
begin
  Ctx := UniDbMakeContext(FConnection, udbSQLite);
  Result := TClientDataSet.Create(nil);
  UniDbSelect(
    'SELECT * FROM Users WHERE Id = :id',
    Format('{"id": %d}', [Id]),
    Result,
    Ctx
  );
end;

function TUserService.CreateUser(const Name: string; Age: Integer): Integer;
var
  Ctx: TUniQueryContext;
begin
  Ctx := UniDbMakeContext(FConnection, udbSQLite);
  Result := UniDbInsertReturningId(
    'INSERT INTO Users (Name, Age) VALUES (:name, :age)',
    Format('{"name": "%s", "age": %d}', [Name, Age]),
    Ctx
  );
  UniBase.Logger.Info(Format('User created: %d', [Result]), 'UserService');
end;

procedure TUserService.UpdateUser(Id: Integer; const Name: string);
var
  Ctx: TUniQueryContext;
begin
  Ctx := UniDbMakeContext(FConnection, udbSQLite);
  UniDbExec(
    'UPDATE Users SET Name = :name WHERE Id = :id',
    Format('{"name": "%s", "id": %d}', [Name, Id]),
    Ctx
  );
end;

procedure TUserService.DeleteUser(Id: Integer);
var
  Ctx: TUniQueryContext;
begin
  Ctx := UniDbMakeContext(FConnection, udbSQLite);
  UniDbExec(
    'DELETE FROM Users WHERE Id = :id',
    Format('{"id": %d}', [Id]),
    Ctx
  );
end;

end.
```

### 7.3 Async Operation Pattern

```pascal
procedure TMainForm.LoadDataAsync;
begin
  btnLoad.Enabled := False;
  ProgressBar.Visible := True;
  
  TTask.Run(procedure
  var
    Data: TClientDataSet;
    Ctx: TUniQueryContext;
  begin
    try
      Ctx := UniDbMakeContext(FConnection, udbSQLite);
      Data := TClientDataSet.Create(nil);
      try
        UniDbSelect('SELECT * FROM LargeTable', '', Data, Ctx);
        
        TThread.Queue(nil, procedure
        begin
          // Update UI in main thread
          DataSource1.DataSet := Data;
          btnLoad.Enabled := True;
          ProgressBar.Visible := False;
        end);
      except
        Data.Free;
        raise;
      end;
    except
      on E: Exception do
        TThread.Queue(nil, procedure
        begin
          btnLoad.Enabled := True;
          ProgressBar.Visible := False;
          ShowMessage(T('Load failed') + ': ' + E.Message);
        end);
    end;
  end);
end;
```

### 8.2 SQL Logging

```pascal
uses UniBase.SQLLogger;

// Enable SQL logging
TSQLLogger.Enabled := True;
TSQLLogger.SlowQueryThresholdMs := 500;

// Set slow query callback
TSQLLogger.OnSlowQuery := procedure(Entry: TSQLLogEntry)
begin
  UniBase.Logger.Warn(
    Format('Slow query: %dms - %s', [Entry.DurationMs, Entry.SQL]),
```
