# DeepBase 功能矩阵 (Feature Matrix)

> **最后更新**: 2026-06-18
> **来源**: REVIEW-P2-001 (架构/API 专家)
> **目的**: 对 README 高层表述做边界说明, 逐项标注每个模块的真实成熟度, 避免调用方拿到 silent fallback。

## 成熟度图例

| 标签 | 含义 |
|------|------|
| Implemented | 公开 API 已实现, 有测试覆盖, 可在生产使用 |
| Partial | 主路径可用, 但存在子功能缺失或平台缺口 (见下文 TODO 链接) |
| Experimental | 设计稳定但测试覆盖不足, 或 API 仍有变更风险 |
| Platform-limited | 仅某平台可用 (Windows-only / VCL-only / FMX-only), 其它平台为 stub |
| Needs-external-service | 运行需依赖外部服务 (DB / HTTP / WebView2 / onnxruntime / 支付 SDK 等) |
| Stub shell | 接口已声明, 但实现为 silent fallback (False/空/默认) |

## 主矩阵

| 模块 | 包 | 成熟度 | 关键依赖 | 初始化要求 | 不可用时行为 |
|------|-----|------|------|------|------|
| **Configuration** | `DeepBaseCore` (DeepBase.Config) | Implemented | 存储抽象 (FireDAC 适配在 Persistence) | 需 `DeepBase.Initialize*` | Fail-closed: 存储工厂失败回退内存 DB, 记 warning |
| **i18n (T())** | `DeepBaseCore` (DeepBase.i18n) | Implemented | 同上; LRU cache 10000 条 | 需 Initialize 注册全局回调 | Fail-closed: 存储初始化失败抛异常 (记日志后回退内存); T() 缺键返回空串 |
| **FormState** | `DeepBaseCore` (DeepBase.FormState) | Implemented | 存储抽象; VCL/FMX 辅助在上层包 | 需 Initialize 注入存储 | Fail-closed: RestoreState 未找到返回 False, 由调用方决定默认值 |
| **Logging** | `DeepBaseServices` | Implemented | Config + 存储 | 需 Initialize | Fail-closed: 队列仅在 shutdown 时可能丢弃; 文件日志失败记内部日志 |
| **MRU** | `DeepBaseCore` + `DeepBasePersistence` | Implemented | FireDAC 适配 | 需 Initialize | Fail-closed: 存储工厂失败记日志, 回退内存 DB |
| **Hotkeys** | `DeepBaseCore` (DeepBase.Hotkeys) | **Platform-limited (Windows)** | Win32 `RegisterHotKey` | 需 Initialize; VCL/FMX 适配层注册平台钩子 | Fail-closed: 注册失败记日志; 非 Windows 无法使用 |
| **Theme** | `DeepBaseCore` (DeepBase.Theme) | Partial | 元数据 + 缓存在 Core; `SetPlatformAdapter` 由 VCL/FMX 注册 | 需 Initialize | **Fail-open**: 未注册 platform adapter 时 `ApplyTheme` 仅更新元数据, UI 不变 |
| **Protection** | `DeepBaseCore` (DeepBase.Protection) | Implemented (Windows) | Windows CryptoAPI + CNG AES-256-GCM | 否 (纯 crypto helpers) | Fail-closed: 无效密钥/加密错误抛异常 |
| **TrayIcon** | `DeepBaseCore` (DeepBase.TrayIcon) | **Platform-limited (Windows)** | Win32 `Shell_NotifyIcon` | 否 | Fail-closed: API 失败抛异常 |
| **Cache** | `DeepBaseCore` (DeepBase.Cache) | Implemented | 无外部依赖 | 否 (泛型独立类) | Fail-closed: 超容量按策略抛; `TryGet` 缺失返回 False |
| **Security (DPAPI + AES-GCM)** | `DeepBaseServices` | Implemented | Windows: DPAPI + Credential Manager; 非 Windows: OpenSSL AES-256-GCM + PBKDF2-SHA256 (UBS2 格式) | 需 Initialize 注入存储 | **Fail-closed**: Windows 抛 `EDPAPIError`; 非 Windows `SecretStore` 抛 `ESecretStoreUnavailable`, 除非设置 `DEEPBASE_INSECURE_DEV_MODE` |
| **AutoFix** | `DeepBaseCore` | Implemented (fail-open) | 显式 `--autofix-mode` 启用 | 独立: `AutoFix.Install` 必须在 `Application.Initialize` 之前调用, **不在** `DeepBase.Initialize` 内 | **Fail-open**: 无 mode 标志时所有 facade 方法均为 no-op, 不写文件 |
| **LLM** | `DeepBaseLLM` | Implemented | 6 个 provider (OpenAI / Anthropic / Azure / LiteLLM / Ollama / Custom); 需网络 + API key | 需 Initialize 加载配置和凭据 | Fail-closed: HTTP/auth 失败抛 `ELLMException`; provider 配置缺失返回空; 需要真实网络 |
| **Commerce** | `DeepBaseCommerce` | Implemented | WeChatPay / Alipay / Stripe / PayPal IPaymentClient; FireDAC 存储 | 需 Initialize + FireDAC | Fail-closed: `Service.Create` 存储为 nil 时抛; gateway 需先注册; 依赖外部支付 SDK 和商户账号 |
| **AutoUpdate** | `DeepBasePlatform` | Partial | version.json 远端; 增量 / 签名验证 / 回滚在 Updater 已设计, AutoUpdate 较轻 | 需 Initialize + 网络 | **Fail-open**: 远端版本 ≤ 当前返回 False; version.json 缺失视为 "无更新"; 调用方需处理 nil Info |
| **Speech** | `DeepBaseSpeech*` (5 包) | Implemented (Windows-primary) | ASR: SAPI + Baidu HTTP + SenseVoice ONNX; TTS: SAPI + Edge WebSocket + StepFun REST; WakeWord: SAPI Grammar; Voiceprint: MFCC+DTW + DPAPI-at-rest; Intent: rule + LLM fallback | 需 Initialize 注册; Registry 自注册 | Fail-closed (local): SenseVoice 模型目录缺失抛; **Fail-open (cloud)**: Baidu/StepFun HTTP 失败返回空结果; WakeWord 需显式 Start; SAPI/WinMM 仅 Windows |
| **FMX mobile** | `DeepBaseFMX` | Partial | FMX.Forms; BUG-277 / BUG-281 跟踪 8 处 TODO (safe area / share / iOS 权限 / Android 回调桥) | 否 (singleton) | **Fail-open**: 非 Android/iOS 时权限检查返回 False; 未实现平台 safe area 返回 Empty; 桩路径 share 返回 False |
| **Browser (CDP)** | `DeepBaseBrowser` | **Implemented (VCL-only)** | WebView2 引擎 + Chrome/Edge 运行时 | 推荐 Initialize | Fail-closed: CDP 连接失败抛 `EBrowserAutomation`; PageDriver 返回 `pdsError`; 需要 WebView2 runtime |
| **DataPlatform** | `DeepBaseDataPlatform` | Partial / Experimental | DeepAxis; Windows UIAutomation; WeChat39x / WeChat4x schema 适配器 | 独立 `Bootstrap.Bootstrap`, 不走 `DeepBase.Initialize` | Fail-closed: DeepAxis / Win32 UIAutomation 缺失时抛; **SQLCipher 适配器未在 DataPlatform.dpk 实际编译** |
| **ORM / Validation / StateMachine / EventBus / IoC / MVVM** | `DeepBaseCore` | Implemented | 纯逻辑; ORM 实际使用需 DB 连接 | 否 (纯逻辑); ORM 使用时需连接 | Fail-closed: ORM 无效映射抛; StateMachine 非法转移抛 `EInvalidTransitionException`; Validation 收集错误; IoC 未解析类型抛; MVVM 由 CanExecute 门控 |
| **Persistence (FireDAC)** | `DeepBasePersistence` | Implemented | FireDAC + SQLite (+ PostgreSQL); 14 个 FireDAC 持久化单元 | 必须链接 `DeepBase.Persistence.Manager.FireDAC` | **Fail-closed**: 未链接 `Manager.FireDAC` 时 `InitializeOrRaise` 抛 "No DB connection adapter registered"; FireDAC 驱动缺失是编译期 |
| **Inference** | `DeepBaseInference` | Partial / Platform-limited | 可选 `onnxruntime`; CPU/DirectML/CUDA | 需 Initialize 通过 IoC 注入 `IInferenceRuntime` | Fail-closed: DirectML/CUDA 无 `HAS_ONNX` 抛 `EInferenceProviderError`; 模型缺失抛; CPU-only 路径无 onnxruntime 可用 |
| **IntentClarification** | `DeepBaseIntentClarification` | **Implemented (VCL-only)** | VCL + LLM; 27 单元; 5 级 provider (L0-L4); LLMResilience 降级 | 需 Initialize + VCL 应用 | Fail-closed: 内部异常捕获为 `TTurnResult` 错误 (绝不抛); LLM 失败按 LLMResilience 降级到更低 provider 层 |
| **Governance** | `DeepBaseGovernance` | **Implemented (VCL-only)** | VCL + Persistence; 37 单元; OCGS Runtime + SQLite 证据存储 | 需 VCL + Persistence; 通过构造注入 | Fail-closed: gate key 缺失或 SQLite store 不可用抛; 证据持久化到 SQLite |

## README 高层表述的边界说明

### "像 Spring Boot 一样简单"
- **含义**: 提供模块化包边界 (Core → Services → Persistence → Features → VCL/FMX), 依赖注入, 统一初始化入口 `DeepBase.Initialize*`。
- **不是**: 不需要配置 / 不需要理解包 DAG / 不需要 FireDAC 驱动。
- **实际前提**: 任何调用 `DeepBase.Initialize*` 的最终程序, 必须链接 `DeepBase.Persistence.Manager.FireDAC`, 否则抛 "No DB connection adapter registered"。

### "所有核心 API 线程安全"
- **范围**: Core 模块 (`Cache` / `EventBus` / `IoC` / `Config` / `i18n` / `Logging` / `MRU` 等) 内部使用 `TCriticalSection` / `TMonitor` 保护共享状态。
- **例外**: 纯逻辑类 (`TValidation` fluent builder / `TStateMachine` 单实例) 不承诺线程安全; 调用方需自行同步。
- **验证**: 参见 `Test.DeepBase.Cache.PBT.pas` / `Test.DeepBase.Browser.ResponseWaiter.PBT.pas` / `Test.DeepBase.Intent.pas` 并发用例。

### "跨平台"
- **真实范围**:
  - `DeepBaseCore` 是 **Windows 运行时核心** (依赖 Winapi, 含 TrayIcon / Hotkeys / Protection / FormState / AutoFix 等桌面能力), 不直接依赖 VCL/FMX/FireDAC。详见 BUG-280。
  - 跨平台扩展通过 `DeepBaseFMX` 包实现 (macOS/Linux), 但 FMX 包当前为 Partial (BUG-277 / BUG-281 跟踪 8 处 TODO)。
  - `DeepBase.Security`: Windows 走 DPAPI, 非 Windows 走 OpenSSL AES-256-GCM + PBKDF2 (UBS2 格式); SecretStore 非 Windows 默认 fail-closed, 需 `DEEPBASE_INSECURE_DEV_MODE` 显式启用开发模式。
  - `Hotkeys` / `TrayIcon` / `Protection` / `AutoFix.StackWalker` / `Browser` 为 Windows-only。
- **不是**: Core 不承诺可编译运行于 macOS/Linux。

## 关键初始化清单

| 场景 | 必须调用 |
|------|------|
| 任何 DB -backed 应用 | `DeepBase.InitializeWithDB(...)` + 链接 `DeepBase.Persistence.Manager.FireDAC` |
| Speech (ASR/TTS/WakeWord) | `DeepBase.Initialize*` (Registry 自注册) |
| LLM client | `DeepBase.Initialize*` 加载配置 + 凭据 |
| Commerce | `DeepBase.Initialize*` + FireDAC 存储 |
| AutoFix | **独立**于 `DeepBase.Initialize`: `AutoFix.Install` 必须在 `Application.Initialize` 之前; 同时传 `--autofix-mode` 启动参数 |
| DataPlatform | **独立**: `TDataPlatformBootstrap.Bootstrap` 不走 `DeepBase.Initialize` |
| Inference | 通过 IoC 注入 `IInferenceRuntime`; ONNX 提供者需 `HAS_ONNX` 编译定义 |

## 外部服务依赖清单

| 模块 | 外部依赖 |
|------|------|
| LLM | HTTP 网络 + 各 provider API key |
| Commerce | 支付 SDK (WeChatPay / Alipay / Stripe / PayPal) + 商户账号 + 服务端回调服务器 |
| Speech ASR (SenseVoice) | ONNX 模型目录 |
| Speech ASR (Baidu) / TTS (Edge/StepFun) | HTTP 网络 + 各 provider 凭据 |
| Browser | Chrome / Edge + WebView2 runtime |
| Inference (DirectML/CUDA) | `onnxruntime.dll` |
| Persistence | FireDAC 驱动 (SQLite / PostgreSQL 等) |
| DataPlatform (SQLCipher) | SQLCipher 库 (当前未在 DataPlatform.dpk 实际接入) |
