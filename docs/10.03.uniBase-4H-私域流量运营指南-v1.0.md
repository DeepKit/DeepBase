### 12.3 Nginx 部署示例（推荐使用路径 /OmniSync）

以下示例假设：
- 已有站点域名：`www.goodmem.cn`
- OmniSync 统一落地页构建后的静态文件放在服务器目录：`/var/www/omnisync`（可按实际修改）
- 使用 Nginx 作为 Web 服务器

在现有 `server { server_name www.goodmem.cn; ... }` 配置块中增加一个 `location /OmniSync/` 即可：

```nginx path=null start=null
server {
    server_name www.goodmem.cn;
    root /var/www/goodmem;   # 原有站点根目录

    # 其他现有配置...

    # OmniSync 统一落地页，挂载在 /OmniSync 路径
    location /OmniSync/ {
        alias /var/www/omnisync/;
        index index.html;
        try_files $uri $uri/ /OmniSync/index.html;
    }
}
```

说明：
- 使用 `alias` 而不是 `root`，方便将 OmniSync 页面放在单独目录。
- 若是单页应用（SPA），`try_files` 会在找不到具体文件时回退到 `/OmniSync/index.html`。
- HTTPS 相关（`listen 443 ssl`、证书配置）保持与原有站点一致，不需要额外修改。

未来如果需要将 OmniSync 独立为子域名 `OmniSync.goodmem.cn`，可新增一个单独的 `server` 块：

```nginx path=null start=null
server {
    server_name OmniSync.goodmem.cn;
    root /var/www/omnisync;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

此时可在 `www.goodmem.cn/OmniSync` 上做 301 重定向到 `https://OmniSync.goodmem.cn`，实现平滑迁移。

## 十三、关于页面推荐结构（所有工具通用）

本节建议所有可视化工具（TwoKeyRun / MoveC / OmniSync / SVGThing / Stocks 等）在「关于」页面中遵循统一结构，方便用户理解并与私域体系形成闭环。

### 13.1 页面目标

- 集中呈现开发者/公司信息与支持方式（打赏、联系方式）。
- 明确展示公司公众号二维码，作为解锁/获取帮助的统一入口。
- 为各工具提供一致的“品牌形象”，与 `https://www.goodmem.cn/tools` 工具合集页形成联动。

### 13.2 推荐 Tab 结构

推荐在 About 页中使用 6 个 Tab（可按需隐藏部分 Tab，具体由 `aboutMeImages.enabled` 控制）：

1. **公司公众号**（ImageKey=`official_gzh`）
   - 展示二维码图片（公司公众号）。
   - 右侧文字示例：
     - 标题：`付乙工具集公众号`
     - 小字：`主体：南充市智慧网络技术有限责任公司` / `公众号 ID：aizhihuilab`
     - 链接按钮：`打开工具合集页面` → `https://www.goodmem.cn/tools`。

2. **微信打赏**（ImageKey=`wechat`）
   - 展示微信收款码二维码。
   - 文字区域展示微信昵称/备注说明等。

3. **支付宝打赏**（ImageKey=`alipay`）
   - 展示支付宝收款码二维码。

4. **BTC 打赏**（ImageKey=`btc`）
   - 展示 BTC 收款二维码（可选）。
   - 下方显示明文 BTC 地址，支持点击复制。

5. **USDT 打赏**（ImageKey=`usdt`）
   - 展示 USDT 收款二维码（可选，建议标明链类型，如 TRON）。
   - 下方显示明文 USDT 地址，支持点击复制。

6. **关于我 / 关于本工具**（ImageKey=`aboutme`）
   - 展示个人头像或 Logo 图像。
   - 文字部分可包含：开发者昵称「付乙」、网站 `www.goodmem.cn`、工具简介、版权信息等。

> 以上 6 个 Tab 的图像与文字均推荐存放在应用 DB1 的 `aboutMeImages` 表中，统一通过 UniBase.VCL.AboutFrame 读取。

### 13.3 与解锁/公众号体系的关系

- 「公司公众号」页签的二维码应与解锁弹窗和统一落地页中展示的公众号二维码保持一致（即 `official_gzh`）。
- About 页中的文案可以简要重复解锁流程提示，例如：
  - `关注「付乙工具集公众号」，在公众号内回复「双键/同步/...」获取解锁码。`
- 通过工具内 About 页 + 解锁弹窗 + 工具合集页 (`/tools`) 的一致设计，用户可以在任意入口清晰理解：
  - 去哪里关注公众号；
  - 用什么关键词获取某个工具的解锁码；
  - 如何支持开发者（微信/支付宝/BTC/USDT 打赏）。

> 关于 AboutFrame 与 `aboutMeImages` 表的技术细节和集成步骤，见 `10.01.uniBase-4AI-发布更新解锁集成指南-v1.0.md` 第 4 章，以及 `04.01.uniBase-4AI-数据库Schema说明-v1.0.md` 中的表结构说明。
