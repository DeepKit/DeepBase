# AntiTamper 防篡改机制集成指南

> **文档版本**: 1.0
> **创建日期**: 2025-12-14
> **用途**: 指导各项目集成 UniBase 防篡改机制（SeedTool + AntiTamper）

---

## 一、概述

### 1.1 什么是 AntiTamper

AntiTamper 是 UniBase 提供的防篡改机制，用于保护敏感资源（如收款二维码、授权图片等）不被篡改。

**安全特性**：

| 特性 | 实现 |
|------|------|
| 数据加密 | AES-256-CBC (Windows Crypto API) |
| 密钥派生 | PBKDF2-SHA256 (可配置迭代次数) |
| 完整性校验 | SHA-256 (明文哈希) |
| 防篡改校验 | HMAC-SHA256 (派生密钥签名) |
| 安全策略 | Fail-closed (校验失败即退出) |

### 1.2 核心文件

```
UniBase/
├── Core/
│   ├── UniBase.AntiTamper.pas      # 防篡改主模块（待整合）
│   └── UniBase.Protection.pas       # 基础加密实现
└── Tools/
    └── SeedTool/
        ├── SeedTool.exe             # 播种工具（GUI）
        ├── uAntiTamperPackage.pas   # 防篡改包（源码）
        ├── uBasicProtection.pas     # AES-256 实现
        └── *.md                     # 文档
```

### 1.3 工作流程

```
开发时（SeedTool）:
  原始图片 → AES-256加密 → 计算SHA-256 → 计算HMAC → 写入数据库

运行时（主程序）:
  读取密文 → AES-256解密 → 验证SHA-256 → 验证HMAC → 显示图片
                              ↓                  ↓
                        失败=篡改           失败=篡改
                              ↓                  ↓
                            弹出警告 + 程序退出 (fail-closed)
```

## 二、集成步骤

### 步骤 1：复制核心文件到项目

将以下文件复制到你的项目目录（或通过搜索路径引用 UniBase）：

```
uAntiTamperPackage.pas   // 防篡改主模块
uBasicProtection.pas     // AES-256 加密实现
```

**推荐方式**：直接在项目搜索路径中添加 UniBase 路径：
- `D:\_Progs\02Business\UniBase\Tools\SeedTool`（临时）
- 或等待整合到 `UniBase\Core` 后使用 `UniBase.AntiTamper`

### 步骤 2：添加 uses 引用

```pascal
uses
  uAntiTamperPackage,
  // FireDAC 必需单元
  FireDAC.Comp.Client, FireDAC.Stan.Param, FireDAC.Stan.Def,
  FireDAC.Phys.SQLite, FireDAC.Phys.SQLiteDef;
```

### 步骤 3：初始化配置（程序启动时）

```pascal
procedure TfrmMain.FormCreate(Sender: TObject);
var
  Config: TAntiTamperConfig;
begin
  // 配置防篡改参数 - 必须与 SeedTool 完全一致
  Config := TAntiTamperPackage.GetDefaultConfig;
  Config.EncryptionKey := 'YourApp_UniqueKey_2025';  // 自定义密钥
  Config.Salt := 'YourApp_Salt_v1';                   // 自定义盐值
  Config.KdfIterations := 10000;                      // KDF 迭代次数
  Config.EnableHMAC := True;                          // 启用 HMAC
  Config.EncryptionType := etAES256;                  // AES-256 加密
  Config.EnableLogging := False;                      // 生产环境关闭日志
  TAntiTamperPackage.Initialize(Config);
  
  // 连接数据库后初始化表结构
  FDConnection.Connected := True;
  TAntiTamperPackage.SetupDatabase(FDConnection);
end;
```

### 步骤 4：加载加密图像

```pascal
procedure TMyForm.LoadSecureImages;
var
  AddressText: string;
begin
  // 加载并显示图像，同时获取地址文本
  if TAntiTamperPackage.LoadSecureImage(FDTable1, 'wechat', imgWechat, AddressText) then
    lblWechatAddress.Caption := AddressText
  else
    // 加载失败或校验失败 → 程序会自动退出
    ShowMessage('图像加载失败');
end;
```

## 三、使用 SeedTool 播种

### 3.1 播种流程

1. 运行 `SeedTool.exe`
2. 选择数据库文件路径（如 `YourApp.db`）
3. 配置加密参数（**必须与代码一致**）：
   - EncryptionKey: `YourApp_UniqueKey_2025`
   - Salt: `YourApp_Salt_v1`
   - KdfIterations: `10000`
   - EnableHMAC: ✓
4. 添加图像文件
5. （可选）切换到"文字配置"页签填写地址和描述
6. 点击"开始播种"

### 3.2 数据库表结构

```sql
CREATE TABLE images (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  image_key TEXT NOT NULL UNIQUE,     -- 业务主键
  image_data BLOB NOT NULL,           -- AES-256 加密密文
  address_text TEXT,                  -- 地址/网址文本
  description TEXT,                   -- 描述信息
  sha256_hash TEXT NOT NULL,          -- 明文 SHA-256
  hmac_sha256 TEXT NOT NULL,          -- 明文 HMAC-SHA256
  created_at DATETIME,
  updated_at DATETIME
);
```

## 五、密钥配置方案

### 方案 A：共享密钥（推荐，简化维护）

如果所有单机工具使用**相同的收款二维码**，推荐使用统一密钥：

```pascal
Config.EncryptionKey := 'UniBase_Shared_Key_2025';
Config.Salt := 'UniBase_Shared_Salt_v1';
Config.KdfIterations := 10000;
Config.EnableHMAC := True;
```

**优点**：
- 只需播种一次模板数据库
- 批量复制到各项目即可
- 更新收款信息时统一处理

**使用方法**：
1. 用 SeedTool 播种 `template.db`
2. 运行 `batch_seed.bat` 批量复制到各项目
3. 各项目使用相同的密钥配置

详见：[共享密钥配置.md](../../Tools/SeedTool/共享密钥配置.md)

### 方案 B：独立密钥（更安全）

如果需要更高安全性，每个项目使用独立密钥：

| 项目 | EncryptionKey | Salt |
|------|---------------|------|
| MoveC | `MoveC_AntiTamper_Key_2025` | `MoveC_Salt_v1` |
| TwoKeyRun | `TwoKeyRun_AntiTamper_Key_2025` | `TwoKeyRun_Salt_v1` |
| TransSuccess | `TransSuccess_AntiTamper_Key_2025` | `TransSuccess_Salt_v1` |
| uniSVG | `uniSVG_AntiTamper_Key_2025` | `uniSVG_Salt_v1` |
| EasyConfig | `EasyConfig_AntiTamper_Key_2025` | `EasyConfig_Salt_v1` |
| OmniSync | `OmniSync_AntiTamper_Key_2025` | `OmniSync_Salt_v1` |
| Touchstone | `Touchstone_AntiTamper_Key_2025` | `Touchstone_Salt_v1` |
| wyjx | `wyjx_AntiTamper_Key_2025` | `wyjx_Salt_v1` |
| Chain2VFactory | `Chain2V_AntiTamper_Key_2025` | `Chain2V_Salt_v1` |

**缺点**：需要为每个项目单独播种。

### 建议

- **收款二维码**（公开信息）→ 使用共享密钥
- **授权文件**（敏感信息）→ 使用独立密钥

## 六、安全建议

1. **每个项目使用独立的密钥和盐值**
2. **不要分发 SeedTool** - 仅开发机使用
3. **定期备份数据库文件**
4. **生产环境关闭日志** - `Config.EnableLogging := False`
5. **密钥不要硬编码在明显位置** - 可考虑混淆或分散存储

## 八、常见问题

### Q1: 报错 "no such column: sha256_hash"
调用 `TAntiTamperPackage.SetupDatabase(FDConnection)` 自动创建/升级表结构。

### Q2: 解密失败
检查 SeedTool 和主程序的加密参数是否完全一致。

### Q3: 如何更换密钥？
修改密钥后需用 SeedTool 重新播种所有图像。

### Q4: 数据库被篡改会怎样？
主程序校验失败 → 弹出警告 → 程序退出。
