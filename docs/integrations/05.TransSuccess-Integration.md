## 集成方案

### 方案概述
TransSuccess 是 VCL 应用，可直接使用 `UniBase.VCL.AboutFrame`。

### 实施步骤

#### Phase 1: UniBase 集成
1. 添加 UniBase 到项目搜索路径
2. 在 dpr 文件添加必要的 uses:
   ```delphi
   uses
     UniBase.Manager,
     UniBase.Security,
     UniBase.VCL.AboutFrame,
     ...
   ```

#### Phase 2: 数据库配置
1. 创建 `TransSuccessConfig.db`
2. 添加 `aboutMeImages` 表
3. 使用 SeedTool 填充 6 个标准图片

#### Phase 3: UI 集成
可选方案：

**方案 A: 菜单项 + 弹窗**
- 在主窗体菜单添加 "帮助" -> "关于"
- 点击弹出包含 AboutFrame 的窗体

**方案 B: 主窗体内嵌 Tab**
- 在主窗体添加 TabSheet
- 嵌入 AboutFrame

**推荐: 方案 A** (工具类应用适合弹窗式)

#### Phase 4: 实现代码

```delphi
// 新建 AboutForm.pas
unit AboutForm;

interface

uses
  Vcl.Forms, UniBase.VCL.AboutFrame;

type
  TAboutForm = class(TForm)
  private
    FAboutFrame: TAboutFrame;
  public
    constructor Create(AOwner: TComponent); override;
  end;

implementation

constructor TAboutForm.Create(AOwner: TComponent);
begin
  inherited;
  Caption := '关于 码到成功';
  Width := 500;
  Height := 600;
  Position := poMainFormCenter;
  
  FAboutFrame := TAboutFrame.Create(Self);
  FAboutFrame.Parent := Self;
  FAboutFrame.Align := alClient;
end;
```

## SeedTool 工作流

```batch
# 创建数据库和表
SeedTool.exe --db TransSuccessConfig.db --init-table aboutMeImages

# 填充图片数据
SeedTool.exe --db TransSuccessConfig.db --seed-images ^
  --source UniBase/Tools/SeedTool/assets/ ^
  --keys official_gzh,wechat,alipay,btc,usdt,aboutme
```
