## 目标架构

### 数据库配置
复用现有 `InfoCenterConfig.db`，添加 `aboutMeImages` 表：

```sql
CREATE TABLE IF NOT EXISTS aboutMeImages (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  image_key TEXT NOT NULL UNIQUE,
  image_data BLOB NOT NULL,      -- AES-256 加密的图像数据（SeedTool 写入）
  address_text TEXT,
  description TEXT,
  enabled INTEGER NOT NULL DEFAULT 1,
  sha256_hash TEXT NOT NULL,
  hmac_sha256 TEXT NOT NULL,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### 标准 ImageKeys
| Key | 描述 |
|-----|------|
| `official_gzh` | 官方公众号 |
| `wechat` | 微信收款码 |
| `alipay` | 支付宝收款码 |
| `btc` | BTC 钱包地址二维码 |
| `usdt` | USDT 钱包地址二维码 |
| `aboutme` | 个人介绍/名片 |

## 集成方案

### 挑战：需要 FMX 版 AboutFrame

与 OmniSync 相同，InfoCenter 使用 FMX 框架。
需要 `UniBase.FMX.AboutFrame` 组件。

### 依赖：FMX 版 AboutFrame

本集成依赖 OmniSync 集成任务中创建的 `UniBase.FMX.AboutFrame.pas`。

### 实施步骤

#### Phase 1: 数据库扩展
1. 在 `InfoCenterConfig.db` 中添加 `aboutMeImages` 表
2. 使用 SeedTool 填充 6 个标准图片

#### Phase 2: UI 集成
1. 在主窗体菜单或侧边栏添加 "关于" 入口
2. 创建 About 页面或弹窗
3. 嵌入 `TFMXAboutFrame`（`UniBase.FMX.AboutFrame`，对齐后复用）

#### Phase 3: 配置
1. 配置数据库路径指向 `InfoCenterConfig.db`
2. 初始化 `UniBase.AntiTamper`（与 SeedTool 播种参数一致）
3. 验证图片可正确解密并通过 sha256/hmac 校验

## SeedTool 工作流

SeedTool 当前以 GUI 方式使用（未实现 CLI 参数）。建议：
1. 打开 `UniBase/Tools/SeedTool/SeedTool.exe`
2. 选择现有数据库: `InfoCenterConfig.db`
3. 初始化 `aboutMeImages` 表（如不存在）
4. 播种 6 张图片（ImageKey: official_gzh/wechat/alipay/btc/usdt/aboutme）
