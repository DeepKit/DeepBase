### 现有 FrameAboutMe.pas 分析

**使用的组件:**
- `TPageControl` + 5 个 `TTabSheet` (Wechat/Alipay/BTC/USDT/AboutMe)
- `TImage` - 显示二维码图片
- `TLabel` - 显示提示和地址
- `TButton` - 复制 BTC/USDT 地址
- `TFDConnection` + `TFDTable` - FireDAC SQLite 连接

**安全机制:**
- 使用 `uAntiTamperPackage`, `uBasicProtection` (旧版 UniBase 组件)
- 图片从数据库加载，带 HMAC 签名验证
- 设计时初始化 + Timer 延迟加载

**数据库:**
- 表名: `aboutMeImages` (已是标准名)
- 使用 `GetProjectRootPath` 确定 `data.db` 位置

### 技术特点
- Tab 自动轮播 (60秒/页)
- 机器码显示 (点击复制)
- 迁移旧加密数据方法 (`MigrateEncryptedImages`)

## 集成方案

### 方案 A: 替换为 UniBase.VCL.AboutFrame (推荐)

**优点:**
- 统一代码，减少维护负担
- 自动获取 UniBase 新功能
- 标准化 Tab 页和布局

**步骤:**
1. 备份现有 `FrameAboutMe.pas`
2. 创建 `SVGThingConfig.db`，迁移 `aboutMeImages` 数据
3. 在主窗体中替换 `TFrameAboutMe` 为 `UniBase.VCL.TAboutFrame`
4. 更新 uses 列表
5. 测试验证

### 方案 B: 保留 UI，更换数据源

**优点:**
- 保留自定义 UI (如机器码显示、Tab 轮播)
- 最小改动

**步骤:**
1. 创建 `SVGThingConfig.db`
2. 修改 `FDConnection1` 指向新数据库
3. 移除旧版 AntiTamper 依赖
4. 使用 `UniBase.Security.TAntiTamperPackage` 加载图片

### 推荐方案: B (保留 UI)

SVGThing 的 AboutFrame 有独特功能 (机器码、轮播)，建议保留 UI 结构，仅更换数据源。
