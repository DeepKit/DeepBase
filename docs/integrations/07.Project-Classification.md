## 二、单机运行项目（9个）

### 2.1 特征

- 纯本地运行，无需网络（或仅调用外部 API）
- 无用户账号体系
- 数据存储在本地 SQLite
- 授权方式：解锁码 / 激活码

### 2.2 项目详情

#### MoveC - C盘瘦身神器
- **定位**：Windows 系统盘空间管理工具
- **技术栈**：Delphi VCL + SQLite
- **授权**：打赏模式（免费使用）
- **AntiTamper**：✅ 已集成（收款二维码防篡改）

#### TwoKeyRun - 双键快启
- **定位**：60 格快捷启动工具
- **技术栈**：Delphi VCL + Skia + SQLite
- **授权**：公众号解锁码（24格免费，48/60格解锁）
- **AntiTamper**：待集成

#### TransSuccess - 码到成功
- **定位**：文本编码检测与批量转换
- **技术栈**：Delphi VCL + SQLite
- **授权**：付费激活码
- **AntiTamper**：待集成

#### EasyConfig - 配置编辑器
- **定位**：跨平台配置文件 IDE
- **技术栈**：Delphi FMX + SQLite
- **授权**：付费激活码
- **AntiTamper**：待集成

#### OmniSync - 全能同步
- **定位**：文件同步 + 快传 + 屏幕协作
- **技术栈**：Delphi FMX + Syncthing
- **授权**：付费激活码
- **AntiTamper**：待集成

#### uniSVG - SVG智慧工坊
- **定位**：SVG 预览/转换/导出工具
- **技术栈**：Delphi VCL + CEF + SQLite
- **授权**：付费激活码
- **AntiTamper**：✅ 已集成

#### wyjx - 无影键侠
- **定位**：自动化操作平台（对标按键精灵）
- **技术栈**：Delphi VCL + Graphics32 + SQLite
- **授权**：付费激活码 / 订阅
- **AntiTamper**：待集成

#### Chain2VFactory - 链影工厂
- **定位**：视频生成工具（FFmpeg）
- **技术栈**：Delphi VCL + Python 后端
- **授权**：付费激活码
- **AntiTamper**：待集成

#### Touchstone - 试金石
- **定位**：多 LLM 并行测试工具
- **技术栈**：Delphi VCL + WebView2 + SQLite
- **授权**：付费激活码
- **AntiTamper**：待集成

## 三、多租户项目（5个）

### 3.1 特征

- 需要用户账号体系
- 数据可能存储在云端
- 支持多用户 / 团队协作
- 授权方式：账号订阅 / Token 计费

### 3.2 项目详情

#### TheSenate - 军师决策推演
- **定位**：四角色 AI 推演决策平台
- **技术栈**：Delphi FMX + PostgreSQL + LLM API
- **多租户需求**：
  - 用户账号（注册/登录）
  - Token 计费（LLM 调用）
  - 账务中心（充值/消费记录）
  - API Key 管理（系统级/用户级）
- **后端**：已有 SenateAccountingCenter

#### Insight - 洞见·思维显影室
- **定位**：个人决策与思维显影工具
- **技术栈**：Delphi FMX + SQLite + LLM API
- **多租户需求**：
  - 用户身份（可选云同步）
  - 多会话管理
  - 数据同步（跨设备）
- **后端**：已有 USyncManager

#### InfoCenter (Stocks) - 股讯聚焦
- **定位**：股民信息聚合分析中枢
- **技术栈**：Delphi FMX + Python 后端
- **多租户需求**：
  - 用户账号（订阅会员）
  - 数据权限（免费/付费内容）
  - 推送服务
- **后端**：待规划

#### DevDirector (devDir) - 软件工程导演台
- **定位**：软件开发流程管理 + AI 协作
- **技术栈**：Delphi VCL + SQLite
- **多租户需求**：
  - 团队协作（项目共享）
  - 多 AI 角色管理
  - 云端项目存储
- **后端**：待规划

#### TheLot - 灵感天幕
- **定位**：课件/内容创作工具
- **技术栈**：Delphi + HTML 导出
- **多租户需求**：
  - 用户账号
  - 云端存储（课件）
  - 分享功能
- **后端**：待规划

### 3.4 UniBase 多租户模块规划

需要在 UniBase 中新增以下模块：

| 模块 | 文件名 | 功能 |
|------|--------|------|
| 认证 | `UniBase.Auth.pas` | 登录/注册/Token 管理 |
| 用户 | `UniBase.User.pas` | 用户信息/偏好设置 |
| 同步 | `UniBase.Sync.pas` | 数据同步（云端） |
| 计费 | `UniBase.Billing.pas` | Token 计费/订阅管理 |
| API | `UniBase.CloudAPI.pas` | 统一云端 API 调用 |
