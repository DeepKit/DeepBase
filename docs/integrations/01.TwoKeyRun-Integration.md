## 1. 现状分析

### 1.1 当前数据库配置
| 项目 | 当前值 |
|------|--------|
| 数据库名称 | `TwoKeyRun.db` |
| 图片存储表 | 自定义实现 (通过 `uDM.pas` 和 `DatabaseSecurity.pas`) |
| 安全模块 | `TDatabaseSecurityManager` (自定义) |
| About Frame | `FrameAboutMe.pas` (自定义 ~856 行) |

### 1.2 现有功能
TwoKeyRun 的 `FrameAboutMe.pas` 实现了:
- 5 个打赏页签 (微信/支付宝/BTC/USDT/关于我)
- 自定义加密地址存储 (`TDonationAddressInfo`)
- 机器码生成与显示
- 主题感知的 Tab 绘制
- 图片从数据库加载 (`LoadImageFromDB`)

### 1.3 集成目标
- 迁移到 UniBase 统一的 `aboutMeImages` 表规范
- 使用 `TwoKeyRunConfig.db` 作为 DB1
- 复用 `UniBase.VCL.AboutFrame` 或保留现有 UI 但切换数据源

## 2. 目标架构

### 2.1 数据库命名
```
旧: TwoKeyRun.db (内含多种业务数据)
新: TwoKeyRunConfig.db (专用配置/公众号/打赏图像)
```

### 2.2 aboutMeImages 表结构
```sql
CREATE TABLE IF NOT EXISTS aboutMeImages (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  image_key TEXT NOT NULL UNIQUE,
  image_data BLOB NOT NULL,      -- AES-256 加密的图像数据（SeedTool 写入）
  address_text TEXT,
  description TEXT,
  enabled INTEGER NOT NULL DEFAULT 1,  -- 0=隐藏该Tab, 1=显示
  sha256_hash TEXT NOT NULL,     -- 解密后明文图像的 SHA-256（HEX）
  hmac_sha256 TEXT NOT NULL,     -- 解密后明文图像的 HMAC-SHA256（HEX）
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### 2.3 标准 ImageKey 列表
| ImageKey | 对应页签 | 用途 |
|----------|----------|------|
| `official_gzh` | 公司公众号 | 公众号二维码 (可选) |
| `wechat` | 微信 | 微信收款码 |
| `alipay` | 支付宝 | 支付宝收款码 |
| `btc` | BTC | BTC 二维码 + 地址 |
| `usdt` | USDT | USDT 二维码 + 地址 |
| `aboutme` | 关于我 | 开发者照片/介绍 |

## 3. 迁移方案

### 3.1 方案 A: 完全替换为 UniBase.VCL.AboutFrame (推荐)

**优点**:
- 代码量减少 ~800 行
- 自动获得 UniBase 安全模块更新
- 与其他工具保持一致

**步骤**:
1. 创建 `TwoKeyRunConfig.db` 并初始化 `aboutMeImages` 表
2. 使用 SeedTool 播种 6 个标准 ImageKey
3. 在主窗体中替换 `TFrameAboutMe` 为 `TUniAboutFrame`
4. 设置 `TUniAboutFrame.DatabasePath := 'TwoKeyRunConfig.db'`
5. 移除 `FrameAboutMe.pas` 和 `DatabaseSecurity.pas` (如仅用于 About)

**代码示例**:
```pascal
uses
  UniBase.AntiTamper,
  UniBase.VCL.AboutFrame;

procedure TMainForm.CreateAboutFrame;
var
  Frame: TUniAboutFrame;
  Config: TAntiTamperConfig;
begin
  // AntiTamper 初始化（参数必须与 SeedTool 播种时一致）
  Config := TAntiTamperPackage.GetDefaultConfig;
  // TwoKeyRun 现有工程里已使用 @2241114 作为密码/口令（DB/Debug 等）；这里复用它作为 AntiTamper 的 EncryptionKey
  Config.EncryptionKey := '@2241114';
  Config.Salt := 'TwoKeyRun_Salt_v1';
  Config.KdfIterations := 10000;
  Config.EnableHMAC := True;
  TAntiTamperPackage.Initialize(Config);

  Frame := TUniAboutFrame.Create(Self);
  Frame.Parent := pnlAbout;
  Frame.Align := alClient;
  Frame.DatabasePath := ExtractFilePath(ParamStr(0)) + 'TwoKeyRunConfig.db';
  Frame.ManualInitialize;
end;
```

### 3.2 方案 B: 保留现有 UI，切换数据源

**优点**:
- 保留 TwoKeyRun 特有的 UI 定制
- 渐进式迁移，风险较低

**步骤**:
1. 创建 `TwoKeyRunConfig.db`
2. 修改 `FrameAboutMe.pas` 连接新数据库
3. 将 `LoadImageFromDB` 改为调用 `TAntiTamperPackage.LoadSecureImage`
4. 使用 SeedTool 播种数据
5. 保留主题/控制器集成逻辑

## 4. SeedTool 播种流程

### 4.1 准备图像资源
```
Assets/
├── official_gzh.png   (公司公众号二维码)
├── wechat.png         (微信收款码)
├── alipay.png         (支付宝收款码)
├── btc.png            (BTC 二维码)
├── usdt.png           (USDT 二维码)
└── aboutme.png        (开发者照片)
```

### 4.2 运行 SeedTool
```powershell
# 打开 SeedTool
cd D:\_Progs\02Business\UniBase\Tools\SeedTool
.\SeedTool.exe

# 在 SeedTool 中:
# 1. 选择目标数据库: TwoKeyRunConfig.db
# 2. 导入 6 张图片
# 3. 配置地址文本 (BTC/USDT 地址)
# 4. 设置各 ImageKey 的 enabled 状态
# 5. 执行播种
```

### 4.3 验证播种结果
```sql
SELECT image_key, enabled, LENGTH(image_data) AS size, address_text 
FROM aboutMeImages;
```

## 5. 解锁/公众号关联

TwoKeyRun 已集成 `UniBase.Unlock` 模块:
- 解锁码验证: `TUniBaseUnlock.ValidateCode`
- 公众号关注流程: 用户扫描 `official_gzh` 二维码 → 获取解锁码 → 输入解锁

About Frame 中的公众号 Tab 可引导用户关注以获取解锁码。
