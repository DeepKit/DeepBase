## 目标架构

### 新建数据库
创建 `OmniSyncConfig.db` 用于存放应用配置，与业务数据库分离：

```sql
-- aboutMeImages 表 (标准 UniBase 模式)
CREATE TABLE IF NOT EXISTS aboutMeImages (
    image_key      TEXT PRIMARY KEY,
    image_data     BLOB,
    address_text   TEXT,
    sha256_hash    TEXT,
    hmac_signature TEXT,
    enabled        INTEGER DEFAULT 1
);
```

## 集成方案

### 挑战：VCL vs FMX
`UniBase.VCL.AboutFrame` 是 VCL 组件，而 OmniSync 使用 FMX。

**方案 A: 创建 FMX 版 AboutFrame** (推荐)
- 新建 `UniBase.FMX.AboutFrame.pas`
- 复用 `UniBase.Security` 的安全存储逻辑
- 支持 FMX 原生控件 (TImage, TTabControl)

**方案 B: 混合模式**
- 使用 VCL 窗体承载 AboutFrame
- 从 FMX 主程序调用
- 不推荐 - 增加复杂度

### 推荐实施步骤

#### Phase 1: 创建 FMX 版 AboutFrame
1. 创建 `VCL/UniBase.FMX.AboutFrame.pas`
2. 实现与 VCL 版相同的功能接口
3. 使用 FMX 控件: `TImage`, `TTabControl`, `TLabel`, `TButton`

#### Phase 2: 数据库配置
1. 创建 `OmniSyncConfig.db`
2. 添加 `aboutMeImages` 表
3. 使用 SeedTool 填充 6 个标准图片

#### Phase 3: 集成到 OmniSync
1. 在 `uSidePanelFrame` 添加 "关于" 导航项
2. 在 `uMainForm` 添加 AboutFrame 容器区域
3. 导航点击时显示 AboutFrame

## SeedTool 工作流

```batch
# 1. 创建数据库和表
SeedTool.exe --db OmniSyncConfig.db --init-table aboutMeImages

# 2. 导入图片 (使用标准 assets 目录)
SeedTool.exe --db OmniSyncConfig.db --seed-images ^
  --source UniBase/Tools/SeedTool/assets/ ^
  --keys official_gzh,wechat,alipay,btc,usdt,aboutme
```
