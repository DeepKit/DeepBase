# UniBase / uniFlow 术语表

> 版本: 1.0.0  
> 更新日期: 2026-05-04  
> 目的: 统一 UniBase 核心术语与 uniFlow 术语，避免 API 和文档混用

---

## 使用规则

- 代码、文档、日志、配置项统一使用本表“规范术语”。
- 历史别名仅用于迁移说明，不用于新增代码。
- 新术语先登记本文件，再进入实现与对外文档。

---

## A. UniBase 核心术语

| 规范术语 | 定义 | 禁用同义词 | 关联模块 |
|---|---|---|---|
| ConfigDB (DB1) | UniBase 配置数据库（每个应用一份） | MainDB, MetaDB | `UniBase.Manager` |
| DB2 / DB3 | 业务数据库（本地/远程） | ConfigDB2 | `UniBase.DB.DoQry` |
| SchemaInfo.SchemaVersion | ConfigDB 架构版本号（统一为 `1.0.0`） | DBVersion, v0.3 | Schema |
| UniDbInit | DoQry 初始化入口 | DoQryInit | `UniBase.DB.DoQry` |
| TUniQueryContext | DoQry 执行上下文 | TDoQryContext | `UniBase.DB.DoQry` |
| UniDbSelect / UniDbExec / UniDbScalar | 统一查询/写入/标量 API | DoQryExecSelect | `UniBase.DB.DoQry` |
| UniDbInsertReturningId | 插入并返回主键 ID | InsertAndGetId | `UniBase.DB.DoQry` |
| UniDbRunInTx | 事务包装（支持嵌套 SAVEPOINT） | RunInTransaction | `UniBase.DB.DoQry` |
| Settings | 通用配置表 | Configs, AppSettings | `UniBase.Config` |
| FormStates | 窗体状态表 | WindowStates | `UniBase.FormState` |
| I18nTexts | 翻译文本表 | Translations | `UniBase.i18n` |
| MRU.ItemKey | 最近使用项标识字段 | ItemPath | `UniBase.MRU` |
| Logger() | 全局日志入口 | Log(), LogUtil | `UniBase.Logging` |
| DiagnoseAll / AutoFix | Schema 诊断与修复入口 | CheckDB | `UniBase.Diagnose` |
| TUniBaseLLM | 直接 LLM 调用 API | AIClient | `UniBase.LLM` |
| TLLMManager | Prompt/版本/元提示词管理 API | PromptManagerV1 | `UniBase.LLM.Manager` |
| LLM() Facade | Features 便捷门面 API | DefaultLLM | `Features/UniBase.LLM.Service` |
| LLMConfig.ApiKeyRef | LLM 凭据引用字段（`credman:`） | ApiKey plaintext | LLM Schema |
| LLMApiKeys | LLM 凭据引用表（不存明文） | ApiKeyStore | LLM Schema |
| aboutMeImages | About/打赏/公众号图像表 | AboutImagesLegacy | Schema Tier2 |

## B. uniFlow 术语

| 规范术语 | 定义 | 禁用同义词 | 备注 |
|---|---|---|---|
| FlowDefinition | 流程定义 | Workflow, ProcessDef | `TWorkflowDefinition` |
| FlowInstance | 流程实例 | Process, Job, Task | `TFlowInstance` |
| Step | 流程步骤 | Stage, Phase, Node | `{Verb}{Noun}` |
| TUniFlowEvent | 状态变化事件 | Activity, ActionLog | 事件溯源 |
| Snapshot | 实例快照 | StateBackup | `TSnapshot` |
| Source | 事件来源 | Origin, Sender | `SoIs/SayDone/...` |
| Payload | 事件载荷 JSON | Data, Body | JSON 对象 |
| IEventStore | 事件存储接口 | EventRepo | `Append/Read...` |
| IPluginActionExecutor | 插件执行接口 | SkillExecutor | `Execute/ValidateInput` |

## 命名约束

1. UniBase 文档必须使用 `UniDb*` 前缀，不再新增 `DoQry*` 命名。
2. MRU 字段统一为 `ItemKey`，历史 `ItemPath` 仅用于迁移脚本说明。
3. LLM API 说明必须明确三套入口的使用场景和迁移路径。
