# Glossary（术语表）

> 版本: 1.0
> 更新日期: 2025-12-07
> 目的: 统一 UniBase/uniFlow 及其集成中的核心术语，降低语义熵

---

## 使用规则
- 在代码、文档、UI、日志、配置中一律使用“规范术语”。
- “禁用同义词”不得出现；若历史代码存在，需在迁移时统一替换。
- 新术语必须先在本文件登记，再在代码中使用。

---

## 术语一览

| 规范术语 | 定义 | 禁用同义词 | 备注 |
|---|---|---|---|
| FlowDefinition | 流程定义，描述步骤与转换规则 | Workflow, ProcessDef | 类型：`TWorkflowDefinition` |
| FlowInstance | 流程实例，某次流程执行的具体对象 | Process, Job, Task, Workflow | 类型：`TFlowInstance` |
| Step | 流程步骤，按“动词+名词”命名 | Stage, Phase, Node | 例：`ClarifyRequirement` |
| TUniFlowEvent | 事件，记录状态变化 | Log, Activity, Action, Record | 字段：`id, flowId, step, source, status, payload...` |
| Snapshot | 快照，流程状态的压缩表示 | State, Checkpoint, Backup | 类型：`TSnapshot` |
| Source | 事件来源标识 | Origin, From, Sender | 值：`SoIs, SayDone, DevDirector, UniFlow, Skill, User, System` |
| Payload | 事件承载的数据 | Data, Body, Content | JSON 对象 |
| ErrorCode | 错误码（统一格式） | Code, Err, Errno | `{Source}/{Category}/{Specific}` |
| IEventStore | 事件存储接口 | EventRepo, EventDAO | 方法：`Append/AppendBatch/ReadEvents/...` |
| IPluginActionExecutor | Skill 执行接口 | Plugin, Extension | 方法：`Execute/GetMetadata/ValidateInput` |
| StateMachine | 有限状态机 | FSM, Automaton | 模块：`UniBase.StateMachine` |
| Transition | 状态转换 | Edge, Link | 定义：`(FromState, Trigger) -> ToState` |
| Logger | 日志接口 | Log, LogUtil | 接口：`ILogger` |
| ConfigProvider | 配置提供者 | Config, Cfg | 接口：`IConfigProvider` |
| LLM | 统一大模型调用封装 | AIClient, OpenAIClient | 类：`TUniBaseLLM` |

---

## 命名规范补充
- Step 名称：`{Verb}{Noun}`，Verb 取值集：`Clarify|Generate|Confirm|Apply|Validate|Execute|Complete`。
- Event `source` 取值必须来自上表 `Source` 列表，不得自创。
- 错误码 `Category` 取值：`Validation|Timeout|LLM|Skill|Network|Internal|External`。

---

## 扩展流程
1. 提交 PR 修改本文件，新增术语行，说明定义与禁用同义词。
2. 通过后在代码里应用新术语，提交“命名一致性修复”。
3. 运行命名一致性检查脚本，确保零“禁用同义词”。
