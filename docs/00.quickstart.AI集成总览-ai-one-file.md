## 0. 先掌握这 7 件事

1. **DeepBase 是 Delphi 桌面应用基础框架**，相当于 Delphi 世界的 Spring Boot。
2. 目标平台：**Delphi 13.1 (Compiler 37) on Windows 主打，FMX 跨平台（macOS/Linux）作为扩展**。
3. 包结构（从底到顶）：`Core → Services → Persistence → Governance → Features → VCL/FMX`，另有 `dcl*` 设计时包。
4. **四库分层**：DB1 本地 ConfigDB / DB2 本地业务库 / DB3 远程业务库 / DB4 生产后端库。客户端**不得直连 DB4**。
5. **敏感数据统一走 `DeepBase.Security`**（Windows DPAPI / 跨平台 UBS2），不要明文写 Settings / 日志 / 业务表。
6. **UI 线程禁止同步重试、长耗 LLM/语音调用、Sleep**。Resilience 在主线程用 `rmwRaise` 或 `ExecuteAsync`。
7. **当前状态**：RC 候选。LLM 与 SQLite+PostgreSQL 统一适配层在并行优化，下游只通过 facade/API 对接，别改底层适配器。

## 2. 核心骨架代码

### 2.1 最小启动

```delphi
program MyApp;
uses
  DeepBase.Manager,
  DeepBase.Persistence.Manager.FireDAC;  // 必须 uses，否则注册不上连接适配器
begin
  DeepBase.InitializeOrRaise;
  // ... 业务逻辑 ...
  DeepBase.Finalize;
end.
```

`root.txt` 放 EXE 同目录，首行写项目根路径。DeepBase 会定位到 `{AppName}Config.db`（DB1）。

### 2.2 常用 facade

```delphi
DeepBase.Config.SetConfig('App.Language', 'zh-CN');
DeepBase.Logger.Info('App started', 'MyTool');
Caption := DeepBase.I18n.T('Main.Title', 'My Tool');
DeepBase.FormState.RestoreFormState(Self);

// Secret（敏感值）
DeepBase.Security.SaveSecret('LLM.Default.ApiKey', Key);
ApiKey := DeepBase.Security.LoadSecret('LLM.Default.ApiKey');
```

### 2.3 LLM 五槽模型

```delphi
Store.SetTierModels(string(TierSmart),         ['gpt-4.1']);
Store.SetTierModels(string(TierBalanced),      ['gpt-4.1-mini']);
Store.SetTierModels(string(TierFast),          ['gpt-4.1-nano']);
```

## 2.5 DeepBase 配置铁律

**DeepBase 唯一的外部配置文件是 `root.txt`。** 所有配置、状态、治理规则统一存入 DB1（ConfigDB SQLite）。

禁止在下游项目中创建散落的 JSON/INI/YAML 配置文件。Governance 的 gates/actions/routes/purposes/fields 也必须存入 ConfigDB 的 governance 相关表，由 Manager 初始化时自动建表，通过 `TConfigLoader.LoadFromDB` 读取。

如果你看到任何指导说"创建 config/governance/*.json"——那是错误的旧方案，已废弃。

## 2.6 Governance observe → enforce 切换 SOP

Governance 默认以 `gmObserve` 模式启动（审计不阻断）。切换到 `gmEnforce` 后，不满足条件的操作会被实际拦截。

**切换方式（运行时）：**

```delphi
// 方式 1：通过 Lifecycle.SwitchMode（推荐，同时更新内存 + DB）
GovernanceLifecycle.SwitchMode(gmEnforce);

// 方式 2：通过 ConfigRegistrar（仅写 DB，需重启生效）
GovernanceRegistrar.SetMode('enforce');
```

**切换前检查清单：**

1. 所有 L2/L3 actions 已注册 DueRule（否则 fail-closed 拦截一切）
2. 所有带条件的 gate 已注册对应 evaluator（gckState/gckPermission/gckAccountability）
3. ActionGrid 双注册已完成（否则 EnterGate 报 "No action resolved"）
4. gate→actionKeys 手动关联已补齐（ConfigRegistrar 不自动关联）
5. Evidence 持久化已验证（`governance_evidence` 表可查）

**回滚：**

```delphi
GovernanceLifecycle.SwitchMode(gmObserve);
// 或重启后自动读取 DB 中的 mode 值
```

**已知限制：** `SwitchMode` 已修复为同时更新内存 FMode + DB 持久化。无需重启。

## 3. 强约束（违反会被门禁拦住）

| 类别 | 必须 | 禁止 |
|------|------|------|
| 配置 | 唯一外部文件 root.txt；所有配置存 DB1 ConfigDB | 在下游项目散落 JSON/INI/YAML 配置文件 |
| DB | DB1 只放框架配置与本地状态；DB4 只走后端 HTTP | 客户端直连 DB4；客户端保存支付私钥 |
| Security | API Key / Token / 支付密钥走 Security | 明文写 Settings / 日志 / 业务表 |
| Resilience | UI 用 `ExecuteAsync` 或 `rmwRaise` | UI 主线程 Sleep / 同步重试 |
| LLM | 用 facade / API | 下游私改 Core 里的 LLM.* / SQLite+PostgreSQL 适配层 |
| Commerce | 支付以后端通知为准；server-admin 适配器仅服务端 | 客户端直接改 order 状态为 paid |
| Speech | Key 走 Security；识别后台线程 | 在 UI 线程同步跑在线 ASR |
| Governance | 对外能力走 Gate + ActionGrid | 绕过 Runtime.EnterGate 执行高风险 Action |
| 包 | Win64 示例过编译门禁 | 把 dcl* 放进运行时依赖 |
