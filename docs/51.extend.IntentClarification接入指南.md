# DeepBase.IntentClarification 下游接入指南

## 概述

意图澄清模块为 Deep 系列产品提供 L0-L4 五级意图理解能力。下游产品通过实现 `IDomainAdapter` 接口并选择预设模板即可接入。

## 最小接入（3 步）

### 步骤 1：选择预设模板

| 模板名 | 适用场景 | MaxLevel | 需要 LLM |
|---|---|---|---|
| `tool-command` | 工具型指令（DeepLaunch、DeepMoveC） | L1 | 否 |
| `creative-assistant` | 创作辅助（DeepShine、DeepClip） | L2 | 是 |
| `decision-advisor` | 决策咨询（DeepInsight、DeepDev） | L4 | 是 |

### 步骤 2：实现 IDomainAdapter

```pascal
type
  TMyDomainAdapter = class(TInterfacedObject, IDomainAdapter)
  public
    function GetDomainName: string;
    function GetMaxLevel: TClarificationLevel;
    function GetContextForSession(const ASessionId: string): TDomainContext;
    function GetDomainKnowledge(const ATopic: string): string;
    function GetPresetSlots(const AIntentName: string): TArray<TIntentClarificationSlot>;
  end;

// 最小实现示例（DeepLaunch）：
function TLaunchAdapter.GetDomainName: string;
begin
  Result := 'DeepLaunch';
end;

function TLaunchAdapter.GetMaxLevel: TClarificationLevel;
begin
  Result := clL1;  // 只需要指令级澄清
end;

function TLaunchAdapter.GetContextForSession(const ASessionId: string): TDomainContext;
begin
  Result := Default(TDomainContext);
  Result.DomainName := 'DeepLaunch';
  Result.ActiveIntent := '';  // 由引擎判断
  Result.ContextSummary := '桌面启动器';
end;

function TLaunchAdapter.GetDomainKnowledge(const ATopic: string): string;
begin
  Result := '';  // L1 不需要领域知识
end;

function TLaunchAdapter.GetPresetSlots(const AIntentName: string): TArray<TIntentClarificationSlot>;
var
  LSlot: TIntentClarificationSlot;
begin
  // 定义你的意图需要哪些参数
  if AIntentName = 'launch_app' then
  begin
    LSlot.Init;
    LSlot.Name := 'app_name';
    LSlot.DisplayName := '应用名称';
    LSlot.Required := True;
    LSlot.Question := '你想打开哪个应用？';
    Result := [LSlot];
  end
  else
    Result := nil;
end;
```

### 步骤 3：创建引擎并使用

```pascal
uses
  DeepBase.IntentClarification,
  DeepBase.IntentClarification.Types,
  DeepBase.IntentClarification.Interfaces,
  DeepBase.IntentClarification.Engine,
  DeepBase.IntentClarification.Registration;

procedure TMyApp.InitClarification;
var
  LEngine: IClarificationEngine;
  LHandle: TSessionHandle;
  LResult: TTurnResult;
  LRequest: TClarificationStartRequest;
begin
  // 创建引擎（使用预设模板）
  LEngine := TIntentClarifier.CreateEngineWithPreset('tool-command');

  // 注册领域适配器
  TClarificationRegistration.RegisterDomainAdapter(LEngine, TLaunchAdapter.Create);

  // 发起会话
  LRequest := Default(TClarificationStartRequest);
  LRequest.UserId := 'user-001';
  LRequest.DomainName := 'DeepLaunch';
  LRequest.IntentName := 'launch_app';
  LRequest.InitialInput := '打开那个';

  LHandle := LEngine.StartSession(LRequest);

  // 提交用户输入，获取澄清结果
  LResult := LEngine.SubmitInput(LHandle, '打开那个');

  // 处理结果
  if LResult.Status = ssActive then
  begin
    // 显示问题和选项给用户
    ShowQuestion(LResult.Question);
    ShowOptions(LResult.Options);  // 1-8 选项
    // 用户选择后再次 SubmitInput
  end
  else if LResult.Status = ssCompleted then
  begin
    // 意图已明确，执行
    ExecuteIntent(LResult);
  end;
end;
```

## 处理用户响应

```pascal
// 用户选了选项 2
LResult := LEngine.SubmitInput(LHandle, '2');

// 用户输入自由文本
LResult := LEngine.SubmitInput(LHandle, '记事本');

// 用户取消（选项 0）
LResult := LEngine.SubmitInput(LHandle, '0');
// → LResult.Status = ssCompleted

// 用户要求重新生成（选项 9）
LResult := LEngine.SubmitInput(LHandle, '9');
// → 系统换个角度重新提问
```

## 与 DeepBase.LLM 模块的关系

| 意图澄清模块 | 使用的 LLM 能力 | 说明 |
|---|---|---|
| L0/L1 | 无 | 纯规则引擎，零 LLM 依赖 |
| L2 | `ILLMClient.Chat(TierFast, ...)` | 问题分析，用快速模型 |
| L3 | `ILLMClient.Chat(TierBalanced, ...)` | 专家指导，需要更好的推理 |
| L4 | `ILLMClient.Chat(TierSmart, ...)` | 圆桌综合，需要最强模型 |
| 预判 | 无（纯规则） | 未来可选接入 LLM |

## Phase 2 推荐接入方式（IoC）

Phase 2 新增了 IoC 容器集成，推荐使用以下方式接入：

```pascal
uses
  DeepBase.IoC,
  DeepBase.IntentClarification.IoC,
  DeepBase.IntentClarification.Interfaces,
  DeepBase.IntentClarification.LLMResilience,
  DeepBase.IntentClarification.FeatureConfig;

procedure TMyApp.InitClarification;
var
  LContainer: TIoCContainer;
  LEngine: IClarificationEngine;
begin
  LContainer := TIoCContainer.Create;  // 或使用全局容器

  // 一行注册所有 IC 组件
  TICIoCRegistration.RegisterAll(LContainer);

  // 从容器创建引擎（自动注入 L0/L1 Provider）
  LEngine := TICIoCRegistration.CreateEngineFromContainer(LContainer);

  // 注册你的领域适配器
  LEngine.SetDomainAdapter(TMyDomainAdapter.Create);

  // 注册带弹性保护的 LLM（推荐）
  var LLM := TResilientLLMWrapper.Create(TLLMService.GetClient);
  LEngine.SetLLM(LLM);
end;
```

## 弹性保护（LLM Resilience）

L2-L4 的 LLM 调用建议用 `TResilientLLMWrapper` 包装：

```pascal
uses DeepBase.IntentClarification.LLMResilience;

var
  LConfig: TLLMResilienceConfig;
begin
  LConfig := TLLMResilienceConfig.Default;
  // 默认: 超时 10s, 重试 2 次, 熔断阈值 3 次连续失败, 冷却 30s
  LConfig.TimeoutMs := 15000;  // 可覆盖

  var ResilientLLM := TResilientLLMWrapper.Create(RawLLMClient, LConfig);
  LEngine.SetLLM(ResilientLLM);
end;
```

## 特性开关（Feature Flags）

通过 `TICFeatureConfig` 控制高级功能：

```pascal
uses DeepBase.IntentClarification.FeatureConfig;

var
  LConfig: TICFeatureConfig;
begin
  LConfig := TICFeatureConfig.Create;
  LConfig.EnableL4 := False;  // 禁用多专家圆桌
  LConfig.EnableAnticipation := False;  // 禁用预判
  // Engine 会自动尊重这些开关
end;
```

## 已知限制

1. L4 专家调用是串行的（未来改为并行）
2. LLM 调用未使用 ChatWithHistory（多轮上下文丢失，下一版修复）
3. IoC 注册中 L2-L4 Provider 需要手动注册（因为依赖 ILLMClient）
4. FeatureConfig.Reload() 目前是 stub，需要接入 DeepBase.Config 的变更通知
