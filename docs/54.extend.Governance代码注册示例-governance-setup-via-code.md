# Governance 代码注册示例 · Governance Setup via Code

> **配置铁律**：不要创建 JSON/INI/YAML 配置文件。Governance 的 gates/actions/purposes 全部通过代码在 `RegisterGovernance` 回调里注册。
>
> 参考实现：`02Business/DeepClip/src/App/DeepClip.Bootstrap.pas`

---

## 1. 最小骨架

```delphi
program MyApp;

uses
  Vcl.Forms,
  DeepBase.Manager,
  DeepBase.Persistence.Manager.FireDAC,
  DeepBase.Governance.Types,
  DeepBase.Governance.Model,
  DeepBase.Governance.KeyResolver,
  DeepBase.Governance.DueChecker,
  DeepBase.Governance.ActionGrid,
  DeepBase.Governance.GateResolver,
  DeepBase.Governance.Purpose,
  DeepBase.Governance.Runtime,
  DeepBase.Governance.Lifecycle,
  DeepBase.Governance.Registration;

procedure SetupMyAppGovernance(
  AKey: TKeyResolver;
  ADue: TDueChecker;
  AGrid: TActionGrid;
  AGateRes: TGateResolver;
  APurposes: TPurposeSet;
  ARuntime: TOCGSRuntime);
var
  G: TAccessGate;
  A: TAction;
begin
  // ---- Purposes（顶层业务域）----
  APurposes.Register(TPurpose.Create(
    'app.manage', 'Data Management', 'User data lifecycle', ''));

  // ---- Gates（门禁）----
  G := TAccessGate.Create(
    'app.delete_gate',     // key
    'Delete Gate',          // display name
    gtAction,               // gtAction / gtEntry / gtTransition
    '',                     // parent key
    'app_main');            // field key (UI 场域)
  G.AddActionKey('app.delete');
  G.AddCondition(TGateCondition.Create(
    gckState,               // gckState / gckPermission / gckEvidence / ...
    '{"!=":[{"var":"record_id"},""]}',   // JsonLogic 表达式
    'Record must be selected',            // 说明
    'Please select a record to delete')); // 用户看到的阻止消息
  AKey.RegisterGate(G);

  // ---- Actions ----
  A := TAction.Create(
    'app.delete',           // key
    'Delete Record',         // display name
    rlL3,                    // rlL0 / rlL1 / rlL2 / rlL3 (风险等级)
    'app.delete_gate');      // 关联门禁 key
  AKey.RegisterAction(A);
end;

begin
  Application.Initialize;
  DeepBase.InitializeOrRaise;
  RegisterGovernance(gmObserve, SetupMyAppGovernance);
  try
    Application.CreateForm(TFormMain, FormMain);
    Application.Run;
  finally
    ShutdownGovernance;
    DeepBase.Finalize;
  end;
end.
```

## 3. 模式选择

| 模式 | 行为 | 适用阶段 |
|------|------|----------|
| `gmObserve` | 记录 Evidence，不阻止 | 首次接入、数据收集、阶段 A |
| `gmEnforce` | 阻止被拒绝的 Action | 稳定后、生产 |
| `gmOff`    | 完全跳过 Governance | 开发调试、紧急回退 |

## 4. 使用 EnterGate（业务代码里检查门禁）

```delphi
uses
  System.JSON,
  DeepBase.Governance.Lifecycle;

procedure TFormMain.btnDeleteClick(Sender: TObject);
var
  Ctx: TJSONObject;
  R: TActionResult;
begin
  Ctx := TJSONObject.Create;
  try
    Ctx.AddPair('user_id', CurrentUser.Id);
    Ctx.AddPair('record_id', FSelectedRecordId);
    Ctx.AddPair('user', TJSONObject.Create.AddPair('role', CurrentUser.Role));

    R := GovernanceLifecycle.Runtime.EnterGate(
      'app.delete_gate', Ctx, rmCommit);
    if R.Status = arsSuccess then
      DoActualDelete
    else
      ShowMessage('Blocked: ' + R.Message);
  finally
    Ctx.Free;
  end;
end;
```

## 5. 常见错误

| 错误 | 原因 | 修正 |
|------|------|------|
| 在项目里创建了 `config/governance/*.json` | 违反配置铁律 | 删除，改为代码注册 |
| `TAction.Create(key, name, risk, gate)` 编译报错 | 以为 KeyResolver 直接接受原语 | 必须先构造 TAction 对象再 RegisterAction |
| `TPurpose.Create('k','n','')` 参数不够 | 第 4 个参数 AParentKey 必填 | 传空串 `''` 即可（顶层没有父） |
| L2+ Action 运行时报 DueRef 缺失 | 风险等级 L2/L3 必须关联 DuePolicy | 注册 DuePolicy 到 DueChecker 或降级到 L1 |
| EnterGate 返回"Gate not found" | Gate 未注册或 key 拼错 | 在 Setup 回调里确认 RegisterGate 被调用 |
