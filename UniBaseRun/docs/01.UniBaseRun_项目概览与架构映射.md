# 01. UniBaseRun 项目概览与架构映射

> 本文档说明 UniBaseRun 示例项目的定位、整体结构，以及它如何落实 UniBase 核心文档中的要求。

## 1. UniBaseRun 的定位

UniBaseRun 是一个基于 **FMX**、Delphi 12.2+ 的 **标准 UniBase 应用示例 + 脚手架项目**，用于：

1. 演示如何在实际项目中正确集成 UniBase（root.txt、config.db、双数据库策略、View/Ctrl/uDM 分层等）。
2. 提供“一键复制即可用”的项目骨架：
   - 用户复制整个 UniBaseRun 目录到新位置；
   - 运行 `scripts\init-project.bat` 完成重命名和初始化；
   - 直接在此基础上开发业务功能。
3. 为未来 Studio 的“新建项目”功能提供同源模板：
   - Studio 内部创建新项目时，也会基于 UniBaseRun 的结构和脚本逻辑生成工程。

**重要：** UniBaseRun 作为模板工程，目标是“**小而全、即开即用**”：
- 基础设施：日志查看 + 配置编辑；
- 业务骨架：用户登录 + 典型 CRUD 表单（示例占位）；
- 数据库示例：PostgreSQL 业务库连接（从 config.db 读取连接参数）。

## 2. 技术栈

- **UI 框架**：FMX（跨平台，未来主力）
- **数据库**：FireDAC + SQLite（config.db）+ PostgreSQL（业务库）
- **架构**：View/Ctrl/uDM 分层 + UniBase 基础设施

## 3. 与 UniBase 核心文档的关系

UniBaseRun 是对以下核心文档的具体落地（文档位于 `UniBase/docs/`）：

1. **`01_UniBase规范.md`**（权威规范）
   - 落地点：
     - 使用 **root.txt 作为锚点文件**，内容为项目根目录绝对路径。
     - 运行时所有配置、日志、i18n 文本、窗体状态等统一存入 **config.db**。
     - 严格区分 **配置库（config.db）** 与 **业务库（PostgreSQL）** 的职责。

2. **`02_开发指南.md`**（架构与最佳实践）
   - 落地点：
     - **业务代码零目录结构**：所有 `.pas/.fmx` 业务单元平铺在项目根目录。
     - 严格的分层约束：View → Controller → Model/uDM 单向依赖。
     - 使用 IView 接口解耦、TTask + TThread.Queue 异步模式。
     - 通过 TFrame 组件化 UI，将复杂窗口拆分为可复用的子组件。

3. **`03_数据库指南.md`**（数据库操作）
   - 落地点：
     - uDM 中演示 PostgreSQL 连接配置（从 config.db 读取连接参数）。
     - 使用 DoQry 参数化查询，禁止裸 SQL 拼接。

4. **`06_AI辅助开发.md`**（AI 开发约束）
   - 落地点：
     - 代码结构符合 AI 复用检查点要求。
     - 所有用户文本使用 `T()` 国际化。

## 4. 项目整体结构概览

UniBaseRun（FMX）的物理目录结构：

```text
UniBaseRun/                     <-- 示例项目根目录（与 root.txt 内容一致）
  UniBaseRun.dpr               <-- 主程序入口（FMX）
  UniBaseRun.dproj             <-- Delphi 工程文件
  ViewMain.pas/.fmx            <-- 主窗体（五面板 + 菜单 + 状态栏）
  ViewLogin.pas/.fmx           <-- 登录窗体（示例骨架）
  FrameCRUD.pas/.fmx           <-- 典型 CRUD 表单 Frame（示例骨架）
  CtrlMain.pas                 <-- 主控制器（日志/配置/导航逻辑）
  CtrlLogin.pas                <-- 登录控制器（示例骨架）
  ModelUser.pas                <-- 用户实体（示例骨架）
  uDM.pas                      <-- 业务数据库数据模块（PostgreSQL 连接示例）
  root.txt                     <-- 锚点文件，仅一行：项目根目录绝对路径
  config.db                    <-- UniBase 配置库（运行时生成/初始化）
  assets/                      <-- 资源目录（图标、图片等）
  logs/                        <-- 文本日志目录（由 UniBase 写入）

  tests/                       <-- 测试相关（DUnitX）
    UniBaseRun.Tests.dpr       <-- 命令行测试工程
    UniBaseRun.GuiTests.dpr    <-- FMX GUI 测试工程
    Tests.*.pas                <-- 测试单元

  scripts/                     <-- 构建与初始化脚本（.bat）
    init-project.bat           <-- 新项目初始化（重命名 + root.txt 重写）
    build.bat                  <-- 编译主程序
    test.bat                   <-- 运行命令行测试
    test-gui.bat               <-- 运行 GUI 测试
    run.bat                    <-- 启动主程序

  docs/                        <-- 本项目说明文档
```

其中：

- **业务代码文件**：平铺在根目录（遵守零目录规范）。
- **骨架文件**（ViewLogin/FrameCRUD/CtrlLogin/ModelUser）：提供典型业务结构占位，用户可直接修改或删除。
- **tests/scripts/docs**：工具性子目录，不放正式业务逻辑。
- **config.db、assets、logs**：由 UniBase 约定和管理。

## 5. 运行时生命周期与 UniBase 集成

UniBaseRun 的运行时主流程（简化）：

1. EXE 所在目录或约定位置找到 `root.txt`，读取其内容，确定项目根目录 `ProjectRoot`。
2. 调用 `UniBase.InitializeEx`，传入 `ProjectRoot`，完成：
   - 打开或创建 `ProjectRoot\config.db`；
   - 初始化日志系统、i18n 系统、窗体状态管理等基础设施；
   - 准备好 `UniBase.GetConfig`、`LogInfo` 等全局入口。
3. 创建主窗体 `TViewMain`，并为其注入控制器接口 `ICtrlMain`。
4. 主窗体展示“日志查看 + 配置编辑”界面，所有配置和日志访问都通过 UniBase 完成。
5. 应用退出时调用 `UniBase.Finalize` 做善后清理。

**注意：** UniBaseRun 默认不集成 madExcept。异常处理采用 Delphi/UniBase 提供的基础机制，未来如需集成 madExcept，可在统一异常处理单元中集中扩展。

## 6. 功能范围

UniBaseRun 包含以下功能模块：

### 6.1 基础设施

1. **日志查看**
   - 从 `logs/` 目录列出可用日志文件；
   - 在中部面板查看日志内容，支持过滤/搜索；
   - 演示从 config.db 读取日志相关设置。

2. **配置编辑**
   - 从 config.db 加载配置项；
   - 左侧树按分组展示配置键；
   - 中央面板提供可视化编辑控件。

### 6.2 业务骨架（示例占位）

3. **用户登录**
   - `ViewLogin.pas`：登录窗体骨架；
   - `CtrlLogin.pas`：登录验证逻辑骨架（可替换为实际业务）。

4. **典型 CRUD 表单**
   - `FrameCRUD.pas`：列表 + 编辑的通用 Frame 骨架；
   - 演示 uDM 数据访问、Controller 业务逻辑、View 展示的分层协作。

5. **PostgreSQL 业务库连接**
   - `uDM.pas`：从 config.db 读取连接参数，创建 TFDConnection；
   - 演示 DoQry 参数化查询用法。

通过这些功能，开发者可以直观理解：
- root.txt 如何作为项目根目录锚点；
- config.db 如何被 UniBase 管理并被应用读取/修改；
- View/Ctrl/uDM 分层协作的完整流程。

## 7. UniBaseRun 的使用场景

### 7.1 作为教学与演示工程

- 新成员加入项目时，可通过 UniBaseRun 快速熟悉：
  - UniBase 的基本概念与初始化方式；
  - 零目录结构与命名规范；
  - View/Ctrl/uDM 分层协作；
  - 日志、配置、数据库、测试的基本用法。

### 7.2 作为新项目模板（一键迁移）

启动新项目时，推荐流程：

1. 复制 UniBaseRun 整个目录到新位置（例如 `D:\Work\MyApp`）；
2. 运行 `scripts\init-project.bat`，根据提示输入新项目名；
3. 脚本自动完成：
   - 重命名 `.dpr/.dproj` 工程文件；
   - 更新代码中的项目名占位符；
   - 重写 `root.txt` 为新路径；
4. 打开新的 `.dproj` 文件开始开发；
5. 可保留或删除骨架文件（ViewLogin/FrameCRUD 等）。

### 7.3 作为 Studio“新建项目”模板来源

- 未来 Studio 中“新建 UniBase 项目”功能可以：
  - 直接拷贝 UniBaseRun 作为模板；
  - 使用与 `init-project.bat` 相同的逻辑进行变量替换；
  - 确保命令行和 IDE 操作为同一套规范。
