## 五、契约陈述（判据 6 · 供主控落 Q3 breaking change 登记）

`TBindingManager.Bind(Source: TObject; const SourceProp: string; Target: TObject; const TargetProp: string; Mode: TBindingMode; Converter: IValueConverter)`

| 入参组合 | 结果 | 副作用 |
|---|---|---|
| source 为 `TObservableObject` 后代 **且** target 为 `TComponent` 后代 | 建立绑定；登记 source 析构通知 + target 的 `FreeNotification` 代理 | 任一侧析构 ⇒ 该侧全部条目自动摘除（含 `bmOneTime`），无需再手工 `Unbind` |
| source 不是 `TObservableObject` 后代（含 `nil`） | 抛 `DeepBase.DataBinding.EBindingUnsupportedObject`（祖先 `DeepBase.Exceptions.EInvalidOperationException`），消息含实际类名（nil ⇒ `nil`）与属性名 | 无：先判后建，`BindingCount` 不变 |
| target 不是 `TComponent` 后代（含 `nil`） | 抛同一异常类，形态同上 | 无 |

破坏性说明：形参**声明**仍是 `TObject`（编译期不报错），语义收窄为「可追踪对象」⇒ 原来能跑通的裸对象组合现在运行期抛类型化异常；`Unbind`/`UnbindObject`/`UnbindAll` 语义不变，新增行为是它们与自动摘除共用同一 `RemoveEntry` 出口（成对退订）。仓内 consumer 影响面为零（§二 A 末段）。外部迁移路径：把不可登记的 target 换成 `TComponent` 后代，或改由调用方自持生命周期并显式 `Unbind`。
