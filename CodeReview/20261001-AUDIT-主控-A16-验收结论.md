## 三、Q3 breaking change 登记（判据 6 的落笔，归主控）

已写入 `./CHANGELOG.md` 的 `## [Unreleased]` 节，置于既有说明段之后、`## [1.1.0]` 之前：

1. **`### ⚠ BREAKING CHANGES（消费者必读）`** 一条：`TBindingManager.Bind` 入参契约收窄为「可追踪对象」——形参声明未变（`Source: TObject; Target: TObject`，编译期不报错）但语义收窄，source 必须是 `TObservableObject` 后代、target 必须是 `TComponent` 后代，任一侧不满足（含 `nil`）即抛 `DeepBase.DataBinding.EBindingUnsupportedObject`（祖先链 `DeepBase.Exceptions.EInvalidOperationException` → `EOperationException` → `EDeepBaseException`）；记载「原来能跑通的裸对象组合现在由『成功但埋 UAF』变为『明确报错』」、报错路径零副作用（先判后建，`BindingCount` 不变）、新增的任一侧析构自动摘除行为、`Unbind`/`UnbindObject`/`UnbindAll` 语义不变。
2. **仓内 consumer 影响面为零**（主控亲读，非甲自报）：`VCL/DeepBase.VCL.MVVMControls.pas:457/580` source 为 `TViewModelBase = class(TObservableObject, IValidatable)`〔`Core/DeepBase.MVVM.pas:268`〕、target 为 `TControl`；`Examples/DataBindingDemo/MainForm.pas:276-283` source 为 `TPersonModel = class(TObservableObject)`、target 为 `TEdit`/`TCheckBox`；`VCL/DeepBase.VCL.BindableControls.pas:12` 是单元头 usage 注释、非可执行调用。
3. **外部迁移路径**：把不可登记的 target 换成 `TComponent` 后代，或改由调用方自持生命周期并显式 `Unbind`。
4. **契约覆盖登记**：`DeepBase.DataBinding` **不在** `contract/consumer-contract.json` 的 units 清单内，故不在 `contract-gate` 的 stable 签名基线覆盖范围内（本变更是语义收窄、签名未动，基线无需重建）。是否把它显式登记进消费者契约属另一项治理决定，已登记为待办。
5. **`### Added`** 一条：`EBindingUnsupportedObject` 类型 + 两夹具并网（`248283b`）。

文件编码纪律：保持既有 `md_crlf_exceptions` 约定（CRLF + UTF-8 BOM），未新增 U+FFFD（存量 4 个在 encoding-gate 基线豁免内）。

「与 A16 两笔无关」这半结论成立（主套件 `Tests/DeepBaseTests.dpr:381` 生产 uses 已在册，全量跑 `Passed 4866 / Errored 1` 即证）；机制表述须订正。**更该修的是面孔 (ii)**——忽略返回值 = 假绿，比 16 例红更危险。已派 `WO-20261001-MC-主控-LICFIX`。
