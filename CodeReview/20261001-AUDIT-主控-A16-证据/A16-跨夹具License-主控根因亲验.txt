结论（主控裁定）
==========================================================================
真根因 = 测试夹具的【隐式传递依赖未声明】，有两个面孔：
  (i)  连接工厂在（LicensingTimeSource 带入）而 License 存储工厂不在 => 16 例运行期抛错；
  (ii) 连接工厂也不在 => InitializeWithDB 失败但返回值被忽略、ConfigDB 留 nil，
        TDeepBaseLicense.Create(nil) 因 Assigned(AConnection)=False 不抛 => 【16 例假绿】
        （亲验 A/B：单跑与两件组合都「全绿」，但那些用例实际未触达任何存储）。
=> 不是「全局注册顺序」缺陷；「与 A16 两笔无关」这半结论成立，但机制表述须订正。
=> 影响面：只在一次性 harness / 子集 dpr 上；主套件面不受影响（dpr:381 已在册）。
=> 更该修的是面孔 (ii)：忽略 InitializeWithDB 返回值 = 假绿，比 16 例红更危险。
=> 已据此另行派单（见 WO-20261001-MC-主控-LICFIX），A16 收尾本单不扩面。
