判据 6 —— removed 第 1 条是幻象：抽取器分块缺陷（check_contract.js:146-155）
--------------------------------------------------------------------------
signatures() 的实现：
    const iface = extractInterface(text);          // stripComments 后取 interface..implementation
    for (let chunk of iface.split(';')) {          // 按分号切块
      const norm = chunk.replace(/\s+/g,' ').trim();
      if (norm) set.add(norm);                     // 每块整体作为一条签名
    }
stripComments() 把 {…} (*…*) //… 全部替换为单个空格（:135-140）。

=> 「type」关键字只是某一分块的前缀词，谁跟在它后面（同块内）就归谁。
   eb93e23 在 type 段首插入带 /// 文档注释的 EDeepBaseLicensingTimeUntrusted 后：
       type [注释→空格] EDeepBaseLicensingTimeUntrusted = class(EDeepBaseCommerceError);
       [注释→空格] TLicensingTier = (ltFree, ltPro);
   按 ';' 分块时，「type」被绑进前一片；TLicensingTier 那片不再含 type 前缀。
=> 声文本体一字未改（TLicensingTier = (ltFree, ltPro) 仍在，字号内容同一），
   仅签名串形态由 "type TLicensingTier = (ltFree, ltPro)" 变为 "TLicensingTier = (ltFree, ltPro)"，
   同一现实被同时计为 1 条 removal + 1 条 addition。
=> 属门禁假阳性；与「公开声明消失或改写」无关。
