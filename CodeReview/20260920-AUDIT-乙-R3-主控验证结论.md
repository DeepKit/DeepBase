1. **`git commit` 必须带 `--only` 或显式 pathspec**，禁止裸 `git commit`（无参数 = 提交 index 中**他人已 stage 的全部内容**）。
2. 提交**前**必跑 `git diff --cached --name-only`，逐项确认无他方文件。

### H16 · 共享 index 并发禁令

多 AI 同时操作同一工作树/index 时，**禁止**在他人有暂存内容（`git diff --cached` 非空）时执行写操作。发现他方暂存 → 停止，书面报告，由主控排序。
