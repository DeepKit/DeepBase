### 2.4 根因机理

源码 L585：

```pascal
// Off-screen: isolate paint budget from DWM Present / remote-display pacing.
Form.SetBounds(-32000, -32000, Form.Width, Form.Height);
```

随后两段重绘循环：

| 段 | 位置 | 迭代数 | 每次动作 |
| :--- | :--- | ---: | :--- |
| warm-up | L591-598 | 100 | `SetBounds`（尺寸在 500-700 × 400-550 间跳变）+ `Form.Update` |
| 测量 | L600-613 | 500 步 × **3 次** Update | 同上 + `TStopwatch` 采样 |

合计 **1600 次** `SetBounds`+`Update`。`Form.Update` 语义为「处理完 Paint 队列才返回」= 同步全失效重绘。

关键放大因素：

- `THbFacetWaterfall.Align := alClient`，随客户区**满幅**重排；
- warm-up 尺寸序列 `W := 500 + (I mod 200)`、`H := 400 + ((I*3) mod 150)` **每个 I 都不同**
  ⇒ 每次 Update 触发**全新布局 + 全新度量 + 全新绘制**，零缓存复用；
- 离屏 `-32000` 使 GDI/D2D **无法命中任何合成器快速路径**，走软件回退。

在软件合成环境下单次全幅重绘从毫秒级劣化到数十至数百毫秒级，1600 次累加 ⇒ **分钟量级**。
与 Gate1（25.6 s）、Gate2（24.3 s）同属 GUI 度量、同受虚显拖累，量级互相印证。
