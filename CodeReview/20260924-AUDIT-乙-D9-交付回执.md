1. **判据必须用「过 clean filter 后的入库字节」，不能用原始磁盘字节**。`git hash-object --no-filters` 读到的含 CRLF 原始 blob

2. **文件清单必须取自 `git status --porcelain`，不能取自 `git diff HEAD`**。`git diff` 自己也应用 clean filter，
   假脏件根本不会出现在 diff 列表里；用 diff 当清单 ⇒ 结构性恒得「假脏 = 0」。判据 3 的口径本身就是 status 的已跟踪条目。
