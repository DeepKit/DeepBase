## 一、待验证 3 项（V1–V3）专项核验结果

### 1. V1：`Cards.pas` `THbListRow.MouseDown` 坐标重算验证（PASS ✅）
- **核验位置**：`VCL\DeepBase.VCL.HB.Cards.pas:700-721`
- **代码实现**：
```delphi
procedure THbListRow.MouseDown(Button: TMouseButton; Shift: TShiftState; X, Y: Integer);
var
  BtnAreaStart: Single;
begin
  inherited;
  if (Button = mbLeft) and Enabled then
  begin
    BtnAreaStart := Width - ScalePixels(190);
    if (X >= BtnAreaStart) and (X <= Width - ScalePixels(10)) and
       (Y >= (Height - ScalePixels(26)) div 2) and (Y <= (Height + ScalePixels(26)) div 2) then
    begin
      if X < (BtnAreaStart + ScalePixels(90)) then
        FActionPressPart := 1
      else
        FActionPressPart := 2;
    end
    else
      FActionPressPart := 0;
    FActionHoverPart := FActionPressPart;
    Invalidate;
  end;
end;
```
- **结论**：`MouseDown` 中直接基于 X/Y 坐标重新计算 `FActionPressPart` 与 `FActionHoverPart`，彻底消除了使用过期 hover 状态导致的误点击问题。

### 3. V3：`PageControl.pas` `MouseMove` 局部 Tab 区域无效化验证（PASS ✅）
- **核验位置**：`VCL\DeepBase.VCL.HB.PageControl.pas:236-258`
- **代码实现**：
```delphi
procedure THbPageControl.MouseMove(Shift: TShiftState; X, Y: Integer);
var
  NewHover: Integer;
  R: TRect;
begin
  inherited;
  NewHover := GetTabAt(X, Y);
  if FHoverIndex <> NewHover then
  begin
    if (FHoverIndex >= 0) and (FHoverIndex < FTabs.Count) then
    begin
      R := GetTabRect(FHoverIndex);
      InvalidateRect(Handle, @R, False);
    end;
    FHoverIndex := NewHover;
    if (FHoverIndex >= 0) and (FHoverIndex < FTabs.Count) then
    begin
      R := GetTabRect(FHoverIndex);
      InvalidateRect(Handle, @R, False);
    end;
  end;
end;
```
- **结论**：悬停变化时仅对旧 Tab 和新 Tab 的矩形区域调用 `InvalidateRect(Handle, @R, False)`，彻底消除全控件重绘闪烁。
