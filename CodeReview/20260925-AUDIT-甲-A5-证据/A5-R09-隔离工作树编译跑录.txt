-- 2. 唯一变量核对：内容级（忽略 CR）比对 --------------------------------------
  注：主树多数 .pas 工作副本是 LF、--detach 工作树 checkout 出 CRLF（.gitattributes
  *.pas text eol=crlf 只管 checkout 方向，索引内一律 LF，两侧 git 状态都干净）。
  因此字节级 diff 会对几乎每个文件报 differ，属行尾噪声；比对必须用 --strip-trailing-cr。

  diff -rq --strip-trailing-cr .tmp/a5r09/wt-prefix/Core Core   | grep -v '^Only in'
    Files .../Core/DeepBase.KeyManager.pas and Core/DeepBase.KeyManager.pas differ
    Files .../Core/DeepBase.License.pas     and Core/DeepBase.License.pas     differ
  diff -rq --strip-trailing-cr .tmp/a5r09/wt-prefix/Tests Tests  | grep -v '^Only in'
    （无输出：既存测试单元内容逐行相同）

  仅主树存在（即本单新增，隔离侧经 staging 供给）：
    Only in Core:  DeepBase.TimeSource.pas
    Only in Tests: Test.DeepBase.TimeSource.pas
  其余 "Only in" 行全是主树的构建产物/日志/临时件（*.exe *.res *.rsm *.drc Win64/
  TestResults/ Logs/ evidence/ *.log sqlite3.dll test_output.xml，以及既存
  Core/DeepBase.Schema.pas.bak），均被 .gitignore 排除、不参与本次编译面。

  ⇒ 结论：隔离侧与主树在「参与本次 runner 编译的源码」上的差集只有
    Core/DeepBase.License.pas（+29/-5）与 Core/DeepBase.KeyManager.pas（+11/-7）。
    DeepBaseServices.dpk 也 differ（+1 行单元注册），但探针 runner 走 -U 源根直编、
    不经包，故不影响本判据；该 +1 行的正确性由第 5 节的包清单核对负责。
