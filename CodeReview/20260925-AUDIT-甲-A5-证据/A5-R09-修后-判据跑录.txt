-- 1. 修法 ----------------------------------------------------------------------
  分层约束（工单 §一 R09 + Tests/Architecture/Test.Arch.PackageBoundaries.pas）：
  DeepBaseCore 不得反向依赖 Features，故时钟源落在 Core 自己的新单元
  Core/DeepBase.TimeSource.pas（包清单 DeepBaseServices.dpk，与 DeepBase.License /
  DeepBase.KeyManager 同包），uses 只有 System.SysUtils / System.DateUtils /
  System.SyncObjs —— 零 Features 引用、零新增第三方依赖。

  为什么新建单元而不是塞进 Core/DeepBase.DateTime.pas：后者是纯格式化/算术无状态工具，
  「带状态的安全水位」属另一职责，合入即职责不清；且它自己有 12 处 System.SysUtils.Now
  读数点（相对时间格式化，属相邻超范围，见 §8 b）。新建单元是单一真相源的正解：
  Core 内授权相关的时间读数只有一个入口。

  四步（对工单 §一 R09 修法四步逐条落地）：
   ①可注入时间源：TDeepBaseNowFunc = reference to function: TDateTime;
     TDeepBaseTimeSource.Now 内部 FNowFunc 非空则取注入读数，否则取 System.SysUtils.Now
     （必须全限定：本单元方法名同为 Now，裸调用自我递归）。形态参考 Core/DeepBase.IoC.pas
     的注册/替换风格，但用进程共享实例 + initialization 期建实例，避免 R05 那类
     「双路径单例」再立一轨。
   ②last-seen 单调水位 + 持久化字段：实例持 FLastSeen；许可证载荷新增 'l'
     （签发时刻水位的 unix 秒，紧随 'i'）。读回时走 SeedWatermark —— 该过程只升不降，
     所以删除许可文件、换成更早的真副本、或篡改载荷（改 'l' 必然过不了 HMAC）都退不回过去。
   ③EffectiveNow = Max(注入读数, 水位)：Now 内部在锁内比较，读数低于水位即
     Inc(FRollbackCount) 并累计 MaxRollbackSeconds（SecondsBetween），返回值仍取水位 ——
     回拨只登记、不续命。
   ④IsExpired / DaysRemaining / DaysUntilExpiry / 三处 FCreatedAt / 一处 FExpiresAt /
     载荷 'i' 全部改走 TDeepBaseTimeSource.Shared.Now，两个单元的裸 Now 归零。

  执行顺序上的一处关键（注释已写进代码）：ValidateLicense 里 SeedWatermark 必须在验签之后、
  判过期之前。放在验签后 ⇒ 伪造的更早水位走不到播种点；放在判过期前 ⇒ 本次判定就用得上
  刚读到的水位，否则进程重启后回拨防护会失效一天。

-- 4. 载荷格式变更（'l' 字段）---------------------------------------------------
  许可证载荷 = Base64URL(JSON) + '.' + HMAC-SHA256（32 hex）。
  键序：修前 v,t,e,i,to,d,u,f  →  修后 v,t,e,i,l,to,d,u,f（'l' 紧随 'i'）。
  兼容性（生产级项目须评估，老板口径「质量优先于兼容，允许 breaking change」）：
    修后读修前载荷：'l' 取默认 0 ⇒ 无水位可播种，判定继续走进程水位，历史许可照常可用。
                    已由 LegacyLicense_WithoutLastSeenField_StillJudgedByWatermark 用
                    真实修前产物（LEGACY_KEY_WITHOUT_LAST_SEEN 常量，e=2027-08-15）覆盖。
    修前读修后载荷：JSON 多余键不校验、且 HMAC 覆盖整个 JSON ⇒ 签名照常通过，字段被忽略。
                    不存在「新载荷在旧版本被判非法」的降级风险。
    既有快照/摘要类消费面：TestResults/** 属禁动区、未触碰；全仓无按载荷字节比对的消费方
                    （grep 见 §6 消费面取证）。
