四、登记项（本单不顺手改，交主控判定）

R1  方言残余通道：本修把「值不再改变 SQL 语义」钉死在单引号状态机上，
    QuotedStr + 单引号双写在 SQL Server / PostgreSQL(standard_conforming_strings=on) /
    Oracle / SQLite 上是无损且正确的；MySQL 默认模式还把反斜杠当转义符，只双写不够。
    该单元是 ADO（SQL Server）面，仓内没有可复用的参数化 API 供 legacy 轨调用，
    真正的收口是让这三处拼接改走服务端/驱动参数绑定，而不是在本单元加方言开关
    （加开关=引入第二套真源且需要 TDatabaseType 贯穿，属过度兜底）。
    ⇒ 登记为结构性议题，不在 B2-13 范围内动。
R2  置空约定冲突：空串与字面量 'NULL' 都写不出「字符串 NULL」本身（legacy 既有契约，
    工单未授权改语义，原样保留并已有用例钉住）。
R3  中文括号归一：旧实现只在「加引号」分支做归一，纯数值字符集分支不可能出现中文括号
    （中文括号不属于 0-9 . + -），因此改成全量归一对旧行为无新增变形面。
R4  带类型入口无外部回归：HandleParamValue(:237)、ValidateSQL(:654)、ValidateSQLQuotes(:52)
    都在 implementation 段（implementation 起于 :43），interface 不导出 ⇒ 新测试单元够不到，

    要建回归网必须扩公开面或建 friend 单元，属结构决策 ⇒ 交主控。
