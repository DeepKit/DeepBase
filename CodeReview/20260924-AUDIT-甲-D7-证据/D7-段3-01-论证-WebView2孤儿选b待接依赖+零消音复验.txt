  BUG-012 DevTools 回调、FEAT-R3-002/E-002 异步任务生命周期守卫等已投入的缺陷修复），删除 = 销毁这些
  与调用方契约绑定的实现，且与 docs/52.extend.BrowserAutomation接入指南.md 声明的引擎路线和仓内
  ThirdParty/ 既有惯例（外部依赖走 ThirdParty，缺口显式声明）冲突。
- git 史证明它是被持续维护的形态而非弃件：7177771 fix(browser): move USE_WEBVIEW2 guard into interface
  so unit compiles when feature disabled —— 守卫位置本身就是为了让「依赖未接入时仓库仍可编译」而设计。
- 工单 (a) 的前置判断是「死件」；实测前提为假（见事实链 1/2/4：它以空桩形态参与编译面语义，不是坏代码）。
