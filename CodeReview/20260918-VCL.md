## 二、按单元分组的发现

### 2.1 `DeepBase.VCL.MVVMControls.pas` — 🔴 全局命令绑定悬挂

**维度②内存/生命周期 + ③线程**

```pascal
var GCommandBindings: TList;  // 单元级全局
procedure TMVVMFormBase.BindCommand(Button: TButton; Command: ICommand; Parameter: TObject);
begin
  Binding := TCommandButtonBinding.Create(Button, Command, Parameter);
  RegisterCommandBinding(Binding);   // 加入全局列表，仅 finalization 释放
end;
```

- `TCommandButtonBinding` 持裸对象引用 `FButton: TButton`，并订阅 `Command.CanExecuteChanged`。宿主表单销毁后，全局列表仍持有该 binding → `FButton` 成为悬垂指针，且仍订阅在命令上。命令任一状态变化触发回调执行 `FButton.Enabled := …` → 访问已释放对象 → **AV**。
- `UnregisterCommandBinding` 已定义但全模块**从未被调用**（Glob/Grep 确认无调用点）。
- `finalization` 阶段释放全局列表时，对每个 binding 执行 `FButton.OnClick := FOriginalOnClick` 还原 → 此时 `FButton` 早已释放 → **进程退出时 AV**。

**触发条件**：任一 `TMVVMFormBase` 子类调用过 `BindCommand` 并关闭表单；命令在表单销毁后触发 `CanExecuteChanged`，或程序正常退出。
**建议修复**：binding 用 `FButton.FreeNotification`（重写 `Notification(opRemove)` 自动解绑并退订 `CanExecuteChanged`）；或在 `TMVVMFormBase.Destroy` 遍历本表单登记项调 `UnregisterCommandBinding`；`finalization` 还原 `OnClick` 前判空/移除。

### 2.2 `DeepBase.VCL.LLMChatFrame.pas` — 🔴 生成中销毁路径死锁 + 释放后使用

**维度②生命周期 + ③线程安全**

```pascal
destructor TLLMChatFrame.Destroy;
begin
  if FIsGenerating then
  begin
    if Assigned(FClient) then FClient.Cancel;
    if Assigned(FCurrentTask) then FCurrentTask.Wait(2000);  // 主线程等待，不泵消息
  end;
  if FOwnsClient and Assigned(FClient) then FreeAndNil(FClient);
  FreeAndNil(FHistory);
  FreeAndNil(FChatItems);
  ...
```

后台任务 `DoSendMessage` 中：`LClient.Chat(...)`（阻塞 HTTP）+ 多处 `TThread.Synchronize(nil, proc)`，proc 捕获 `Self`/`ComponentState`/`FRichEditChat`/`FHistory`。

- 析构在主线程 `FCurrentTask.Wait(2000)` **不泵送 Synchronize 队列**：若后台任务在 `Synchronize` 处等待主线程，而主线程卡在 `Wait` → **最长 2 秒界面冻结/死锁**。
- 超时（>2s）后仍继续 `FreeAndNil(FClient/FHistory)`：后台线程仍在解引用它们 → **释放后使用 AV**；已排队的 `Synchronize` proc 会在已释放 frame 上运行（`Self` 悬垂）。

**触发条件**：AI 回复生成过程中关闭宿主表单，且请求耗时 > 2s（弱网/长回答极常见）。
**建议修复**：不要在 UI 线程 `Wait`；改为设置协作取消标志 + `FIsGenerating` 门，把 `FClient`/历史的所有权交给后台任务，任务完成时经 `TThread.Queue` 回主线程再释放；`Synchronize` proc 内首行判 `ComponentState`/`csDestroying`/代数计数器（generation token）后再触碰控件。

### 2.3 `DeepBase.VCL.HB.VirtualList.pas` — 🔴 RowHeight 除零崩溃

**维度①正确性**

```pascal
property RowHeight: Integer read FRowHeight write FRowHeight default 72;  // 无写方法保护
...
ClickedIdx := (Y - TopOffset + FScrollOffset) div FRowHeight;             // L567 MouseDown
StartIdx := EnsureRange(FScrollOffset div FRowHeight, 0, ...);            // L638 Paint
CurY := TopOffset + 4 - (FScrollOffset mod FRowHeight);                   // L639 Paint
```

`FRowHeight` 可被外部（含 .dfm / 代码）设为 `0`，无 setter 校验。上述 `div`/`mod` 立即 **整数除零 → EDivByZero/崩溃**。

**触发条件**：设计期或运行期把 `RowHeight` 设为 0，随后绘制或点击。
**建议修复**：`write SetRowHeight`，setter 内 `Value := Max(1, Value)`；或在绘制/命中前 `if FRowHeight <= 0 then Exit`。

**关联 🟡（维度①）**：构造函数创建批量栏子按钮后漏设 `Parent`：

```pascal

FTimer := TTimer.Create(Self);          // L168 紧接着建 timer
```
→ "全选/反选"按钮永不显示（批量选择功能不可用）。**修复**：补 `Parent` 赋值。

**🔵**：分组桶/可折叠分组/`SummaryLine2`/`FHeaderHeight` 等为声明但未接线的"死特性"；虚拟模式（`FVirtualItemCount>0`）下搜索过滤静默失效。

### 2.6 `DeepBase.VCL.HB.Controls.pas` — 🟡 WMPaint 吞异常导致永久销毁控件

**维度④异常处理**（2385 行，绘制核心，整体 GDI+/主题监听生命周期规范）

```pascal
procedure THbCustomControl.WMPaint(var Message: TWMPaint);
begin

  try
    inherited; EmitTelemetry; FLife.MarkRendered;
```

**🔵**：`GStringFormatCenter`（init 创建）从未使用（退出前无意义持有）；`THbSkeleton` 宣称"扫光动画"但仅绘制实色矩形，`FAnimOffset` 未参与绘制；骨架 timer 常开 `Invalidate`（即使不可见也重绘）。

### 2.12 `DeepBase.VCL.MRUControls.pas` — 🟡 悬垂指针存入 Tag + 死 API + 🔵 全局单例耦合

**🟡 维度①/②**（L149）：

```pascal
MenuItem.Tag := NativeInt(PChar(Item.ItemKey)); // Store ItemKey
```
`Item` 是 `for Item in MRUItems` 的循环局部变量，`PChar(Item.ItemKey)` 指向即将失效的临时短字符串指针，存入 `Tag`。目前 `GetSelectedItemKey`（L161-165）是**永远返回 `''` 的空壳**，故未立即崩溃，但这是一枚"把野指针存进 Tag"的地雷，一旦有人回填 `Result := PChar(MenuItem.Tag)` 即 AV/数据损坏。
**建议**：`Tag` 只存整型索引；键值用 `TMenuItem` 伴生对象或 `FMRTree`/字典映射，勿存字符串指针。

**🔵 维度⑦**：控件内部直接引用全局单例 `DeepBase.Manager.DeepBase`（`IsInitialized`/`.MRU`），VCL 层硬耦合 Core 全局对象，不可注入、不可测。
