# 共享密钥配置说明

> 如果所有单机工具使用相同的收款二维码，可以使用统一的密钥配置简化管理。

## 统一密钥配置

所有单机工具项目使用以下配置：

```pascal
Config.EncryptionKey := 'UniBase_Shared_Key_2025';
Config.Salt := 'UniBase_Shared_Salt_v1';
Config.KdfIterations := 10000;
Config.EnableHMAC := True;
Config.EncryptionType := etAES256;
```

## 使用流程

### 1. 播种模板数据库

1. 运行 `SeedTool.exe`
2. 创建新数据库：`template.db`
3. 使用上述统一密钥配置
4. 播种 6 张标准图片：
   - `official_gzh` - 公众号二维码
   - `wechat` - 微信收款码
   - `alipay` - 支付宝收款码
   - `btc` - BTC 钱包二维码
   - `usdt` - USDT 钱包二维码
   - `aboutme` - 开发者照片

### 2. 批量复制到各项目

运行 `batch_seed.bat`，自动复制到：

| 项目 | 数据库文件名 |
|------|-------------|
| MoveC | MoveCConfig.db |
| TwoKeyRun | TwoKeyRunConfig.db |
| TransSuccess | TransSuccessConfig.db |
| uniSVG | uniSVGConfig.db |
| EasyConfig | EasyConfigConfig.db |
| OmniSync | OmniSyncConfig.db |
| Touchstone | TouchstoneConfig.db |
| wyjx | wyjxConfig.db |
| Chain2VFactory | Chain2VConfig.db |

### 3. 各项目代码配置

在各项目的初始化代码中使用统一配置：

```pascal
uses
  uAntiTamperPackage;

procedure InitAntiTamper;
var
  Config: TAntiTamperConfig;
begin
  Config := TAntiTamperPackage.GetDefaultConfig;
  Config.EncryptionKey := 'UniBase_Shared_Key_2025';
  Config.Salt := 'UniBase_Shared_Salt_v1';
  Config.KdfIterations := 10000;
  Config.EnableHMAC := True;
  Config.EncryptionType := etAES256;
  Config.EnableLogging := False;  // 生产环境关闭日志
  TAntiTamperPackage.Initialize(Config);
end;
```

## 安全说明

### 优点
- 维护简单，只需播种一次
- 更新收款信息时，只需重新播种模板并批量复制

### 缺点
- 所有程序共用密钥，一个被破解可能影响其他
- 但对于收款二维码这类公开信息，风险可接受

### 建议
- 收款二维码等公开信息：使用共享密钥
- 授权文件等敏感信息：使用独立密钥

## 更新收款信息

当需要更换收款二维码时：

1. 用 SeedTool 重新播种 `template.db`
2. 运行 `batch_seed.bat` 批量更新
3. 重新发布各程序（或提供数据库更新包）
