# 播种工具与主程序对应关系说明

## 1. 概述

SeedTool 是一个通用的防篡改播种工具，用于将图像加密存储到 SQLite 数据库中，支持：
- **图像加密播种** - 将图片文件加密并存储到数据库
- **文字配置** - 为每个图像配置地址文本和描述信息
- **从数据库加载** - 读取现有记录并修改文字

## 2. 图像 Key 对应关系

### 播种工具 → 数据库 → 主程序

```
播种工具                    数据库                      主程序代码
───────────────────────────────────────────────────────────────────
文件名(不含扩展名)      →   image_key 字段        →   LoadSecureImage() 参数
───────────────────────────────────────────────────────────────────
wechat.png              →   'wechat'              →   'wechat'
alipay.png              →   'alipay'              →   'alipay'  
btc.png                 →   'btc'                 →   'btc'
usdt.png                →   'usdt'                →   'usdt'
aboutme.png             →   'aboutme'             →   'aboutme'
```

### 关键约束

1. **图像 Key = 文件名（不含扩展名）**
2. **大小写敏感** - `wechat` ≠ `Wechat` ≠ `WECHAT`，建议统一使用小写
3. **主程序读取时必须使用相同的 Key**

## 3. SeedTool 使用流程

### 方式 A：全新播种

1. **设置数据库路径** - 选择或新建 .db 文件
2. **配置加密参数** - 确保与主程序一致
3. **添加图像文件** - 点击"添加图像"或"选择文件夹"
4. **配置文字**（可选）- 切换到"文字配置"页签，填写地址和描述
5. **开始播种** - 加密并写入数据库

### 方式 B：修改现有文字

1. **设置数据库路径** - 选择现有 .db 文件
2. **点击"从数据库加载"** - 读取现有记录
3. **切换到"文字配置"页签** - 修改地址文本和描述
4. **开始播种** - 仅更新文字字段（不重新加密图像）

### 数据库字段说明

| 字段 | 用途 | 示例 |
|------|------|------|
| image_key | 图像唯一标识 | `wechat`, `btc` |
| image_data | 加密后的图像二进制 | (BLOB) |
| address_text | 地址/网址文本 | `bc1qxxx...` 或 `www.goodmem.cn` |
| description | 描述信息 | "开发者: xxx\n网站: xxx" |
| sha256_hash | 明文哈希 | (SHA-256) |
| hmac_sha256 | HMAC 签名 | (HMAC-SHA256) |

## 4. 加密配置一致性

### 必须保持一致的参数

| 参数 | SeedTool | 主程序 (uMain.pas) |
|------|----------|--------------------|
| EncryptionKey | 界面输入 | `Config.EncryptionKey` |
| Salt | 界面输入 | `Config.Salt` |
| KdfIterations | 界面输入 | `Config.KdfIterations` |
| EnableHMAC | 勾选框 | `Config.EnableHMAC` |

### MoveC 默认配置

```
EncryptionKey:  MoveC_AntiTamper_Key_2025
Salt:           MoveC_Salt_v1
KdfIterations:  10000
EnableHMAC:     True
```

## 5. 主程序集成示例

### 初始化配置 (uMain.pas)

```pascal
procedure TfrmMain.FormCreate(Sender: TObject);
var
  Config: TAntiTamperConfig;
begin
  Config := TAntiTamperPackage.GetDefaultConfig;
  Config.EncryptionKey := 'MoveC_AntiTamper_Key_2025';
  Config.Salt := 'MoveC_Salt_v1';
  Config.KdfIterations := 10000;
  Config.EnableHMAC := True;
  Config.EncryptionType := etAES256;
  TAntiTamperPackage.Initialize(Config);
end;
```

### 加载图像 (FrameAboutMe.pas)

```pascal
procedure TFrameAboutMe.LoadImages;
var
  AddressText: string;
begin
  // 加载并显示图像，AddressText 返回数据库中的地址文本
  if TAntiTamperPackage.LoadSecureImage(FDTable1, 'wechat', imgWechat, AddressText) then
    lblWechatAddress.Caption := AddressText;
    
  if TAntiTamperPackage.LoadSecureImage(FDTable1, 'btc', imgBTC, AddressText) then
    lblBTCAddress.Caption := AddressText;  // 显示 BTC 地址
end;
```

## 6. 安全机制

### 防篡改流程

```
播种时：
  明文图像 → AES-256加密 → 计算SHA-256 → 计算HMAC → 写入数据库

加载时：
  读取密文 → AES-256解密 → 验证SHA-256 → 验证HMAC → 显示图像
                                ↓                  ↓
                          失败=篡改           失败=篡改
                                ↓                  ↓
                              弹出警告 + 程序退出 (fail-closed)
```

### 分发清单

| 文件 | 给用户 | 管理员保留 |
|------|--------|------------|
| 主程序.exe | ✓ | ✓ |
| 数据库.db | ✓ | ✓ |
| SeedTool.exe | ✗ | ✓ |
| 原始图片 | ✗ | ✓ |

## 7. 常见问题

### Q1：修改密码后旧数据库能用吗？
**不能。** 需用新密码重新播种。

### Q2：只想修改文字，不想重新加密图片？
点击"从数据库加载"，修改文字后播种，会仅更新文字字段。

### Q3：数据库被篡改会怎样？
主程序校验失败 → 弹出警告 → 程序退出。

### Q4：如何在其它程序中使用？
参考《加密防篡改集成说明.md》。
