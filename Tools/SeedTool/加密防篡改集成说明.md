# 加密防篡改集成说明

本文档指导如何在任意 Delphi VCL/FireDAC + SQLite 程序中集成防篡改机制。

## 一、机制概览

### 安全特性

| 特性 | 实现 |
|------|------|
| 数据加密 | AES-256-CBC (Windows Crypto API) |
| 密钥派生 | PBKDF2-SHA256 (可配置迭代次数) |
| 完整性校验 | SHA-256 (明文哈希) |
| 防篡改校验 | HMAC-SHA256 (派生密钥签名) |
| 安全策略 | Fail-closed (校验失败即退出) |

### 数据库表结构 (默认表名: `images`)

```sql
CREATE TABLE images (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  image_key TEXT NOT NULL UNIQUE,     -- 业务主键
  image_data BLOB NOT NULL,           -- AES-256 加密密文
  address_text TEXT,                  -- 地址/网址文本
  description TEXT,                   -- 描述信息
  sha256_hash TEXT NOT NULL,          -- 明文 SHA-256
  hmac_sha256 TEXT NOT NULL,          -- 明文 HMAC-SHA256
  created_at DATETIME,
  updated_at DATETIME
);
```

## 二、集成步骤

### 步骤 1：复制核心文件

将以下文件复制到你的项目目录：

```
uAntiTamperPackage.pas   // 防篡改主模块 (KDF, 加解密, 校验, DB操作)
uBasicProtection.pas     // AES-256 加密实现 (Windows Crypto API)
```

### 步骤 2：添加 uses 引用

```pascal
uses
  uAntiTamperPackage,
  // FireDAC 必需单元
  FireDAC.Comp.Client, FireDAC.Stan.Param, FireDAC.Stan.Def,
  FireDAC.Phys.SQLite, FireDAC.Phys.SQLiteDef;
```

### 步骤 3：初始化配置 (程序启动时)

```pascal
procedure TfrmMain.FormCreate(Sender: TObject);
var
  Config: TAntiTamperConfig;
begin
  // 配置防篡改参数 - 必须与 SeedTool 完全一致
  Config := TAntiTamperPackage.GetDefaultConfig;
  Config.EncryptionKey := 'YourApp_UniqueKey_2025';  // 自定义密钥
  Config.Salt := 'YourApp_Salt_v1';                   // 自定义盐值
  Config.KdfIterations := 10000;                      // KDF 迭代次数
  Config.EnableHMAC := True;                          // 启用 HMAC
  Config.EncryptionType := etAES256;                  // AES-256 加密
  Config.EnableLogging := False;                      // 生产环境关闭日志
  TAntiTamperPackage.Initialize(Config);
  
  // 连接数据库后初始化表结构
  FDConnection.Connected := True;
  TAntiTamperPackage.SetupDatabase(FDConnection);
end;
```

### 步骤 4：加载加密图像

```pascal
procedure TMyForm.LoadSecureImages;
var
  AddressText: string;
begin
  // 加载并显示图像，同时获取地址文本
  if TAntiTamperPackage.LoadSecureImage(FDTable1, 'wechat', imgWechat, AddressText) then
    lblWechatAddress.Caption := AddressText
  else
    // 加载失败或校验失败
    ShowMessage('图像加载失败');
end;
```

## 三、使用 SeedTool 播种

### 播种流程

1. 运行 `SeedTool.exe`
2. 选择数据库文件路径 (如 `YourApp.db`)
3. 配置加密参数 (**必须与代码一致**):
   - EncryptionKey: `YourApp_UniqueKey_2025`
   - Salt: `YourApp_Salt_v1`
   - KdfIterations: `10000`
   - EnableHMAC: ✓
4. 添加图像文件
5. (可选) 切换到"文字配置"页签填写地址和描述
6. 点击"开始播种"

### 修改现有文字

1. 选择现有数据库
2. 点击"从数据库加载"
3. 切换到"文字配置"页签修改
4. 点击"开始播种"（仅更新文字字段）

## 四、配置一致性检查表

| 参数 | 主程序 | SeedTool | 必须一致 |
|------|--------|----------|----------|
| EncryptionKey | `Config.EncryptionKey` | 界面输入 | **是** |
| Salt | `Config.Salt` | 界面输入 | **是** |
| KdfIterations | `Config.KdfIterations` | 界面输入 | **是** |
| EnableHMAC | `Config.EnableHMAC` | 勾选框 | **是** |
| 数据库路径 | 运行时读取 | 播种时选择 | 同一文件 |

## 五、安全建议

1. **每个项目使用独立的密钥和盐值**
2. **不要分发 SeedTool** - 仅开发机使用
3. **定期备份数据库文件**
4. **生产环境关闭日志** - `Config.EnableLogging := False`

## 八、常见问题

### Q1: 报错 "no such column: sha256_hash"
调用 `TAntiTamperPackage.SetupDatabase(FDConnection)` 自动创建/升级表结构。

### Q2: 解密失败
检查 SeedTool 和主程序的加密参数是否完全一致。

### Q3: 如何更换密钥？
修改密钥后需用 SeedTool 重新播种所有图像。
